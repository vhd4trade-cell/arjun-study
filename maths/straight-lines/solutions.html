Q.S1Chapter Practice · Subjective Level-I
Origin માંથી પસાર થતી રેખા x = 1, y = 2 અને x + y = 4 ને અનુક્રમે A, B, C માં મળે છે, અને OA · OB · OC = 8√2. રેખાનું સમીકરણ શોધો.
1પ્રશ્ન શું પૂછે છે
આ પ્રશ્ન શું પૂછે છે:
Origin માંથી જતી એક રેખા શોધવી, જે ત્રણ આપેલી રેખાઓને A, B, C માં મળે અને OA·OB·OC = 8√2 થાય.
[Chapter notes: વિભાગ 1, 3]

શું hidden છે: રેખાનો slope m

શું આપ્યું છે તેની જગ્યાએ: slope સીધો નથી આપ્યો — તેના બદલે ત્રણ અંતરોનો ગુણાકાર આપ્યો છે

તે slope m કેવી રીતે મળે છે:
• "Origin માંથી રેખા" ⟹ રેખા y = mx — એક જ અજ્ઞાત m બચે છે.
• y = mx ને x = 1, y = 2, x + y = 4 સાથે ઉકેલો ⟹ A, B, C ના coordinates m માં મળે.
• Origin થી (x, mx) નું અંતર = |x|·√(1 + m²) ⟹ OA, OB, OC ત્રણેય m માં.
• ગુણાકાર = 8√2 મૂકો ⟹ m નું એક જ equation ⟹ m = 1.
2Approach અને શા માટે
Step 1: y = mx (origin આવે છે) → intersections: A(1, m), B(2/m, 2), C(4/(1+m), 4m/(1+m))
Step 2: Distances: OA = √(1+m²), OB = 2√(1+m²)/|m|, OC = 4√(1+m²)/|1+m|
Step 3: Product equation: 8(1+m²)^1.5 / |m(1+m)| = 8√2
Step 4: Square both sides: (1+m²)³ = 2m²(1+m)² → m = 1 (only real root)
3Catches / Do's and Don'ts
  • DO: OA = |x_A|√(1 + m²) — origin થી રેખા પર point (x, mx) નું અંતર
  • DON'T: x = 0 (ઊભી રેખા) ભૂલવી — તે x = 1 ને મળતી જ નથી, તેથી બાકાત
4તમારી ભૂલ ક્યાં થઈ શકે
Equation ને square કરતી વખતે |m(1 + m)| નું sign ભૂલવું — square કર્યા પછી m = 1 મળે, અને બીજાં real roots નથી તે ચકાસવું.

6Ideal method — સંપૂર્ણ steps

OA·OB·OC = 8(1 + m²)^{3/2} / |m(1 + m)| = 8√2

Q.S2Chapter Practice · Subjective Level-I
Point A(2, 1) ને x + y = 1 ને સમાંતર, ordinate વધે તે દિશામાં 3√2 એકમ ખસેડીને B મળે છે. x + y = 1 માં B નું image શોધો.
1પ્રશ્ન શું પૂછે છે
આ પ્રશ્ન શું પૂછે છે:
આપેલ બિંદુ માંથી આપેલ દિશા અને અંતર r સાથે ખસતું બિંદુ શોધવું
[Chapter notes: 3f. Parametric form]

શું hidden છે: θ (direction angle)

શું આપ્યું છે તેની જગ્યાએ: x+y=1 અને "ordinate વધે તે"

તે θ કેવી રીતે મળે છે:
- "x+y=1 ને સમાંતર" → line નું direction મેળવો
- "ordinate વધે તે" → sin θ ≥ 0 બંધાણ ચેક કરો
2Approach અને શા માટે
Step 1: દિશા વેક્ટર શોધો
• x+y=1 નું normal: (1,1) ⟹ direction (−1,1) (perpendicular)
• "ordinate વધે" ⟹ y-component positive ⟹ (−1,1) ✓
Step 2: Unit vector બનાવો
• unit = (−1,1)/√(1²+1²) = (−1,1)/√2
Step 3: B ની position
• B = A + 3√2 · (unit) = (2,1) + 3√2·(−1/√2, 1/√2) = (2−3, 1+3) = (−1, 4)
Step 4: x+y=1 માં image
• Shortcut (line x+y=c માટે): (x,y) → (1−y, 1−x)
• (−1,4) → (−3, 2)
3Catches / Do's and Don'ts
  • DO: "ordinate વધે" ⟹ sin θ > 0 વાળી દિશા (135°) પસંદ કરો
  • DON'T: (1, −1) દિશા લેવી — તે y ઘટાડે
4તમારી ભૂલ ક્યાં થઈ શકે
Unit vector બનાવ્યા વગર (−1, 1) ને સીધું 3√2 વડે ગુણવું ⟹ 6 એકમ ખસી જવાય.
5Chapter notes માંથી શું fetch કરવું ↗
Part 03 — parametric form  ·  Part 04 — image formula
6Ideal method — સંપૂર્ણ steps
દિશા θ = 135°: (cos θ, sin θ) = (−1/√2, 1/√2)
B = (2 − 3, 1 + 3) = (−1, 4)
Image: (x − (−1))/1 = (y − 4)/1 = −2(−1 + 4 − 1)/2 = −2 ⟹ (−3, 2)
Answer: (−3, 2)  · publisher key: (−3, 2) ✓
7Alternative approach / ચકાસણી
Shortcut x + y = 1 માં (x, y) → (1 − y, 1 − x): (−1, 4) → (1 − 4, 1 + 1) = (−3, 2) ✓.
⏱Time-saving tip
Image માટે રેખા x ± y = c હોય તો coordinates અદલાબદલી shortcut — formula કરતાં 3 ગણું ઝડપી.
9Graphical interpretation
A થી રેખાને સમાંતર 3√2 (વાદળી dashed) ⟹ B(−1, 4); B નું x + y = 1 માં image B′(−3, 2) — BB′ રેખાને લંબ.
Q.S3Chapter Practice · Subjective Level-I
Curve px² − 4by = 0 ની chord 4px − √2 py = 4√2 b, origin પાસે કેટલો ખૂણો બનાવે (subtend કરે)?
1પ્રશ્ન શું પૂછે છે
આ પ્રશ્ન શું પૂછે છે:
Curve px² − 4by = 0 અને chord 4px − √2py = 4√2b ના બે છેદબિંદુઓ origin સાથે જોડો; એ બે રેખાઓ વચ્ચેનો ખૂણો શોધો.
[Chapter notes: વિભાગ 10]

શું hidden છે: Origin થી chord ના બે છેડા સુધીની બે રેખાઓ

શું આપ્યું છે તેની જગ્યાએ: બે રેખાઓ નથી આપી — ફક્ત curve અને chord ના equations આપ્યાં છે

તે બે રેખાઓ કેવી રીતે મળે છે:
• Chord ને "= 1" ના રૂપમાં લખો: (4px − √2py)/(4√2b) = 1.
• Curve માં degree-1 પદ (−4by) ને આ "1" થી ગુણો ⟹ દરેક પદ degree 2 નું બને (homogenisation).
• મળેલું x² − 2√2xy + y² = 0 એ origin માંથી જતી pair of lines છે — એ જ hidden બે રેખાઓ.
• Pair ના angle formula tan θ = 2√(h² − ab)/|a + b| ⟹ θ = π/4.
2Approach અને શા માટે
Step 1: Homogenize curve
• Chord: 4px − √2py = 4√2b ⟹ normalize (4px − √2py)/(4√2b) = 1
• curve × normalized-chord: px²(4px−√2py)/(4√2b) − 4by·1 = 0
• Simplify: x² − 2√2xy + y² = 0 ← homogeneous pair through origin
Step 2: Extract a, b, h
• x² term: a=1, y² term: b=1, xy term: 2h=−2√2 ⟹ h=−√2
Step 3: Apply angle formula
• tan θ = 2√(h²−ab) / |a+b| = 2√(2−1) / 2 = 1
• θ = π/4 = 45°
3Catches / Do's and Don'ts
  • DO: ફક્ત degree-1 પદને "1" વડે ગુણો; x² પદ પહેલેથી degree 2 છે
  • DON'T: p, b ને ખોટી રીતે રદ કરવા — અંતે p થી ભાગી શકાય (p ≠ 0)
4તમારી ભૂલ ક્યાં થઈ શકે
Formula માં h ને xy ના coefficient બરાબર લેવું — અહીં 2h = −2√2 ⟹ h = −√2.
5Chapter notes માંથી શું fetch કરવું ↗
Part 10 — homogenisation, angle formula
6Ideal method — સંપૂર્ણ steps
px² − 4by·(4px − √2py)/(4√2b) = 0 ⟹ px² − (4/√2)pxy + py² = 0
x² − 2√2xy + y² = 0: a = b = 1, h = −√2
tan θ = 2√(2 − 1)/(1 + 1) = 1 ⟹ θ = π/4
Answer: π/4  · publisher key: π/4 ✓
7Alternative approach / ચકાસણી
p = b = 1 લઈ numerically: x² = 4y અને 4x − √2y = 4√2 ના છેદ x = 4√2 ± 4 ⟹ બંને રેખાઓ વચ્ચે ખૂણો 45.000° (ગણેલું) ✓.
⏱Time-saving tip
"Subtends angle at origin" ⟹ તરત homogenise; જવાબ p, b પર આધાર રાખતો નથી — એ જ સંકેત કે homogenised equation માં તે રદ થશે.
9Graphical interpretation
p = b = 1 (x² = 4y) લઈ દોર્યું: chord ના છેડા (9.66, 23.31) અને (1.66, 0.69); origin પાસે ખૂણો 45° (ગણેલું) — p, b ગમે તે હોય, ખૂણો એ જ.
Q.S4Chapter Practice · Subjective Level-II
એક variable રેખાના coordinate axes પરના intercepts ના વર્ગોનો સરવાળો અચળ = a² છે. Origin થી આ રેખા પર દોરેલા લંબ ના પગનો locus શોધો.
⚠ Publisher key માં ફક્ત "a²" છપાયું છે — તે locus નથી (અધૂરું/ખોટું છપાયેલું). Locus (x² + y²)³ = a²x²y² બે રીતે ચકાસ્યું: intercepts 3, 4 (a = 5) વાળી રેખા પર ખરેખર પગ ગણીને equation satisfy થાય છે.
1પ્રશ્ન શું પૂછે છે
આ પ્રશ્ન શું પૂછે છે:
Variable રેખાના intercepts A, B માટે A² + B² = a² (અચળ). Origin થી એ રેખા પરના લંબના પગનો locus શોધો.
[Chapter notes: વિભાગ 8, 3]

શું hidden છે: પગ (h, k) અને રેખાના equation વચ્ચેનો સંબંધ

શું આપ્યું છે તેની જગ્યાએ: રેખા કે પગ કંઈ જ સીધું નથી આપ્યું — ફક્ત intercepts ની શરત આપી છે

તે પગ–રેખા સંબંધ કેવી રીતે મળે છે:
• પગ = (h, k) ધારો. Origin થી પગ સુધીની દિશા (h, k) રેખાને લંબ છે ⟹ (h, k) એ રેખાનો normal.
• તેથી રેખા: hx + ky = h² + k² (પગ પોતે રેખા પર છે).
• Intercepts: A = (h² + k²)/h, B = (h² + k²)/k.
• A² + B² = a² મૂકી h, k ને x, y કરો ⟹ (x² + y²)³ = a²x²y².
2Approach અને શા માટે
Step 1: પગ થી line equation
• foot of perpendicular: (h,k)
• origin થી direction: (h,k) ← normal to line
• line equation: hx + ky = h² + k²
Step 2: Intercepts શોધો
• x-intercept: y=0 ⟹ hx = h²+k² ⟹ A = (h²+k²)/h
• y-intercept: x=0 ⟹ ky = h²+k² ⟹ B = (h²+k²)/k
Step 3: Constraint લાગુ કરો
• A² + B² = a²
• [(h²+k²)/h]² + [(h²+k²)/k]² = a²
• (h²+k²)² [1/h² + 1/k²] = a²
• (h²+k²)³ / (h²k²) = a²
Step 4: Locus (x,y) માં
• (x² + y²)³ = a² x² y²
3Catches / Do's and Don'ts
  • DO: "origin થી લંબ નો પગ" ⟹ normal form ની જેમ hx + ky = h² + k²
  • DON'T: intercepts a, b ને અલગ unknowns રાખી બે equations બનાવવી — લાંબું
4તમારી ભૂલ ક્યાં થઈ શકે
Intercept (h² + k²)/h ને વર્ગ કરતાં ઘાત ગૂંચવવી: (h² + k²)²(1/h² + 1/k²) = (h² + k²)³/(h²k²).
5Chapter notes માંથી શું fetch કરવું ↗
Part 08 — locus ની રીત  ·  Part 03 — intercept અને normal form
6Ideal method — સંપૂર્ણ steps
રેખા: hx + ky = h² + k² ⟹ intercepts A = (h² + k²)/h, B = (h² + k²)/k
A² + B² = (h² + k²)²·(h² + k²)/(h²k²) = a²
Locus: (x² + y²)³ = a²x²y²
Answer: (x² + y²)³ = a²x²y²  · publisher key: a² ⚠
7Alternative approach / ચકાસણી
ચકાસણી: A = 3, B = 4 (a² = 25): પગ = (48/25, 36/25); (x² + y²)³ = (2304 + 1296)³/25⁶ = 3600³/25⁶ અને a²x²y² = 25·(48·36)²/25⁴ — બંને = 2985.98 ✓.
⏱Time-saving tip
"Origin થી પગ નો locus" ⟹ પગ (h, k) સીધો normal form આપે: hx + ky = h² + k². આ એક વાક્ય 70% કામ કરે છે.
9Graphical interpretation
a = 5: A = 5cos t, B = 5sin t માટે પગ ગણીને (લીલો) locus દોર્યો — ચાર પાંખડી જેવો આકાર; x/3 + y/4 = 1 નો પગ તેના પર (ગણેલું).
Q.S5Chapter Practice · Subjective Level-II
રેખાઓ ax + by + p = 0 અને x cos α + y sin α − p = 0 વચ્ચે π/4 નો ખૂણો છે અને બંને રેખા x sin α − y cos α = 0 ને એક જ બિંદુએ મળે છે. તો a² + b² = ?
1પ્રશ્ન શું પૂછે છે
આ પ્રશ્ન શું પૂછે છે:
ત્રણ રેખા concurrent અને બે વચ્ચે π/4 નો ખૂણો
[Chapter notes: વિભાગ 7, 2]

શું hidden છે: a² + b²

શું આપ્યું છે તેની જગ્યાએ: Euler line relation, 90° બંધાણ, concurrent condition

તે hidden a²+b² કેવી રીતે મળે છે:
Normal form → foot → angle constraint → dot product 0
2Approach અને શા માટે
Step 1: Concurrent point શોધો
• બીજી અને ત્રીજી રેખા perpendicular (dot product 0)
• તેમનું intersection = (p cos α, p sin α)

• (p cos α, p sin α) પર ax + by + p = 0

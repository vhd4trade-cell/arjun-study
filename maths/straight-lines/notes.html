00Straight line શું છે

શા માટે ભણવું: આખો chapter "રેખા = fixed દિશા" ના એક જ વિચાર પર ઊભો છે.

outcome કોઈ પણ રેખાને equation માં લખવી, બે રેખા વચ્ચે ખૂણો/અંતર/છેદબિંદુ શોધવું, અને point–line ના સંબંધ (અંતર, પ્રતિબિંબ, કઈ બાજુ) ને algebra વડે ઉકેલવા — એ આ chapter નું core skill છે. JEE માં આ જ tools circle, parabola, ellipse ના chapters માં સીધા વપરાય છે.

"Coordinate geometry" શું છે

Geometry (ભૂમિતિ) માં આકારો આકૃતિ દોરીને સમજાય છે; algebra માં સંખ્યાઓ અને equations થી. 1637 માં René Descartes એ આ બંનેને જોડ્યા: plane પરના દરેક point ને સંખ્યાની જોડી (x, y) આપી દો — પછી "રેખા", "વર્તુળ" જેવા આકારો equations બની જાય, અને geometry ના પ્રશ્નો algebra થી ઉકેલાય. એટલે આ શાખાને coordinate geometry (અથવા analytical geometry) કહે છે.

શબ્દોનો પાયો — coordinate, abscissa, ordinateCoordinate = Latin co- (સાથે) + ordinare (ક્રમમાં ગોઠવવું): બે સંખ્યા "સાથે મળીને" point ને તેની જગ્યા પર ગોઠવે છે. Ordinate (y) એ જ ordinare પરથી — "ગોઠવેલી" ઊભી રેખા. Abscissa (x) = Latin abscindere (કાપવું): x-axis પરથી "કાપીને" લીધેલો ટુકડો. અને linear (રેખીય) = Latin linea (દોરો, રેખા) — એટલે "linear equation" નો શાબ્દિક અર્થ જ "રેખાનું equation".
Point P(3, 2): પહેલા x-axis પર 3 એકમ (abscissa), પછી y-axis ની દિશામાં 2 એકમ (ordinate) — બે સંખ્યાનો ક્રમ (ordered pair) જ point ને "ગોઠવે" છે; ચાર quadrants ના sign સાથે

રેખા એટલે શું — અને ax + by + c = 0 જ કેમ રેખા આપે?

Straight line (સીધી રેખા) = એવો માર્ગ જેની દિશા ક્યારેય બદલાતી નથી. Coordinate ભાષામાં: રેખા પરના કોઈ પણ બે points લો, તો "y માં ફેરફાર ÷ x માં ફેરફાર" (rise/run) હંમેશાં એક જ સંખ્યા આવે. આ સંખ્યા એ જ slope.

Mechanism (કારણ, ઉપમા નહીં): ધારો (x₁, y₁) અને (x₂, y₂) બંને ax + by + c = 0 ને satisfy કરે. બાદ કરો: a(x₂ − x₁) + b(y₂ − y₁) = 0 ⟹ (y₂ − y₁)/(x₂ − x₁) = −a/b. એટલે કોઈ પણ બે solution points વચ્ચે rise/run એક જ fixed −a/b આવે — c કે points ની પસંદગી પર આધાર નથી. Fixed rise/run = દિશા બદલાતી નથી = સીધી રેખા. (b = 0 હોય તો x = −c/a — ઊભી રેખા.) x², xy જેવું કોઈ પદ આવે તો આ બાદબાકી fixed ratio નથી આપતી — એટલે જ degree-1 (linear) equation જ રેખા છે.

Equation 2x − y − 1 = 0 ના ત્રણ solutions: દરેક પગલે x 1 વધે તો y 2 વધે — rise/run હંમેશાં 2. "દિશા ક્યારેય બદલાતી નથી" = સીધી રેખા
why it mattersPhysics માં uniform motion (s = ut), Ohm’s law (V = IR), calibration graphs; Economics માં cost/revenue; JEE માં circle-tangent, parabola-chord, locus — બધે "રેખાનું equation લખવું અને તેના પર કામ કરવું" એ પાયો છે. Straight Lines પરથી જ Conic sections (Class 11) અને 3D lines (Class 12) બને છે.
real-world exampleTaxi કે auto નું ભાડું: fixed charge + km દીઠ દર. Graph સીધી રેખા છે કારણ કે દર (slope) બદલાતો નથી.
Taxi ભાડું = 30 + 15 × (km): દરેક km એ ભાડું સરખું 15 વધે છે ⟹ graph સીધી રેખા; slope = દર (₹15/km), intercept = fixed charge

01Coordinate basics — ઝડપી પુનરાવર્તન

શા માટે ભણવું: Straight line ના લગભગ દરેક પ્રશ્નમાં છેલ્લે અંતર/section/ક્ષેત્રફળ ગણવું પડે છે.

distancesection (અંદર/બહાર)midpointcentroidincentreક્ષેત્રફળcollinearity

આ બધું 10th માં આવી ગયું છે — અહીં ફક્ત તે formulas જે આગળ વારંવાર વપરાશે, અને તે "કેમ" સાચા છે.

1a. બે points વચ્ચે અંતર

કામમાં આવે: આપેલ બે બિંદુ વચ્ચેનું સીધું (હવાઈ) અંતર શોધવા

formula — must memorize
AB = √[(x₂ − x₁)² + (y₂ − y₁)²]
A, B વચ્ચે આડું અને ઊભું અંતર — એ right triangle ના legs; AB એ hypotenuse (Pythagoras)
Distance formula = Pythagoras: આડું અંતર 4, ઊભું અંતર 3 ⟹ AB = 5 (ગણેલું)
Generic: x₁, x₂, y₁, y₂ ને તમારા પ્રશ્નના મૂલ્યો સાથે બદલો

JEE twist: તમને બે points આપ્યા જશે નહીં. બદલે બે રેખા આપશે, તેમનો છેદબિંદુ શોધો, પછી અંતર ગણો.

real-world exampleMap પર બે શહેરોના grid coordinates (km માં) આપ્યા હોય તો "હવાઈ અંતર" (crow-flight distance) આ જ સૂત્ર — GPS apps અંદર નાના વિસ્તાર માટે આ જ ગણતરી કરે છે.

1b. Section formula

કામમાં આવે: રેખા પર એક બિંદુ અમુક ગુણોત્તર (ratio) માં વહેંચતો હોય તો તે બિંદુના coordinates શોધવા

formula — must memorize
અંદર m:n ⟹ P = ((mx₂ + nx₁)/(m + n), (my₂ + ny₁)/(m + n)); બહાર m:n ⟹ (mx₂ − nx₁)/(m − n), …
AP:PB = m:n. Midpoint = 1:1. બહારના (external) division માં n ને −n કરો
Section formula: P એ AB ને અંદરથી 1:2 માં વહેંચે (AP:PB = 1:2), Q બહારથી 3:1 માં (AQ:QB = 3:1, Q લંબાવેલી રેખા પર) — બંને ગણેલા
Generic: તમારા m, n, (x₁,y₁), (x₂,y₂) મૂલ્યો મૂકો

કેમ સાચું:
A થી B જવામાં P એ કુલ માર્ગનો m/(m+n) ભાગ કાપે છે.
એટલે x માં ફેરફાર પણ એટલો જ ભાગ:
x = x₁ + [m(x₂ − x₁)]/(m + n) = (mx₂ + nx₁)/(m + n)
y માટે પણ એ જ લાગુ

JEE twist: તમને ratio ના અંશ-છેદ આપશે નહીં, બદલે "Point P એ triangle નું 2:1 વહેંચે" જેવું કહેશે — તમે પહેલાં 2:1 શું છે તે સમજો, પછી ફોર્મુલા લગાડો।

real-world examplePhysics નું centre of mass: બે દળ m₁, m₂ અનુક્રમે x₁, x₂ પર હોય તો x_cm = (m₁x₁ + m₂x₂)/(m₁ + m₂) — આ section formula જ છે (ભારે દળ તરફ બિંદુ ખસે છે).
common mistakeRatio m:n માં m એ બીજા point (B) ના coordinate સાથે ગુણાય છે, પહેલા સાથે નહીં — mx₂ + nx₁. ઊંધું લખવું સૌથી સામાન્ય ભૂલ છે. "Point કયા ratio માં વહેંચે" પ્રશ્નમાં ratio k:1 ધારો — k ઋણ આવે તો division બહારનું (external) છે.

1c. Centroid અને incentre

કામમાં આવે: ત્રિકોણનું "સંતુલન બિંદુ" (centroid) અથવા "inscribed circle નું કેન્દ્ર" (incentre) શોધવા

formula — must memorize
G = ((x₁ + x₂ + x₃)/3, (y₁ + y₂ + y₃)/3); I = (ax₁ + bx₂ + cx₃)/(a + b + c), …
G = medians નું મિલનબિંદુ (vertices નો સરેરાશ). I = angle bisectors નું — a, b, c = સામેની બાજુઓની લંબાઈ (a = BC)
ત્રણેય medians (ભૂરી dashed) એક જ બિંદુ G માં મળે છે; G દરેક median ને 2:1 માં વહેંચે — G = vertices નો સરેરાશ (ગણેલું)
real-world exampleત્રિકોણ આકારની પાતળી ધાતુની પટ્ટીને આંગળી પર એક જ બિંદુએ સંતુલિત કરી શકાય — તે બિંદુ centroid. Engineering માં trusses/plates નું સંતુલન આ જ ગણતરીથી.

1d. Triangle નું ક્ષેત્રફળ અને collinearity

કામમાં આવે: ત્રિકોણનું ક્ષેત્રફળ અથવા ત્રણ બિંદુ એક જ રેખા પર છે કે નહીં તે પરખવા

formula — must memorize
Δ = ½ |x₁(y₂ − y₃) + x₂(y₃ − y₁) + x₃(y₁ − y₂)|
Δ = 0 ⟺ ત્રણેય points એક જ રેખા પર (collinear). Polygon માટે shoelace: ½|Σ(xᵢyᵢ₊₁ − xᵢ₊₁yᵢ)|
Shoelace formula થી ½|1(2 − 5) + 6(5 − 1) + 3(1 − 2)| = ½|18| = 9 ચોરસ એકમ
real-world exampleજમીન માપણી (land survey): ખેતરના ખૂણાઓના GPS coordinates પરથી ક્ષેત્રફળ — સરકારી 7/12 ઉતારા અને digital land records માં આ shoelace સૂત્ર જ વપરાય છે.
exam focusDiagonals d₁, d₂ વચ્ચે ખૂણો θ હોય તો કોઈ પણ quadrilateral (parallelogram, rhombus) નું ક્ષેત્રફળ = ½ d₁ d₂ sin θ; diagonals ના slopes પરથી sin θ. (Question bank: Section II Comprehension Q3–Q4 — ત્યાં diagram સાથે.)
self-checkPoints (x, −1), (2, 1), (4, 5) collinear હોય તો x = ? (જવાબ: 1 — slope (5 − 1)/(4 − 2) = 2 = (1 + 1)/(2 − x))

02Slope અને ખૂણો

શા માટે ભણવું: Parallel, perpendicular, ખૂણો — બધું slope ની એક સંખ્યા પરથી નક્કી થાય છે.

inclination θslope m = tan θબે points થી slopeparallel / perpendicularબે રેખા વચ્ચેનો ખૂણો

2a. Slope — "દિશા" ને સંખ્યામાં

Inclination θ = રેખા x-axis ની ધન દિશા સાથે anticlockwise માપે તે ખૂણો (0° ≤ θ < 180°).
Slope (ઢાળ) m = tan θ.
શબ્દ "slope" જૂના અંગ્રેજી aslope (ત્રાંસું) પરથી; સમાનાર્થી gradient = Latin gradus (પગથિયું) — "એક પગલે કેટલું ચઢાણ".

formula — must memorize
m = tan θ = (y₂ − y₁)/(x₂ − x₁)
બે points (x₁, y₁), (x₂, y₂) પરથી. Equation ax + by + c = 0 નો slope = −a/b (Part 00 નું mechanism)
Slope = rise/run = 3/4 = tan(36.87°): θ = રેખા x-axis ની ધન દિશા સાથે (anticlockwise) બનાવતો ખૂણો — inclination
Generic: તમારા θ, (x₁,y₁), (x₂,y₂) મૂલ્યો મૂકો

tan θ જ કેમ? Run અને rise એ right triangle ના adjacent અને opposite sides છે, અને opposite/adjacent = tan θ — એ trigonometry ની વ્યાખ્યા જ છે.

Slope નું sign: જમણે જતાં ઉપર ચઢે તો ધન, નીચે ઉતરે તો ઋણ; આડી રેખા 0; ઊભી રેખા (θ = 90°) માટે tan અવ્યાખ્યાયિત

JEE twist: તમને θ આપશે નહીં. બદલે "રેખા x-axis સાથે 30° બનાવે છે" જેવું કહેશે અથવા equation x − √3y + 4 = 0 આપશે (જ્યાં slope શોધવો પડશે: −a/b = −1/(−√3) = 1/√3 = tan 30°).

real-world exampleRoad sign "Gradient 1 in 10" = 10 m આગળ જતાં 1 m ચઢાણ ⟹ slope 0.1. Wheelchair ramps માટે building code મહત્તમ slope 1:12 (≈ 4.8°) રાખે છે; ઘાટ (ghat) roads પર ભારે વાહનો માટે slope ની મર્યાદા આ જ રીતે નક્કી થાય છે.

2b. Parallel અને perpendicular

કામમાં આવે: બે રેખા સમાંતર છે કે લંબ છે તે તુરંત પણ તેમના slopes પરથી નક્કી કરવા

formula — must memorize
Parallel: m₁ = m₂; Perpendicular: m₁ · m₂ = −1
General form માં: a₁b₂ = a₂b₁ (parallel), a₁a₂ + b₁b₂ = 0 (perpendicular). ઊભી-આડી રેખા માટે m₁m₂ = −1 લાગુ નથી — directly perpendicular

m₁m₂ = −1 કેમ? રેખાને 90° ફેરવો તો (run, rise) = (1, m) બને (−m, 1). નવો slope = 1/(−m) = −1/m. એટલે m₂ = −1/m₁ ⟺ m₁m₂ = −1.

બે ભૂરી રેખાઓ: slope બંનેનો ½ ⟹ parallel. લીલી રેખા: slope −2, અને (½)(−2) = −1 ⟹ perpendicular (લાલ ચોરસ = 90°)
real-world exampleRailway ના બે પાટા parallel (સરખો slope — ક્યાંય મળતા નથી); મકાનની દીવાલ અને જમીન perpendicular — કડિયો "ગુણિયો" (carpenter’s square) વડે 90° ચકાસે છે.

2c. બે રેખા વચ્ચેનો ખૂણો

કામમાં આવે: બે આપેલ રેખાઓ વચ્ચે બીજું કયું ખૂણો બને તે શોધવા (acute અને obtuse બંને)

formula — must memorize
tan θ = |(m₁ − m₂)/(1 + m₁m₂)|
| | ⟹ acute ખૂણો; obtuse = 180° − θ. 1 + m₁m₂ = 0 ⟹ θ = 90°
m₁ = 2, m₂ = 1/3: tan θ = |(2 − 1/3)/(1 + 2/3)| = 1 ⟹ θ = 45° (ખૂણો ખરેખર 63.43° − 18.43° = 45°)
Generic: તમારા m₁, m₂ મૂલ્યો મૂકો. tan(θ) = |(m₁ − m₂)/(1 + m₁m₂)|

ક્યાંથી: inclinations θ₁, θ₂ હોય તો વચ્ચેનો ખૂણો θ₁ − θ₂.
tan(θ₁ − θ₂) = (tan θ₁ − tan θ₂)/(1 + tan θ₁ tan θ₂)
— એ Trigonometry નું compound-angle સૂત્ર છે.

JEE twist: તમને બે equation આપશે (દા.ત. 2x − y + 3 = 0 અને x + 2y − 5 = 0). તમે પહેલા બંનેથી slopes શોધો (m₁ = −a₁/b₁ = 2, m₂ = −1/2), પછી ફોર્મુલા લગાડો. "45° બનાવતી રેખા" જેવા પ્રશ્નમાં tan(45°) = 1 છે, પણ θ ± નો ઉપયોગ કરીને બે રેખા મળે છે.

real-world exampleRoad junction ની design: બે રસ્તા ખૂબ નાના ખૂણે મળે તો ડ્રાઇવર ને બીજો રસ્તો દેખાતો નથી — traffic engineers નો નિયમ: junction નો ખૂણો 70° થી ઓછો ન રાખવો. બંને રસ્તાના slopes પરથી આ ખૂણો સીધો નીકળે છે.
common mistakeFormula માં | | ભૂલી જવું ⟹ "ખૂણો 45° સાથે રેખા" પ્રકારના પ્રશ્નમાં ફક્ત એક જ જવાબ આવે; ખરેખર (m − m₁)/(1 + mm₁) = ± tan θ — બંને signs લો ⟹ બે રેખાઓ.
self-checkLine √3x + y = 1 સાથે 60° બનાવતી રેખાઓના slopes? (જવાબ: √3 અને 0 — inclinations 120° ± 60°)

03Equation ના forms

શા માટે ભણવું: આપેલી માહિતી ને અનુરૂપ form પસંદ કરવાથી ગણતરી અડધી થઈ જાય છે.

point-slopeslope-intercepttwo-pointinterceptnormalparametric (distance)general + conversion

રેખા નક્કી કરવા બે સ્વતંત્ર માહિતી જોઈએ (point + દિશા, બે points, બે intercepts…). જે માહિતી આપી હોય તેને અનુરૂપ form પસંદ કરો — બધાં forms છેવટે ax + by + c = 0 જ છે.

3a. Point-slope form

કામમાં આવે: એક બિંદુ અને રેખાની દિશા આપી હોય તો તે બિંદુ માંથી પસાર થતી રેખાનું equation લખવા

formula — must memorize
y − y₁ = m(x − x₁)
(x₁, y₁) માંથી પસાર, slope m. Slope ની વ્યાખ્યા (y − y₁)/(x − x₁) = m ને સીધું ગુણ્યું છે
Point-slope: (2, 1) માંથી શરૂ, દરેક 3 એકમ જમણે 2 એકમ ઉપર (m = 2/3)

JEE twist: તમને point અને θ (angles) આપશે નહીં. બદલે બે lines આપશે અને કહેશે "આ line ને parallel રેખા (4, 5) માંથી શોધો". પ્રથમ પ્રથમ line થી slope શોધો (−a/b), પછી point-slope form: y − 5 = (−a/b)(x − 4).

real-world exampleWheelchair ramp: દરવાજા પાસે (x₁, y₁) = (0, 0.5 m) ઊંચાઈ અને code મુજબ slope 1/12 ⟹ ramp ની સપાટી y − 0.5 = −(1/12)x; જમીન (y = 0) સુધી પહોંચવા x = 6 m લાંબો ramp જોઈએ.

3b. Slope-intercept form

કામમાં આવે: y-axis પર રેખા કયા ઊંચાઈએ કાટે છે અને દિશા આપ્યા હોય તો equation લખવા

formula — must memorize
y = mx + c
c = y-intercept (x = 0 મૂકતાં). Point-slope માં (0, c) મૂકવાથી મળે
Slope-intercept: રેખા y-axis ને c = 2 પર કાપે (x = 0 મૂકતાં y = c); slope ½
real-world exampleMobile/electricity bill: fixed monthly charge (c) + યુનિટ દીઠ દર (m) × યુનિટ. Part 00 નું taxi ભાડું પણ આ જ form.

3c. Two-point form

કામમાં આવે: બે બિંદુ આપ્યા હોય તો તેમને જોડતી રેખાનું equation લખવા

formula — must memorize
(y − y₁)/(x − x₁) = (y₂ − y₁)/(x₂ − x₁)
બે points આપ્યા હોય ત્યારે — slope પહેલા ગણો, પછી point-slope
Two-point: P રેખા પર ⟺ AP નો slope = AB નો slope; અહીં (y − 4)/(x − 1) = −½ ⟹ x + 2y − 9 = 0
real-world exampleTemperature scale: પાણી 0°C = 32°F અને 100°C = 212°F પર — આ બે points પરથી two-point form: F − 32 = (180/100)(C − 0) ⟹ F = 9C/5 + 32. Thermometer calibration આ જ રીતે થાય છે.

3d. Intercept form

કામમાં આવે: બંને axes ને કટતા બિંદુ આપ્યા હોય (x-intercept, y-intercept) તો equation લખવા

formula — must memorize
x/a + y/b = 1
x-intercept a, y-intercept b (બંને ≠ 0). Origin માંથી પસાર થતી રેખા માટે આ form વાપરી ન શકાય
Intercept form: x-axis ને a = 4, y-axis ને b = 3 પર કાપે; axes સાથેના ત્રિકોણનું ક્ષેત્રફળ ½|ab| = 6
real-world exampleEconomics ની budget line: ₹600 માં ₹50 ની નોટબુક (x) અને ₹30 ની પેન (y): 50x + 30y = 600 ⟹ x/12 + y/20 = 1 — intercepts એટલે "ફક્ત એક જ વસ્તુ ખરીદો તો કેટલી".
common mistake"Equal intercepts" પ્રશ્નમાં ફક્ત x + y = a લખીને અટકવું — origin માંથી પસાર થતી રેખા (બંને intercepts 0) પણ શરત પૂરી કરે છે; JEE માં બંને જવાબ જોઈએ.

3e. Normal form

કામમાં આવે: Origin થી રેખાનું લંબ-અંતર અને તે લંબનો દિશા આપ્યા હોય તો equation લખવા (ઊભી રેખા માટે પણ)

formula — must memorize
x cos α + y sin α = p
p = origin થી રેખાનું લંબ-અંતર (p ≥ 0), α = તે લંબનો x-axis સાથે ખૂણો. ax + by + c = 0 ને ±√(a² + b²) થી ભાગો, sign એવો કે જમણી બાજુ ધન રહે
Normal form: origin થી રેખા પર લંબ (લીલો) ની લંબાઈ p = 3 અને તેનો x-axis સાથે ખૂણો α = 35° — આ બે સંખ્યા રેખાને અનન્ય રીતે નક્કી કરે છે
real-world exampleComputer vision (self-driving cars માં lane detection): Hough transform દરેક રેખાને (ρ, θ) = (p, α) — આ જ normal form — થી ઓળખે છે, કારણ કે ઊભી રેખા માટે પણ p, α finite રહે છે (slope અનંત થતો નથી).

3f. Parametric (distance) form

કામમાં આવે: આપેલ બિંદુ માંથી આપેલ ખૂણા અને આપેલ અંતર r સાથે ખસતું બિંદુ શોધવા (ઇમેજ શોધવા)

formula — must memorize
(x − x₁)/cos θ = (y − y₁)/sin θ = r
રેખા પરનો point (x₁ + r cos θ, y₁ + r sin θ); |r| = (x₁, y₁) થી અંતર. "અમુક અંતરે point" કે "રેખા curve ને કાપે ત્યાં OA·OB" પ્રકારમાં
Parametric (distance) form: A થી 30° દિશામાં r અંતરે point = (1 + r cos30°, 1 + r sin30°) — r = 2, 4 માટે ગણેલું
real-world exampleજહાજ/વિમાન નું navigation: બંદર (x₁, y₁) થી bearing θ પર કલાકના v km ઝડપે ⟹ t કલાક પછી સ્થાન (x₁ + vt cos θ, y₁ + vt sin θ) — r = vt.
exam focusCurve ને રેખા A, B, C, D માં કાપે અને OA·OB·OC·OD પૂછે ⟹ origin માંથી રેખાને parametric form (x = r cos θ, y = r sin θ) માં curve માં મૂકો: r માં polynomial મળે; product of roots = |constant/leading coefficient|. (Question bank: Practice MCQ Q5)

self-checkPoint (4, 5) માંથી પસાર, equal intercepts વાળી રેખાઓ? (જવાબ: x + y = 9 અને 5x − 4y = 0)

04Point અને line

શા માટે ભણવું: JEE અને board બંનેમાં સૌથી વધુ પુછાતા સૂત્રો આ part માં છે.

4a. Point રેખાની કઈ બાજુ?

કામમાં આવે: બિંદુ રેખાની કઈ બાજુ છે તે શોધવા (linear programming માં "feasible region" શોધવા માટે જરૂરી)

formula — must memorize
L(x₁, y₁) = ax₁ + by₁ + c નું sign
બે points માટે L નાં signs સરખા ⟹ એક જ બાજુ; વિરુદ્ધ ⟹ સામસામી બાજુ (વચ્ચેથી રેખા પસાર થાય)

કેમ: L(x, y) = 0 ફક્ત રેખા પર. એક બાજુથી બીજી બાજુ જવા રેખા ઓળંગવી પડે; L એ x, y નું સતત (continuous) function છે, એટલે sign બદલાવા L એ 0 માંથી પસાર થવું પડે — એ જ રેખા. રેખા ઓળંગ્યા વિના sign બદલાઈ શકે નહીં.

L(x, y) = x + y − 3 નું sign: લીલી બાજુ બધે ધન, બીજી બાજુ ઋણ — A, B એક જ બાજુ (બંને ધન), O સામેની બાજુ
real-world exampleLinear programming (factory નો production plan): દરેક મર્યાદા (કાચો માલ, મજૂરી) એક રેખા છે અને "માન્ય" બાજુ એક half-plane — બધી મર્યાદાઓની સાચી બાજુઓનો સામાન્ય ભાગ (feasible region) Class 12 માં આ જ sign test થી શોધાય છે.
exam focus"Point (a, a) બે રેખાઓ વચ્ચે" ⟹ બે શરતો: પહેલી રેખાની એક બાજુ અને બીજી રેખાની બીજી બાજુ. "Triangle ની અંદર" ⟹ દરેક બાજુ માટે, point અને સામેનો vertex એક જ બાજુ.

4b. Point થી રેખાનું અંતર

કામમાં આવે: બિંદુ પરથી રેખા સુધીનું લંબ-અંતર (perpendicular distance) શોધવા

formula — must memorize
d = |ax₁ + by₁ + c| / √(a² + b²)
લંબ (perpendicular) અંતર — રેખા પરના કોઈ પણ point સુધીનું સૌથી નાનું અંતર

ક્યાંથી: (a, b) એ રેખાને લંબ દિશા (normal) છે. રેખા પરના કોઈ point Q થી P સુધીનો vector QP લઈ normal ની unit દિશા પર projection લો: |a(x₁ − x_Q) + b(y₁ − y_Q)|/√(a² + b²) = |ax₁ + by₁ + c|/√(a² + b²), કારણ કે ax_Q + by_Q = −c.

P(4, 4) થી રેખા: d = |12 + 16 − 12|/5 = 3.2; લંબ નો પગ (foot) M = (2.08, 1.44) ગણેલો — d એ P થી રેખાનું સૌથી ટૂંકું અંતર
real-world exampleઘરથી સીધા રસ્તા સુધી પાણી/ગેસ ની pipeline નાખવી: સૌથી ઓછી pipe ત્યારે, જ્યારે તે રસ્તાને લંબ (perpendicular) હોય — લંબાઈ = આ d.

JEE twist: તમને line અને point આપશે અને કહેશે "ન્યૂનતમ અંતર" — હંમેશા લંબ-અંતર જ ન્યૂનતમ છે.

4c. બે સમાંતર રેખા વચ્ચે અંતર

કામમાં આવે: બે parallel lines વચ્ચેનું અંતર શોધવા (highway lanes, railway tracks)

formula — must memorize
d = |c₁ − c₂| / √(a² + b²)
ax + by + c₁ = 0 અને ax + by + c₂ = 0 — a, b બંનેમાં બરાબર સરખા કરીને જ
સમાંતર રેખાઓ વચ્ચે: d = |c₁ − c₂|/√(a² + b²) = |−12 + 2|/5 = 2 (x, y ના coefficients પહેલા સરખા કરવા)
real-world exampleHighway ની lane width: lane ની બે ધાર parallel રેખાઓ — તેમની વચ્ચેનું લંબ અંતર (ભારતમાં ~3.5 m) એ જ lane ની પહોળાઈ.
common mistake3x + 4y = 9 અને 6x + 8y = 15 વચ્ચે |9 − 15|/5 લખવું — પહેલા 6x + 8y = 15 ને 2 વડે ભાગી 3x + 4y = 7.5 કરો ⟹ d = 1.5/5 = 0.3.

4d. Foot of perpendicular અને image

કામમાં આવે: બિંદુનું રેખા પર લંબ નો પગ (foot) અને પ્રતિબિંબ (image) શોધવા

formula — must memorize
(x − x₁)/a = (y − y₁)/b = −(ax₁ + by₁ + c)/(a² + b²) [foot]; … = −2(ax₁ + by₁ + c)/(a² + b²) [image]
Foot: P થી normal (a, b) દિશામાં ખસીને રેખા પર. Image: એનાથી બમણું — foot એ P અને image નું midpoint
Image: M = foot (mirror પર લંબ નો પગ), P′ = P ની બરાબર સામે એટલા જ અંતરે — M એ PP′ નું midpoint
real-world exampleસમતલ અરીસા માં પ્રતિબિંબ અરીસાની પાછળ એટલા જ અંતરે દેખાય છે — આ "image" નું જ physics. Billiards (કે carrom) ના bank shot માં ખેલાડી પાટિયા (cushion) માં ધ્યેય (target) નું image કલ્પીને સીધું નિશાન લે છે.
exam focusOrigin થી intercept-રેખા AB (A x-axis પર, B y-axis પર) પર લંબ નો પગ C હોય તો BC : CA = OB² : OA² (right triangle માં altitude નો નિયમ). ઉદા.: 3x + y = λ ⟹ OA = λ/3, OB = λ ⟹ BC : CA = 9 : 1. (Section II MCQ Q7 — diagram ત્યાં.)
exam focusShortcut: y = x માં image (x, y) → (y, x); x + y = 0 માં (x, y) → (−y, −x); x = a માં (x, y) → (2a − x, y). Curve કે રેખાનું image ⟹ coordinates આ રીતે બદલો (Practice MCQ Q3: y = |x| નું x = 1 માં image).
self-checkPoint (3, −8) નું x + y = 0 માં image? (જવાબ: (8, −3))

05છેદબિંદુ, concurrency અને family of lines

શા માટે ભણવું: JEE માં "fixed point" અને "concurrent" પ્રશ્નો આ part ના એક જ વિચાર પર છે.

છેદબિંદુconcurrencyfamily L₁ + λL₂ = 0coefficient-pattern વાળી families

5a. બે રેખાનું છેદબિંદુ

formula — must memorize
a₁x + b₁y + c₁ = 0, a₂x + b₂y + c₂ = 0 ⟹ x = (b₁c₂ − b₂c₁)/(a₁b₂ − a₂b₁), y = (c₁a₂ − c₂a₁)/(a₁b₂ − a₂b₁)
a₁b₂ − a₂b₁ = 0 ⟹ parallel (છેદ નથી) કે એકરૂપ. વ્યવહારમાં simultaneous equations જ ઉકેલો
Cost line અને revenue line નો છેદ (8, 80) = break-even: 800 એકમથી વધારે વેચાણ પર નફો (ગણેલું)
real-world exampleBusiness break-even: cost line (fixed ખર્ચ + એકમ દીઠ ખર્ચ) અને revenue line નું છેદબિંદુ — તે પછી જ નફો શરૂ થાય.

5b. ત્રણ રેખા concurrent (એક બિંદુએ)

formula — must memorize
| a₁ b₁ c₁ ; a₂ b₂ c₂ ; a₃ b₃ c₃ | = 0
અથવા સરળ: બે રેખાનું છેદબિંદુ શોધી ત્રીજીમાં મૂકો. (Determinant 0 ત્યારે પણ થાય જ્યારે ત્રણેય parallel હોય — તે case જુદો ચકાસો)
ત્રણ રેખાઓ concurrent: બધી (1, 2) માંથી પસાર — determinant 0 (ગણેલું)
real-world exampleશહેરનું roundabout/circle (દા.ત. ઘણા રસ્તા એક જ ચોકમાં મળે) — planning map પર એ રસ્તાઓની centre-lines concurrent હોય તો જ ચોક એક બિંદુ પર બને.

5c. Family of lines: L₁ + λL₂ = 0

formula — must memorize
(a₁x + b₁y + c₁) + λ(a₂x + b₂y + c₂) = 0
λ ની દરેક કિંમતે L₁ = 0 અને L₂ = 0 ના છેદબિંદુ માંથી પસાર થતી રેખા

Mechanism: છેદબિંદુ પર L₁ = 0 અને L₂ = 0 બંને, એટલે 0 + λ·0 = 0 — λ ગમે તે હોય, આ point equation ને satisfy કરે જ. અને equation હજુ x, y માં degree 1 છે ⟹ રેખા. ઉલટું: કોઈ equation ને L₁ + λL₂ = 0 સ્વરૂપમાં લખી શકો (p, q જેવા parameter ને અલગ કરીને) તો fixed point = L₁ = 0, L₂ = 0 નું છેદ.

(x + y − 2) + λ(x − y) = 0 ના λ = −3, −1, 0, ½, 2 (અને λ → ∞ માટે x − y = 0) — બધી (1, 1) માંથી પસાર
real-world exampleLighthouse નો પ્રકાશ-કિરણ એક જ સ્થિર બિંદુ (lamp) ની આસપાસ ફરે છે — દરેક ક્ષણનું કિરણ family નું એક સભ્ય, λ એ "સમય" જેવો parameter. દરવાજો તેના hinge ની આસપાસ ફરે તેમ.
worked example
Given — (p + 2q)x + (p − 3q)y = p − q, p, q બદલાય
Need — fixed point
Method — p અને q ના પદો અલગ કરો
Calculation — p(x + y − 1) + q(2x − 3y + 1) = 0 ⟹ x + y = 1, 2x − 3y = −1 ⟹ (2/5, 3/5)
Check — 2/5 + 3/5 = 1 ✓, 4/5 − 9/5 = −1 ✓

5d. Coefficients ની pattern પરથી fixed point

formula — must memorize
a, b, c AP માં (a − 2b + c = 0) ⟹ ax + by + c = 0 હંમેશાં (1, −2) માંથી
સામાન્ય નિયમ: a, b, c વચ્ચેનો linear સંબંધ pa + qb + rc = 0 ⟹ fixed point (p/r, q/r). (a, c, b AP ⟹ 2c = a + b ⟹ (−½, −½))
a, b, c AP માં (2b = a + c) હોય તો ax + by + c = 0 હંમેશાં (1, −2) માંથી — કારણ a·1 + b·(−2) + c = a − 2b + c = 0
real-world exampleFamily diagram ઉપર જેવું જ: એક જ hinge (fixed point) ની આસપાસ ફરતો દરવાજો — "શરત" (AP) એ hinge નું સ્થાન નક્કી કરે છે. (આ box નો real-world સંબંધ 5c જેવો જ છે.)
common mistakea, b, c ની pattern માં કયો coefficient કયા સ્થાને છે (ax + by + c) તે ધ્યાન ન રાખવું: "a, b, c AP" ⟹ (1, −2), પણ "a, c, b AP" ⟹ (−½, −½). Condition ને a·x₀ + b·y₀ + c = 0 સાથે સરખાવીને x₀, y₀ વાંચો.
exam focusFamily L₁ + λL₂ = 0 (fixed point Q) નું point P થી સૌથી દૂરનું સભ્ય = Q માંથી પસાર અને QP ને લંબ; મહત્તમ અંતર = QP. (Section II Numerical Q1, Match-list Q — diagram ત્યાં.)

06Angle bisectors

શા માટે ભણવું: Incentre, reflection અને "બે રેખાથી સમાન અંતર" વાળા locus — બધામાં વપરાય છે.

bisector નું સૂત્રorigin વાળો bisectoracute/obtuse ઓળખtriangle નો internal bisector

6a. બે રેખાના angle bisectors

formula — must memorize
(a₁x + b₁y + c₁)/√(a₁² + b₁²) = ± (a₂x + b₂y + c₂)/√(a₂² + b₂²)
Bisector = બંને રેખાઓથી સમાન લંબ-અંતરે રહેલા points નો locus ⟹ બે bisectors, પરસ્પર લંબ

કેમ ±: અંતર = |L|/√(a² + b²). |L₁|/r₁ = |L₂|/r₂ ⟺ L₁/r₁ = ±L₂/r₂ — બે શક્યતાઓ ⟹ બે રેખાઓ (દરેક ખૂણાનો એક).

L₁: 3x + 4y − 12 = 0, L₂: 4x − 3y + 4 = 0; bisectors b₁: 7x + y = 8, b₂: x − 7y + 16 = 0 (લીલી dashed) — એક પરનો point Q બંને રેખાથી સરખા અંતરે (1.929 = 1.929, ગણેલું); બંને bisectors પરસ્પર લંબ
real-world exampleબે દીવાલો (કે બે વાડ) થી સરખા અંતરે બગીચાનો sprinkler મૂકવો હોય તો શક્ય જગ્યાઓ એ ખૂણાનો bisector. Physics માં અરીસા પર normal એ incident અને reflected કિરણો વચ્ચેના ખૂણાનો bisector છે (Part 09).

6b. કયો bisector કયો?

formula — must memorize
c₁, c₂ બંને ધન કરો; પછી + sign ⟹ origin ધરાવતા ખૂણાનો bisector
એ પછી a₁a₂ + b₁b₂ < 0 ⟹ (+) bisector acute ખૂણાનો; a₁a₂ + b₁b₂ > 0 ⟹ (+) bisector obtuse ખૂણાનો

શંકા હોય ત્યારે સૌથી ખાતરીવાળી રીત: bisector પરનો એક point લઈ, તેના બંને રેખાઓ સાથેના ખૂણા (Part 02 નું tan θ) ગણો — 45° થી ઓછો ⟹ acute ખૂણાનો bisector.

c₁ = 2, c₂ = 4 બંને ધન કર્યા (x + y = 4 ને −x − y + 4 લખીને); a₁a₂ + b₁b₂ = 1 > 0 ⟹ + bisector (લીલો) obtuse ખૂણાનો — દરેક bisector નો રેખા સાથેનો ખૂણો 54.2° અને 35.8° (ગણેલું)
real-world exampleઉપરના diagram જેવો જ — sprinkler ને "સાંકડા ખૂણામાં" જોઈએ કે "પહોળા ખૂણામાં", તે મુજબ બે માંથી સાચો bisector પસંદ થાય.

Triangle ની બાજુઓ રેખાઓ તરીકે આપી હોય ⟹ પહેલા slopes ગુણી જુઓ: −1 આવે તો right triangle — ગણતરી શૂન્ય
Right triangle: બંને પગ (legs) પોતે altitudes ⟹ H = 90° vertex; hypotenuse વર્તુળનો વ્યાસ ⟹ O = તેનું midpoint
real-world exampleThales નો નિયમ (semicircle માં ખૂણો 90°) — carpenter એક વર્તુળ દોરી, વ્યાસના છેડાથી કોઈ પણ point સુધી ત્રાંસી રેખાઓ દોરી 90° ખૂણો તૈયાર કરે છે.
worked example
Given — B(4, −3), C(−2, 5), orthocentre H(1, 2)
Need — A
Method — AH ⊥ BC અને BH ⊥ AC
Calculation — BC દિશા (−6, 8): (x − 1)(−6) + (y − 2)(8) = 0; BH = (−3, 5) ⊥ AC: (x + 2)(−3) + (y − 5)(5) = 0 ⟹ A = (33, 26)
Check — AH = (−32, −24) · (−6, 8) = 192 − 192 = 0 ✓

8a. Locus — ફરતા point નો માર્ગ

Locus = Latin locus (જગ્યા, સ્થાન; બહુવચન loci) — કોઈ શરતને પાળતા બધા points ની જગ્યા. (અંગ્રેજી "location", "local" એ જ મૂળ.)

formula — must memorize
Locus ની રીત: (1) ફરતા point ને (h, k) કહો (2) શરત h, k (અને parameter) માં લખો (3) parameter દૂર કરો (4) h → x, k → y
Parameter (θ, λ, m…) દૂર કરવા: sin²θ + cos²θ = 1, બે equations ભાગવા/બાદ કરવા, કે સીધું substitute
4 m ની સીડી દીવાલ અને જમીન વચ્ચે સરકે છે: તેનું મધ્યબિંદુ (લાલ) હંમેશાં origin થી 2 m — locus x² + y² = 4 નો ચોથો ભાગ (દરેક સ્થાન માટે ગણેલું)
real-world exampleસીડી દીવાલ પરથી સરકે ત્યારે તેના પર બેઠેલી બિલાડી (મધ્યબિંદુ) વર્તુળાકાર માર્ગે જાય છે — machines ના linkages (piston-crank, Klann linkage) ની design આ locus ગણતરી છે.
worked example
Given — Variable રેખાના intercepts ના વર્ગોનો સરવાળો a²
Need — origin થી લંબ ના પગનો locus
Method — પગ (h, k) હોય તો રેખા hx + ky = h² + k² (normal form)
Calculation — intercepts (h² + k²)/h, (h² + k²)/k ⟹ (h² + k²)²(1/h² + 1/k²) = a² ⟹ (x² + y²)³ = a²x²y²
Check — a = 5, intercepts 3, 4 વાળી રેખા પર ગણી ચકાસ્યું ✓

8b. Shift of origin

formula — must memorize
નવું origin (h, k): X = x − h, Y = y − k
Axes ની દિશા એ જ — ફક્ત શરૂઆતનું બિંદુ ખસ્યું. Equation માં x → X + h, y → Y + k મૂકો
Origin ને O′(2, 1) પર ખસેડો: X = x − 2, Y = y − 1 ⟹ P(5, 4) નવા axes માં (3, 3)
real-world exampleઊંચાઈ "સમુદ્ર સપાટી થી" કે "માળના ભોંયતળિયે થી" માપવી — reference point (origin) બદલવાથી દરેક ઊંચાઈમાંથી એક જ સંખ્યા બાદ થાય.

8c. Rotation of axes JEE

formula — must memorize
X = x cos θ + y sin θ, Y = −x sin θ + y cos θ; ઉલટું: x = X cos θ − Y sin θ, y = X sin θ + Y cos θ
Axes θ (anticlockwise) ફેરવો. રેખાના નવા intercepts જોઈએ ⟹ equation માં x, y ની જગ્યાએ X, Y વાળાં સ્વરૂપ મૂકો
Axes 30° ફેરવો: X = x cos30° + y sin30° = 3.598, Y = −x sin30° + y cos30° = 0.232 (ગણેલું) — point એ જ, ફક્ત "માપવાની દિશાઓ" બદલાઈ
real-world examplePhysics માં ઢાળ (inclined plane) ના પ્રશ્નોમાં axes ને ઢાળ ની દિશામાં ફેરવીએ છીએ — gravity ના components mg sin θ, mg cos θ આ જ rotation formula છે. Phone ની screen auto-rotate થાય ત્યારે software દરેક touch-point ને આ સૂત્રથી ફેરવે છે.
exam focusબે પરસ્પર લંબ રેખાઓથી અંતરોનો સરવાળો k ⟹ તે રેખાઓને જ axes લો ⟹ |x| + |y| = k: square, diagonal 2k, ક્ષેત્રફળ 2k². (Section I Q22, Section II Numerical Q2.)
common mistake"Axes θ ફેરવો" માં દિશા લખી ન હોય તો anticlockwise માનવું પ્રમાણભૂત છે; clockwise માટે θ ને −θ કરો — intercepts ના sign/ક્રમ બદલાય (Practice Multi Q5 માં publisher બંને દિશા સ્વીકારે છે).
common mistakeAxes 90° ફેરવવા ⟹ (x, y) → (y, −x); intercepts a, b હોય તો નવા p = b, q = −a — sign ભૂલવું સૌથી સામાન્ય (Practice MCQ Q9).
self-check2x + y = 2 ના axes 45° ફેરવ્યા પછી intercepts? (3X − Y = 2√2 ⟹ 2√2/3 અને −2√2)

9a. Reflection

કામમાં આવે: બિંદુ અથવા રેખાનું કોઈ line પર પ્રતિબિંબ શોધવા

કામમાં આવે: બિંદુનું અમુક રેખા પર પ્રતિબિંબ શોધવા, અથવા પાઠ ન માંગતો તે સમીકરણ સીધો વાપરવા

formula — must memorize
પરાવર્તિત કિરણ = (incidence point) ને (source નું mirror માં image) સાથે જોડતી રેખાનું extension
Angle of incidence = angle of reflection ⟺ source નું image, incidence point અને પરાવર્તિત કિરણ એક રેખા પર. ઉદા.: x = 1 પરનું કિરણ x + y = 1 થી પરાવર્તિત ⟹ y = 0
Heron નો પ્રશ્ન: A થી નદીએ જઈ B — A નું image A′ લઈ સીધી રેખા A′B; P = (4, 0) ત્યાં AP + PB = A′B ન્યૂનતમ (ગણેલું)
real-world examplePeriscope અને ગાડીના side-mirror; billiards/carrom નો bank shot — ખેલાડી ધ્યેયનું cushion માં image કલ્પીને સીધું નિશાન લે છે. GPS-free "shortest path to a river" (પાણી ભરીને ઘરે જવું) એ જ Heron નો પ્રશ્ન.

9b. Refraction-type પ્રશ્ન

formula — must memorize

Inclination (135°) માં સીધો 15° ઉમેરવો ખોટું — તે 150° (x-axis સાથે 30°) એટલે axis તરફ વળ્યું કહેવાય

real-world exampleપ્રકાશ હવા માંથી પાણીમાં જાય ત્યારે normal તરફ વળે (x-axis = સપાટી થી દૂર) — એ જ કારણે પાણીમાં ડૂબેલી લાકડી વળેલી દેખાય છે.

9c. Optimisation: min (PA + PB) અને max |PA − PB|

A, B ની સ્થિતિmin (PA + PB)max |PA − PB|
સામસામી બાજુP = AB ∩ L (સીધું)B નું image B′: P = AB′ ∩ L
એક જ બાજુA નું image A′: P = A′B ∩ LP = AB (લંબાવેલી) ∩ L; max = AB
formula — must memorize
PA + PB ≥ AB, |PA − PB| ≤ AB (triangle inequality)
સમાનતા P, A, B collinear હોય ત્યારે જ — તેથી image લઈને બંને points ને જરૂરી બાજુએ લાવો
A, B એક જ બાજુ: |PA − PB| ≤ AB (triangle inequality), સમાનતા જ્યારે P, A, B એક રેખા પર ⟹ P = AB નું extension ∩ L = (−4, 3)
real-world exampleLORAN અને ભૂકંપ-કેન્દ્ર શોધવાની રીત: બે stations પર signal પહોંચવાના સમયનો તફાવત |PA − PB| માપીને સ્થાન શોધાય છે. Matching-type પ્રશ્ન (Section II) માં આ ચારેય (min, max, ⊥) એક સાથે.
exam focus∠APB = α સ્થિર અને ક્ષેત્રફળ મહત્તમ ⟹ P એ AB ના perpendicular bisector પર (isosceles). Convex quadrilateral ABCD માટે PA + PB + PC + PD ≥ AC + BD, સમાનતા diagonals ના છેદ પર. (Practice Multi Q4, Section II Numerical Q4.)
common mistakeA, B એક જ બાજુ હોય ત્યારે min(PA + PB) માટે સીધું AB ∩ L લેવું — એ point રેખા પર "વચ્ચે" નથી આવતો; image લેવું ફરજિયાત. પહેલા sign test (Part 04) થી બાજુ ચકાસો.

10Pair of straight lines

શા માટે ભણવું: JEE માં circle/parabola ની chords અને "ખૂણો subtend કરે" પ્રશ્નોનો પાયો.

beyond board syllabus — JEE Gujarat board (NCERT) માં pair of lines નથી; JEE Main/Advanced માં નિયમિત પુછાય છે. Question bank માં ~10 પ્રશ્નો.

ax² + 2hxy + by² = 0slopes નો સરવાળો/ગુણાકારખૂણોgeneral 2nd degree: Δ = 0homogenisationproduct of perpendiculars

10a. Origin માંથી પસાર થતી બે રેખાઓ

Mechanism: (y − m₁x)(y − m₂x) = 0 ને ગુણો તો x² , xy, y² ના પદો જ આવે (દરેક પદ degree 2 — "homogeneous" = Greek homos સમાન + genos પ્રકાર, બધાં પદો સમાન degree ના). ઉલટું, ax² + 2hxy + by² = 0 ને x² થી ભાગો ⟹ m = y/x માં quadratic bm² + 2hm + a = 0 — તેનાં બે roots એ જ બે slopes (Quadratic Equations chapter નો sum/product અહીં સીધો).

formula — must memorize
m₁ + m₂ = −2h/b, m₁m₂ = a/b, tan θ = 2√(h² − ab)/|a + b|
Perpendicular ⟺ a + b = 0; coincident ⟺ h² = ab; real lines માટે h² ≥ ab. Bisectors: (x² − y²)/(a − b) = xy/h
x² + 4xy + y² = 0 ⟹ m² + 4m + 1 = 0 ⟹ L₁, L₂: m = −2 ± √3; tan θ = 2√(h² − ab)/|a + b| = 2√3/2 ⟹ θ = 60° (ગણેલું); bisectors y = ±x
real-world exampleક્રોસ થતાં બે laser beams કે કાતરના બે પાંખિયાં — બંને એક જ hinge (origin) માંથી, અને એક જ equation તેમની "જોડી" ને વર્ણવે છે. Robotics માં બે sensor-rays ને આ રીતે એક સાથે handle કરાય છે.

10b. General second-degree equation

formula — must memorize
ax² + 2hxy + by² + 2gx + 2fy + c = 0 બે રેખા ⟺ Δ = abc + 2fgh − af² − bg² − ch² = 0
Δ = | a h g ; h b f ; g f c |. (અને h² ≥ ab). λ કે k શોધવાના પ્રશ્નો: Δ = 0 ઉકેલો
λ = 2 પર x² − 3xy + 2y² + 3x − 5y + 2 = 0 એ ખરેખર બે રેખાઓ (x − 2y + 1)(x − y + 2) = 0 — છેદ (−3, −1); બંને રેખાઓના points equation માં મૂકી ચકાસ્યું
worked example
Given — x² − 3xy + λy² + 3x − 5y + 2 = 0 બે રેખા
Need — λ
Method — a = 1, h = −3/2, b = λ, g = 3/2, f = −5/2, c = 2 ⟹ Δ = 0
Calculation — Δ = 2λ + 45/4 − 25/4 − 9λ/4 − 18/4 = (2 − λ)/4 = 0 ⟹ λ = 2
Check — λ = 2: (x − 2y + 1)(x − y + 2) ગુણતાં x² − 3xy + 2y² + 3x − 5y + 2 ✓ — બે રેખાઓ, h² = 9/4 ≥ ab = 2 ✓
real-world exampleશહેરનો "+" આકારનો ચાર રસ્તો — બે રસ્તાને એક જ equation થી map software માં દર્શાવી શકાય; Δ = 0 એ ખાતરી આપે કે તે equation ખરેખર બે સીધા રસ્તા છે, વાંકો curve નહીં.

10c. Homogenisation — chord કેટલો ખૂણો બનાવે?

formula — must memorize
Curve S = 0 અને chord lx + my = n: S ના દરેક પદને (lx + my)/n ની યોગ્ય ઘાત થી ગુણી બધાં પદો degree 2 બનાવો
પરિણામ = origin થી chord ના છેડા સુધીની બે રેખાઓ. 90° ⟺ x² નો coeff + y² નો coeff = 0

કેમ ચાલે: chord પરના points પર (lx + my)/n = 1, એટલે તેનાથી ગુણવાથી curve-equation ત્યાં સાચું જ રહે; અને નવું equation homogeneous છે ⟹ origin માંથી બે રેખાઓ, જે બંને છેદબિંદુઓમાંથી પસાર થાય.

x² = 4y અને chord y = x/2 + 4: છેદ x = 1 ± √17 (ગણેલું); origin થી બંને છેડા ની રેખાઓ લંબ — homogenised x² − y² + xy/2 = 0 માં x² અને y² ના coefficients નો સરવાળો 1 − 1 = 0 ✓
real-world exampleCamera નું field of view: observer (origin) થી કોઈ વસ્તુના બે છેડા જોતાં બનતો ખૂણો — એ જ "chord subtends angle at origin". Football માં goal post ના બે થાંભલા ખેલાડીને જે ખૂણે દેખાય તે shooting angle.

10d. Product of perpendiculars અને parallel pair

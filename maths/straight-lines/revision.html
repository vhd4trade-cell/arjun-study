08Locus, shift, rotation — JEE ↗

locus steps

10Pair of straight lines — JEE ↗

ax² + 2hxy + by² = 0
m₁+m₂ = −2h/b, m₁m₂ = a/b
angle
tanθ = 2√(h²−ab)/|a+b|
⊥ ⟺ a + b = 0
general 2nd degree
Δ = abc + 2fgh − af² − bg² − ch² = 0
product of ⊥s
|ax₁²+2hx₁y₁+by₁²|/√((a−b)²+4h²)
homogenisation
curve ના નીચી ઘાતના પદ × (lx+my)/n; 90° ⟺ x² + y² coeff નો સરવાળો 0

!Common mistakes

Section formula માં m ને પહેલા point સાથે ગુણવું
Angle formula ના | | ભૂલી ફક્ત એક રેખા લખવી
∥ lines અંતરમાં a, b સરખા કર્યા વગર |c₁ − c₂|
Pair of lines માં h, g, f અડધા ન કરવા (2h = xy coeff)
Same side હોવા છતાં min(PA+PB) માં image ન લેવી
"a, b, c AP" અને "a, c, b AP" ના fixed points ગૂંચવવા
Rotation/90° માં sign: (a, b) → (b, −a)

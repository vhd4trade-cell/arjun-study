00Calculus શું છે

outcome Calculus કયા પ્રકારના problem માટે બન્યું છે, અને "differential calculus" નામ કેમ પડ્યું — એ સ્પષ્ટ થશે, જેથી આગળનું બધું procedure નહીં, logic તરીકે યાદ રહે.

નામ ક્યાંથી આવ્યું

Calculus Latin શબ્દ છે જેનો મૂળ અર્થ "નાનો પથ્થર" (small stone/pebble) — પ્રાચીન સમયમાં ગણતરી (counting) માટે નાના પથ્થર વાપરતા, એટલે "calculus" નો જૂનો અર્થ જ "ગણતરીની પદ્ધતિ" હતો. આજે calculus એટલે continuous ફેરફાર (change) ને ગણવાની ગણિત-પદ્ધતિ — કેટલી ઝડપથી કંઈક બદલાય છે (differential calculus) અને નાના-નાના ટુકડા ભેગા કરીને કુલ કેટલું થાય (integral calculus), એ બંને. આ chapter ફક્ત પહેલા ભાગ — differential calculus ના પાયા (limits + derivative) પૂરતું છે; integral calculus પછીના chapter/વર્ષમાં આવશે.

why it matters અત્યાર સુધી (algebra, trigonometry) આપણે static સંબંધો ભણ્યા — એક x માટે એક ચોક્કસ y. પણ real world માં motion, growth, rate — બધું બદલાતું રહે છે: car ની speed સમય સાથે બદલાય, વસ્તીની growth rate બદલાય, ball ની height સમય સાથે બદલાય. "આ ક્ષણે કેટલી ઝડપથી બદલાઈ રહ્યું છે" — આ પ્રશ્નનો જવાબ algebra પાસે નથી, calculus પાસે છે. Physics (motion, SHM પછીના chapters), JEE — બંનેમાં derivative સીધું અને વારંવાર વપરાય છે.
મૂળ સમસ્યા — algebra કેમ અધૂરું પડે છે Average speed કાઢવી algebra થી સહેલી છે: distance/time. પણ "બરાબર આ ક્ષણે" (instant) ની speed કાઢવી હોય તો? Time interval ને 0 તરફ લઈ જવો પડે — પણ time=0 વડે ભાગી ન શકાય (0/0 undefined). Calculus નો આખો પાયો આ જ વિરોધાભાસ ઉકેલવા માટે બન્યો: "0 ની બિલકુલ નજીક પણ 0 નહીં" એવી ચોક્કસ ગણતરી-પદ્ધતિ — જેને limit કહે છે.
real-world motivation
Situation — Car 0 થી 2 કલાકમાં 120 km જાય છે. Average speed = 120/2 = 60 km/h.
પ્રશ્ન — બરાબર t=1 કલાકે (ચોક્કસ ક્ષણે) speed કેટલી હતી? Speedometer ની સોય ત્યાં શું બતાવતી હતી?
Algebra ની મર્યાદા — speed = distance/time માટે એક time-interval જોઈએ; "એક જ ક્ષણ" પર interval ની length 0 થાય, અને 0 વડે ભાગવું અર્થહીન છે.
Calculus નો ઉકેલ — ખૂબ નાનો interval (t=1 થી t=1+h, h ખૂબ નાનો) લઈને, h ને 0 ની નજીક-નજીક (પણ ક્યારેય બરાબર 0 નહીં) લઈ જતાં, average speed શું value તરફ સ્થિર થાય છે — એ જ instant speed. આ જ "limit" નો વિચાર છે, Part 1 માં ચોક્કસ વ્યાખ્યા.
→ Next action: Part 1 થી શરૂ — "limit" નો ખ્યાલ ચોક્કસ રીતે સમજવો, કારણ કે derivative સહિત આ આખું chapter limit ના પાયા પર જ ઊભું છે.

01Limit નો ખ્યાલ

outcome આ part પછી તું કહી શકીશ કે "limit" શબ્દનો ખરો અર્થ શું છે, left-hand/right-hand limit કેમ અલગ ગણવા પડે, અને limit ક્યારે exist કરે.
why it matters Limit વગર derivative ની વ્યાખ્યા જ ન બની શકે (Part 4). Limit એ "0/0 જેવી undefined situation ને ચોક્કસ રીતે handle કરવાની" પદ્ધતિ છે — આખા calculus નું building block.
1a — શબ્દનો અર્થ 1b — Intuitive idea 1c — Formal notation 1d — Left/right-hand limit 1e — Limit ક્યારે ન મળે

1a. "Limit" શબ્દ કેમ વપરાય છે

રોજિંદી ભાષામાં "limit" એટલે એવી હદ જેની તદ્દન નજીક પહોંચી શકાય, પણ જરૂરી નથી કે ત્યાં પહોંચવું જ પડે. Math માં પણ બરાબર આ જ અર્થ છે: x ને કોઈ ચોક્કસ value (દા.ત. a) ની તદ્દન નજીક લઈ જતાં f(x) કઈ value ની તદ્દન નજીક પહોંચે છે — એ જ f(x) ની "limit" છે, પછી ભલે x=a પર f ખરેખર define હોય કે ન હોય.

1b. Intuitive idea — numerically જોઈએ

Function f(x) = (x²−1)/(x−1) લો. x=1 પર સીધું મૂકતાં 0/0 — undefined. પણ x=1 ની નજીકની values મૂકીને જોઈએ:

x0.90.990.999→1←1.0011.011.1
f(x)1.91.991.999?2.0012.012.1
must understand x=1 પર f(x) undefined હોવા છતાં, x=1 ની બંને બાજુથી નજીક જતાં f(x) સ્પષ્ટ રીતે 2 તરફ સ્થિર થાય છે. આ "2" જ f ની x→1 પરની limit છે. કારણ સ્પષ્ટ છે: (x²−1)/(x−1) = (x−1)(x+1)/(x−1) = x+1 (x≠1 માટે), અને x+1 ને x=1 ની નજીક મૂકતાં 2 મળે.
Graph પર x=1 એ "hole" (ખાલી બિંદુ) છે — છતાં બંને બાજુથી curve y=2 ની તદ્દન નજીક પહોંચે છે, એટલે limit = 2

1c. Formal notation

formula — must memorize
lim(x→a) f(x) = L
"x, a ની નજીક જાય તેમ f(x), L ની નજીક જાય છે" — x=a પર f ખરેખર define હોય એ જરૂરી નથી

1d. Left-hand limit અને Right-hand limit

x, a ની નજીક બે દિશાથી જઈ શકે — ડાબેથી (a કરતાં નાની values, x→a⁻) અને જમણેથી (a કરતાં મોટી values, x→a⁺). Limit "exist" કરે એ કહેવા માટે બંને દિશાની limit સરખી આવવી જોઈએ.

formula — must memorize
lim(x→a) f(x) exists ⟺ LHL = RHL
LHL = lim(x→a⁻)f(x), RHL = lim(x→a⁺)f(x) — બંને equal હોય તો જ limit exist કરે, અને એ common value જ limit
Step function (દા.ત. parking-fee slab, income-tax slab): x=2 પર કૂદકો (jump) — LHL=1, RHL=3, બંને અલગ એટલે limit exist નથી કરતું
real-world example
Parking ફી — 2 કલાક સુધી ₹20, 2 કલાકથી વધુ ₹35 (2 કલાક પૂરા થતાં જ કૂદકો). બરાબર 2 કલાકની "તદ્દન નજીક પહેલાં" ફી ₹20 તરફ જાય છે (LHL), "તદ્દન નજીક પછી" ₹35 તરફ (RHL) — બંને અલગ, એટલે "2 કલાકે ફી ની limit" જેવી કોઈ એક ચોક્કસ value exist નથી કરતી. આવા sudden-jump situations (income-tax slabs, courier weight-slabs) એ જ discontinuity નું રોજિંદું ઉદાહરણ છે (Part 3 માં જોડાણ).

1e. Limit ક્યારે ન મળે

કારણઉદાહરણ
LHL ≠ RHLstep/jump function (ઉપર જોયું)
Function ∞ તરફ જાયlim(x→0) 1/x² — બંને બાજુથી ∞, limit exist નથી (finite value નથી)
Function oscillate કરેlim(x→0) sin(1/x) — x→0 પાસે અનંતવાર −1 થી 1 વચ્ચે ઝૂલે છે, કોઈ એક value પર સ્થિર નથી થતું
common mistake "f(a) ની value કાઢી લીધી એટલે limit મળી ગઈ" એવું ધારી લેવું. f(a) undefined હોય તો પણ limit exist કરી શકે (ઉપરનું hole-ઉદાહરણ), અને f(a) define હોય તો પણ limit ≠ f(a) હોઈ શકે (discontinuous function, Part 3).

2. LHL અને RHL અલગ હોય તો limit exist કરે કે નહીં?

02Limit કાઢવાની રીતો

outcome આ part પછી તું direct substitution, factorization, rationalization વાપરીને limit કાઢી શકીશ, અને sinx/x જેવા standard limits યાદ રાખી શકીશ.
why it matters દર વખતે table બનાવીને numerically limit કાઢવી શક્ય નથી — parीक्षामां ઝડપી algebraic રીતો જોઈએ. મોટાભાગના limit પ્રશ્નો આ થોડી standard techniques માંથી જ કોઈ એક વાપરે છે.
2a — Direct substitution 2b — Factorization (0/0) 2c — Rationalization 2d — Standard algebraic limit 2e — sinx/x ની limit

2a. Direct substitution — પહેલો પ્રયત્ન

જો f(a) સીધું define થતું હોય (0/0 કે ∞/∞ ન આવે) તો limit = f(a) જ છે — limit ની આખી "નજીક જવાની" મહેનત ત્યારે જ જરૂરી પડે જ્યારે સીધું મૂકતાં undefined form (0/0, ∞/∞) આવે.

worked example
Given — lim(x→2) (x²+3x)
Method — x=2 સીધું મૂકીએ, undefined form નથી આવતું
Calculation — 4+6 = 10

2b. Factorization — 0/0 form માટે

Direct substitution થી 0/0 આવે તો, numerator/denominator બંનેમાં common factor (x−a) છુપાયેલો છે — એને કાઢીને cancel કરો, પછી substitution કરો.

technique
0/0 form → factor કાઢો → (x−a) cancel કરો → પછી x=a મૂકો
Part 1 ના ઉદાહરણ (x²−1)/(x−1) આ જ technique નું ઉદાહરણ હતું
worked example
Given — lim(x→3) (x²−9)/(x²−5x+6)
Need — x=3 મૂકતાં 0/0 આવે છે, factor કરવું પડશે
Method — numerator = (x−3)(x+3), denominator = (x−3)(x−2)
Calculation — (x−3) cancel: (x+3)/(x−2), x=3 મૂકતાં = 6/1 = 6
Check — table બનાવીને x=2.99, 3.01 મૂકી verify કરી શકાય, ≈6 જ આવશે

2c. Rationalization — √ હોય ત્યારે

Numerator કે denominator માં square root હોય અને 0/0 આવે, તો conjugate વડે ગુણીને root હટાવો.

worked example
Given — lim(x→0) (√(1+x) − 1)/x
Method — conjugate (√(1+x)+1) વડે numerator, denominator બંનેને ગુણો
Calculation — numerator = (1+x)−1 = x; expression = x/[x(√(1+x)+1)] = 1/(√(1+x)+1); x=0 મૂકતાં = 1/2

2d. Standard algebraic limit — must memorize

formula — must memorize
lim(x→a) (xⁿ−aⁿ)/(x−a) = n·aⁿ⁻¹
factorization ની જગ્યાએ સીધું વાપરી શકાય — power-limit પ્રશ્નોમાં ઝડપી shortcut. n કોઈપણ rational number હોઈ શકે.
આ formula કેમ સાચું — mechanism xⁿ−aⁿ = (x−a)(xⁿ⁻¹+xⁿ⁻²a+...+aⁿ⁻¹) — આ (n પદ ની) factorization દરેક n માટે સાચી છે (n=2 માટે તો ઓળખીતું x²−a²=(x−a)(x+a) જ છે). (x−a) cancel કરતાં બાકી રહે છે n પદ, અને x=a મૂકતાં દરેક પદ aⁿ⁻¹ બને છે, કુલ n×aⁿ⁻¹.
worked example
Given — lim(x→2) (x⁵−32)/(x−2)
Method — સીધું formula: n=5, a=2
Calculation — = 5×2⁴ = 5×16 = 80

2e. Standard trigonometric limit — sinx/x

x radian માં ખૂબ નાનો (0 ની નજીક) હોય ત્યારે sinx ≈ x — આ approximation ને ચોક્કસ limit-સ્વરૂપે લખીએ:

formula — must memorize
lim(x→0) (sinx)/x = 1
x radian માં જ, અને x→0 (x=0 પોતે નહીં, ત્યાં 0/0 છે)
θ=0.4 rad માટે ત્રણ areas: △OAP (sinθ ઊંચાઈ) < sector OAP (θ) < △OAT (tanθ ઊંચાઈ) — બંને બાજુ θ→0 લેતાં sinθ/θ, 1 ની વચ્ચે "squeeze" થઈને 1 જ બને છે
must understand — Squeeze (Sandwich) logic sinθ < θ < tanθ પરથી 1 < θ/sinθ < secθ મળે છે. θ→0 જતાં secθ→1, અને θ/sinθ આ બે (1 અને secθ) ની વચ્ચે "સેન્ડવિચ" થયેલું છે — બંને બાજુની limit 1 હોય તો વચ્ચેની quantity ની limit પણ ફરજિયાત 1 જ હોય. આનાથી θ/sinθ→1, એટલે sinθ/θ→1 (reciprocal).
Related standard limitsValue

real-world example
Pendulum ની motion — નાના oscillation (θ નાનો) માટે pendulum નું equation sinθ ધરાવે છે, જે ઉકેલવું અઘરું છે; sinθ≈θ (આ જ limit નું પરિણામ) વાપરીને physics simple harmonic motion જેવું સરળ સમીકરણ મેળવે છે — 12th/JEE physics ના SHM chapter માં આ approximation સીધી વપરાય છે.
worked example
Given — lim(x→0) (sin5x)/(x)
Method — sin5x/x = 5 × sin5x/(5x); હવે 5x=t મૂકતાં t→0, sin t/t → 1
Calculation — = 5×1 = 5
Clue — general pattern: lim(x→0) sin(kx)/x = k
common mistake sinx/x ની limit formula માં x ને degree માં લઈ લેવું — formula ફક્ત radian માટે સાચું છે (Trigonometry chapter ના radian ના જ કારણે — Part 1 ત્યાં જુઓ). Degree માં direct વાપરવાથી ખોટો જવાબ આવશે.
self-check 1. lim(x→1) (x³−1)/(x−1) કાઢ (formula 2d વાપરીને).
2. lim(x→0) (sin3x)/(sin5x) કાઢ. (Hint: બંનેને x વડે ભાગો)
→ Next: Limit કાઢવાની techniques આવડી ગઈ. હવે limit ને function ના "તૂટ્યા વગર" હોવા સાથે જોડીશું — continuity, Part 3.

03Continuity — તૂટ્યા વગરનું function

outcome આ part પછી તું કોઈ function કોઈ બિંદુ પર continuous છે કે નહીં — એ ત્રણ શરતો ચકાસીને કહી શકીશ.
why it matters Derivative (Part 4) ફક્ત continuous function માટે જ meaningful રીતે define થાય છે — function માં જ "તૂટ" (break/jump) હોય ત્યાં tangent line ની વાત જ અર્થહીન બની જાય. Continuity check એ calculus ના મોટાભાગના theorem ની પૂર્વશરત છે.
3a — શબ્દનો સીધો અર્થ 3b — ત્રણ શરતો 3c — Discontinuity ના પ્રકાર

3a. "Continuous" — પેન ઊંચકવી ન પડે

Continuous Latin "continuus" (અખંડ, unbroken) પરથી. Graph ને પેન ઊંચકી લીધા વગર, એક જ સ્ટ્રોકમાં દોરી શકાય — એ જ intuitive test છે. જ્યાં પેન ઊંચકવી પડે (hole, jump, કે વર્ટિકલ ઉછાળો) — ત્યાં function discontinuous છે.

3b. ચોક્કસ વ્યાખ્યા — ત્રણ શરતો

f(x), x=a પર continuous છે ⟺ નીચેની ત્રણેય શરતો સાચી હોય:

formula — must memorize
1) f(a) defined  2) lim(x→a) f(x) exists (LHL=RHL)  3) lim(x→a) f(x) = f(a)
ત્રણેય શરત — એક પણ તૂટે તો discontinuous
must understand — ત્રણેય કેમ જરૂરી શરત (1) વગર — f(a) જ ન હોય તો "value બરાબર" ની વાત જ ન થાય (hole). શરત (2) વગર — LHL≠RHL હોય તો કઈ બાજુની value ને "f(a) બરાબર" ગણવી એ જ nonsense છે (jump). શરત (3) વગર — limit exist કરે પણ f(a) એનાથી અલગ define કરેલી હોય (દા.ત. hole ને ખોટી જગ્યાએ ભરેલી) — ત્યાં પણ ગ્રાફ "તૂટેલો" જ દેખાય. ત્રણેય મળીને જ "no-lift-the-pen" ને ચોક્કસ ગણિત-ભાષામાં કેદ કરે છે.
ડાબે: hole (શરત 1 તૂટે — f(a) defined નથી). વચ્ચે: jump (શરત 2 તૂટે — LHL≠RHL). જમણે: infinite/asymptote (limit finite નથી — 1/(x−a) જેવું)
real-world example
Continuous — temperature આખા દિવસ દરમિયાન સમય સાથે — ક્યારેય અચાનક કૂદકો નથી મારતું, ધીરે ધીરે જ બદલાય છે.
Discontinuous (jump) — mobile recharge નો data balance — recharge કરો એ ક્ષણે અચાનક કૂદકો (jump) મારે છે, ધીરે ધીરે નથી વધતો.
common mistake "Function નું formula એક જ line માં લખાયેલું છે (દા.ત. polynomial)" જોઈને સીધું "continuous છે" માની લેવું ખોટું નથી (polynomial હંમેશા continuous હોય છે) — પણ piecewise (ટુકડાવાર) defined functions માં જોડાણ બિંદુ પર ત્રણેય શરત ચકાસ્યા વગર continuity ધારી ન લેવી.
self-check f(x) = x² for x≤2, f(x) = 3x for x>2 — x=2 પર continuous છે કે નહીં? (ત્રણેય શરત ચકાસ.)
→ Next: Limit + continuity બંને પાયા તૈયાર છે. હવે એમના પરથી જ derivative ની વ્યાખ્યા બાંધીશું — Part 4, chapter નું મુખ્ય target.

04Derivative — first principles

outcome આ part પછી તું derivative ની વ્યાખ્યા (limit તરીકે) લખી શકીશ, અને first principles વડે સાદા function નું derivative જાતે derive કરી શકીશ.
why it matters "Derivative" એ calculus નું સૌથી central પરિણામ છે — rate of change ને ચોક્કસ ગણિત-સંખ્યામાં ફેરવે છે. Part 6 ના બધા ઝડપી rules (power, product, quotient, chain) આ જ limit-આધારિત વ્યાખ્યામાંથી જ સાબિત થાય છે — shortcut પહેલાં પાયો સમજવો જરૂરી.
4a — "Derivative" નામ કેમ 4b — Average થી instantaneous rate 4c — ચોક્કસ વ્યાખ્યા 4d — Notation 4e — Worked derivation

4a. "Derivative" નામ ક્યાંથી આવ્યું

Derivative Latin "derivare" (de- = "થી દૂર" + rivus = "નદી/પ્રવાહ", મૂળ અર્થ "એક પ્રવાહ માંથી નવો પ્રવાહ કાઢવો") પરથી — એટલે "કોઈ વસ્તુ માંથી કાઢેલી/ઉતારેલી નવી વસ્તુ." Derivative, original function f(x) માંથી જ "કાઢેલું" (derived) એક નવું function છે — જે દરેક બિંદુએ f ના બદલાવાની ઝડપ (rate of change) બતાવે છે. મૂળ function ને "differentiate" કરવું એટલે એનો આ derived-rate-function કાઢવો — એટલે જ chapter ને "differential calculus" કહે છે.

4b. Average rate થી Instantaneous rate — Intro ના car ઉદાહરણનો ઉકેલ

Intro માં પ્રશ્ન હતો: બરાબર t=1 કલાકે car ની speed? f(t) = t=1 થી t=1+h સુધીનો average rate લખીએ:

Average rate of change
[f(a+h) − f(a)] / h
h = interval ની length. h ને 0 તરફ લઈ જતાં → instantaneous rate

h ને નાનો-નાનો કરતાં (પણ 0 નહીં) આ average rate કઈ value તરફ સ્થિર થાય છે — એ જ limit (Part 1) છે, અને એ જ "derivative."

4c. Derivative ની ચોક્કસ વ્યાખ્યા (first principles)

formula — must memorize
f'(x) = lim(h→0) [f(x+h) − f(x)] / h
x એ ચોક્કસ બિંદુ, h એ x થી કેટલું આગળ ગયા (નાનો ફેરફાર). આ limit exist કરે તો જ f, x પર "differentiable" કહેવાય
must understand — 0/0 form ફરી h=0 સીધું મૂકતાં numerator=denominator=0 — 0/0, undefined. બરાબર Part 1-2 ના જ techniques (factorization, standard limits) વાપરીને આ 0/0 ને ઉકેલવાનું છે — derivative ની વ્યાખ્યા પોતે જ એક limit-problem છે, નવો વિષય નથી.

4d. Notation

Notationવંચાયક્યાંથી આવ્યું
f'(x)"f dash x"Lagrange — compact, functions માટે common
dy/dx"dy by dx"Leibniz — y ના નાના ફેરફાર (dy), x ના નાના ફેરફાર (dx) નો ratio; physics/JEE માં સૌથી વધુ વપરાય
why "dy/dx" — નામ પાછળનું logic dy/dx કોઈ ભાગાકાર fraction નથી (એક જ symbol છે) — પણ એ Δy/Δx (average rate) ના જ h→0 limit માંથી આવે છે, એટલે ભાગાકાર જેવો દેખાવ ઈરાદાપૂર્વક રાખવામાં આવ્યો છે: "y માં અતિ-નાનો ફેરફાર, x માં અતિ-નાના ફેરફાર ભાગ્યા" — બરાબર Part 4b ના average-rate formula નું જ limiting સ્વરૂપ.

4e. Worked derivation — f(x) = x² નું derivative first principles થી

worked example
Given — f(x) = x², first principles વડે f'(x) કાઢવું
Method — વ્યાખ્યા સીધી વાપરો: f'(x) = lim(h→0) [f(x+h)−f(x)]/h
Calculation — f(x+h) = (x+h)² = x²+2xh+h². તેથી [f(x+h)−f(x)]/h = [x²+2xh+h²−x²]/h = [2xh+h²]/h = 2x+h (h≠0 એટલે cancel થાય)
Limit — lim(h→0) (2x+h) = 2x (સીધો substitution, undefined form નથી)
Answer — f'(x) = 2x
Check — x=1 પર f'(1)=2, જે Part 5 ના tangent-slope diagram સાથે બરાબર મળે છે
common mistake f(x+h) કાઢતી વખતે (x+h)² ને ખોટી રીતે x²+h² લખી દેવું — cross term 2xh ભૂલાઈ જાય છે. Binomial expansion પૂરું કરો: (x+h)² = x²+2xh+h².
self-check 1. f(x) = x³ નું derivative first principles વડે કાઢ (hint: (x+h)³ = x³+3x²h+3xh²+h³).
2. f(x) = 5 (constant) નું derivative first principles વડે કેટલું આવશે?
→ Next: f'(x) = 2x — આ સંખ્યાનો geometric અર્થ શું છે, ગ્રાફ પર શું દેખાય છે — Part 5.

05Geometric interpretation — tangent line નો slope

outcome આ part પછી તું સમજી શકીશ કે derivative ખરેખર ગ્રાફ પર શું બતાવે છે — secant line, tangent line, અને h→0 નો limiting process ગ્રાફ પર જોઈ શકીશ.
why it matters Derivative ને ફક્ત formula તરીકે યાદ રાખવાને બદલે, "ગ્રાફ પર એ શું છે" સમજવાથી curve-sketching, tangent-normal, અને physics ના motion-graphs — બધે derivative નો અર્થ સાહજિક બની જાય છે.
5a — Secant line શું 5b — h→0 એટલે secant→tangent 5c — Slope ની formula સાથે જોડાણ

5a. Secant line — બે બિંદુ જોડતી રેખા

Secant (Latin "secare" = કાપવું) — curve ને બે બિંદુએ કાપતી સીધી રેખા, Trigonometry chapter ના sec θ નામનું મૂળ પણ આ જ શબ્દ છે. f(x)=x² curve પર બિંદુ (1,1) અને (1+h, (1+h)²) જોડતી secant line નો slope બરાબર Part 4b નું જ average rate of change છે.

5b. h ને 0 તરફ લઈ જતાં — secant, tangent બને છે

h મોટો હોય ત્યારે બંને બિંદુ દૂર-દૂર છે, secant line curve ને "કાપે" છે. h ને નાનો-નાનો કરતાં બીજું બિંદુ પહેલા બિંદુની એકદમ નજીક આવતું જાય છે — અને secant line ધીરે ધીરે એ બિંદુ પર curve ને માત્ર "સ્પર્શ" (touch) કરતી tangent line તરફ સ્થિર થાય છે.

h ઘટતો જાય (1 → 0.5 → 0.25 → 0) તેમ secant line નો slope (3 → 2.5 → 2.25 → ...) 2 તરફ સ્થિર થાય છે — બરાબર f'(1)=2×1=2, Part 4e ના જવાબ સાથે મેળ
must understand Derivative f'(a) = બિંદુ (a, f(a)) આગળ curve ની tangent line નો slope. આ કોઈ અલગ વ્યાખ્યા નથી — Part 4c ની limit-વ્યાખ્યા અને "tangent slope" એ એક જ વસ્તુના બે નામ છે: [f(a+h)−f(a)]/h એ secant નો slope છે, h→0 limit લેતાં એ tangent નો slope બની જાય છે.

5c. Slope ની formula સાથે verify

worked example — verify
Given — f(x)=x², x=1 પર tangent
Slope — f'(1) = 2(1) = 2 (Part 4e થી)
Tangent line equation — point-slope: y−1 = 2(x−1) ⟹ y = 2x−1
Check — x=1 મૂકતાં y=1 ✓ (બિંદુ (1,1) પરથી પસાર થાય છે)
formula — must memorize
Tangent at (a,f(a)): y − f(a) = f'(a)(x − a)
Normal (tangent ને લંબ રેખા): slope = −1/f'(a), same point થી
real-world example
Roller-coaster ટ્રેક — કોઈપણ ક્ષણે ટ્રેકનો ઢાળ (કેટલો ઊભો છે) એ જ એ બિંદુ પરની tangent line નો slope છે — derivative curve ના દરેક બિંદુ પરનો "ત્યાં નો ઢાળ" આપે છે, આખા ટ્રેક નો એક જ ઢાળ નહીં.
self-check f(x)=x², x=2 પર tangent line નું equation કાઢ. (f'(2) પહેલા કાઢ.)
→ Next: First principles દર વખતે limit કાઢવી — ધીમું છે. હવે ઝડપી standard rules — Part 6.

06Differentiation ના standard rules

outcome આ part પછી તું power, product, quotient, chain rule વાપરીને કોઈપણ સામાન્ય function નું derivative ઝડપથી કાઢી શકીશ — first principles ના લાંબા રસ્તા વગર.
why it matters Real પ્રશ્નોમાં x³sinx કે (2x+1)/(x²+1) જેવા complex functions આવે છે — દર વખતે first principles કરવું impractical છે. આ rules, first principles માંથી જ એક વાર સાબિત થયેલા shortcuts છે.
6a — Power rule 6b — Constant multiple + sum 6c — Product rule 6d — Quotient rule 6e — Chain rule

6a. Power rule

formula — must memorize
d/dx (xⁿ) = n·xⁿ⁻¹
n કોઈપણ real number (positive, negative, fraction) માટે સાચું
આ ક્યાંથી આવ્યું Part 2d ના standard limit lim(x→a)(xⁿ−aⁿ)/(x−a) = n·aⁿ⁻¹ ને જ first-principles વ્યાખ્યામાં મૂકો: f'(a) = lim(x→a) [f(x)−f(a)]/(x−a) = lim(x→a) (xⁿ−aⁿ)/(x−a) = n·aⁿ⁻¹ — Part 4e ના x² ઉદાહરણ (n=2 ⟹ 2x) એનું જ ખાસ case છે. Power rule કોઈ નવો નિયમ નથી, Part 2 ના standard limit નું જ સીધું પરિણામ છે.
n=2 (parabola), n=3 (cubic), n=½ (√x) — ત્રણેયમાં ઢાળ સતત બદલાય છે, derivative formula આ બદલાવને દરેક બિંદુ પર ચોક્કસ સંખ્યા આપે છે
worked example
d/dx(x⁵) = 5x⁴
d/dx(1/x²) = d/dx(x⁻²) = −2x⁻³ = −2/x³
d/dx(√x) = d/dx(x^½) = ½x^(−½) = 1/(2√x)

6b. Constant multiple અને Sum/Difference rule

formula — must memorize
d/dx[c·f(x)] = c·f'(x)    d/dx[f(x)±g(x)] = f'(x)±g'(x)
Constant ને બહાર કાઢી શકાય; term-by-term differentiate કરી શકાય
real-world example
Projectile height — h(t) = 20t − 5t² (ऊंचाई, meters, t=seconds). Velocity = h'(t) = 20 − 10t — Sum/constant-multiple rule સીધો વપરાય છે, t=2s એ velocity = 0 (highest point, JEE physics standard problem).

6c. Product rule

formula — must memorize
d/dx[f(x)·g(x)] = f'(x)·g(x) + f(x)·g'(x)
"પહેલાનું derivative × બીજું, + પહેલું × બીજાનું derivative" — ક્યારેય f'·g' (બંને derivative ગુણવા) નહીં
skip — diagram justification Product rule શુદ્ધ algebraic operation (બે function નો ગુણાકાર differentiate કરવો) છે — એનું કોઈ પ્રામાણિક geometric ચિત્ર (unlike tangent-slope) સીધું નથી; area-based proof existe કરે છે પણ 11th સ્તરે જરૂરી નથી, એટલે diagram જાણી-જોઈને છોડેલ છે.
worked example
Given — y = x²·sinx
Method — f=x² (f'=2x), g=sinx (g'=cosx)
Calculation — dy/dx = 2x·sinx + x²·cosx
common mistake d/dx(f·g) = f'·g' ધારી લેવું (બંને derivative સીધા ગુણી દેવા) — ખોટું છે. Sum rule ની જેમ product rule term-by-term નથી ચાલતો; ચારેય પદ (f'g + fg') જોઈએ.

6d. Quotient rule

formula — must memorize
d/dx[f(x)/g(x)] = [f'(x)·g(x) − f(x)·g'(x)] / [g(x)]²
"નીચેવાળા વડે ઉપરવાળાનું ગુણો, ઓછું ઉપરવાળા વડે નીચેવાળાનું ગુણો, નીચેવાળાનો વર્ગ ભાગનાર" — order મહત્વનું (bાદબાકીની જગ્યા fixed)
worked example
Given — y = x/(x+1)
Method — f=x (f'=1), g=x+1 (g'=1)
Calculation — dy/dx = [1·(x+1) − x·1]/(x+1)² = [x+1−x]/(x+1)² = 1/(x+1)²
real-world example
Average cost function — economics/optimization માં Cost(x)/x (per-unit cost) જેવા ratio-functions નું derivative optimum production-level શોધવા quotient rule વાપરે છે — JEE Main ના optimization પ્રશ્નોમાં આ pattern વારંવાર આવે છે.
common mistake Quotient rule ના numerator માં ક્રમ ઊંધો કરવો (f·g' − f'·g લખવું) — sign ખોટું આવશે. "પહેલા f', પછી g'" ક્રમ ફિક્સ યાદ રાખવો.

6e. Chain rule — function ની અંદર function

જ્યારે y, u નું function હોય અને u પોતે x નું function હોય (દા.ત. y=sin(x²) — બહાર sin, અંદર x²) ત્યારે derivative "સ્તર-દર-સ્તર" (layer by layer) લેવાય છે.

formula — must memorize
dy/dx = dy/du × du/dx
"બહારના function નું derivative (અંદરવાળું એમ જ રાખીને) × અંદરના function નું derivative"
must understand — નામ "chain" કેમ y, u સાથે અને u, x સાથે "સાંકળ" (chain) ની જેમ જોડાયેલા છે — y ને x સાથે સીધો સંબંધ નથી, u ના મારફતે જ છે. dy/du × du/dx માં du કપાઈ જાય (Leibniz notation ના fraction જેવા દેખાવનું જ કારણ — Part 4d) અને dy/dx જ બાકી રહે, બરાબર જેમ સાંકળના વચલા કડા બંને છેડાના કડાને જોડે છે.
x → u → y ની "સાંકળ": u ના મારફતે x, y ને અસર કરે છે — dy/dx બંને વચલા-કડાના derivatives નો ગુણાકાર
worked example
Given — y = sin(x²)
Method — u = x² (અંદરનું), y = sinu (બહારનું). du/dx = 2x, dy/du = cosu = cos(x²)
Calculation — dy/dx = cos(x²) × 2x = 2x·cos(x²)
real-world example
Ripple ની area — તળાવમાં પથ્થર પડતાં ripple નો radius r, time t સાથે વધે (r=f(t)); ripple ની area A=πr² છે, r સાથે બદલાય. "Area, time સાથે કેટલી ઝડપથી વધે છે" (dA/dt) કાઢવા chain rule જોઈએ: dA/dt = dA/dr × dr/dt — બરાબર related-rates નો સૌથી common ઉદાહરણ.
common mistake y=sin(x²) ને differentiate કરતાં ફક્ત cos(x²) લખી દેવું, ×2x (du/dx) ભૂલી જવું — chain rule નો બીજો ભાગ (અંદરના function નું પોતાનું derivative) છોડી દેવો એ સૌથી common error છે.
self-check 1. y = (3x+1)⁵ નું dy/dx કાઢ.
2. y = x²cosx નું dy/dx કાઢ (product rule).
3. y = sinx/x² નું dy/dx કાઢ (quotient rule).

Implicit differentiation — y ને અલગ કર્યા વગર dy/dx

વર્તુળ x² + y² = 25 equal-scale axes પર ગણેલું; (3, 4) પર slope −3/4 નો tangent — ત્રિજ્યાને લંબ (slope 4/3 × −3/4 = −1).
formula — must memorize
F(x, y) = 0 ⟹ dy/dx = −(∂F/∂x)/(∂F/∂y)
બંને બાજુ x પ્રત્યે differentiate કરો; y નું દરેક પદ chain rule થી y′ આપે: d(y²)/dx = 2y·y′, d(xy)/dx = y + x·y′. પછી y′ વાળા પદો એક બાજુ ભેગા કરો. Real-world: "related rates" — દીવાલ સાથે સરકતી નિસરણી (x² + y² = L²) માં ઉપરનો છેડો કેટલી ઝડપે નીચે આવે તે આ જ રીતે મળે.
worked example
Given — x² + xy + y² = 7, બિંદુ (1, 2)
Need — dy/dx
Method — implicit: 2x + (y + xy′) + 2yy′ = 0
Calculation — y′ = −(2x + y)/(x + 2y) = −4/5
Check — formula −F_x/F_y = −(2x + y)/(x + 2y) સમાન ✓
common mistaked(y²)/dx = 2y લખવું (y′ ભૂલવું), કે xy ના derivative માં product rule ન વાપરવો.

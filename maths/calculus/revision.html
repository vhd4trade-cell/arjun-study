00Calculus શું છે↗

01Limit↗

notation
lim(x→a) f(x) = L
x=a પર f define ન હોય તો પણ limit exist કરી શકે
existence
exists ⟺ LHL = RHL
limit ન મળે
LHL≠RHL / →∞ / oscillate
example
parking-fee slab jump
2 kલાક પર LHL=20, RHL=35

02Limit techniques↗

direct sub
undefined form ન આવે તો f(a) જ
0/0 → factorize
common factor (x−a) cancel કરો
√ હોય → rationalize
conjugate વડે ગુણો
standard algebraic
lim(x→a)(xⁿ−aⁿ)/(x−a) = n·aⁿ⁻¹
standard trig
lim(x→0) sinx/x = 1 (radian!)
related
tanx/x→1, (1−cosx)/x→0, (1−cosx)/x²→½

03Continuity↗

3 conditions — all required
f(a) defined · lim exists · lim = f(a)
breaks
hole / jump / infinite (asymptote)

04Derivative — first principles↗

definition — must memorize
f'(x) = lim(h→0) [f(x+h)−f(x)]/h
notation
f'(x) (Lagrange)  =  dy/dx (Leibniz)
worked — f(x)=x²
f'(x) = 2x
(x+h)²−x²)/h = 2x+h → 2x

05Geometric meaning↗

tangent at (a,f(a))
y − f(a) = f'(a)(x − a)
normal
slope = −1/f'(a), same point

06Differentiation rules↗

power
d/dx(xⁿ) = n·xⁿ⁻¹
constant / sum
(cf)'=cf'   (f±g)'=f'±g'
product
(fg)' = f'g + fg'
quotient
(f/g)' = (f'g − fg')/g²
chain
dy/dx = dy/du × du/dx  (y=f(u), u=g(x))
implicit
y′ = −F_x/F_y
d(y²)/dx = 2yy′, d(xy)/dx = y + xy′
પહેલાં સાદું કરો
(x − y)³ = −1 ⟹ y = x + 1 (factorise પછી differentiate)

!Common mistakes

sinx/x limit formula degree માં નહીં — radian જ
(x+h)² ને x²+h² ન લખો — cross term 2xh ભૂલશો નહીં
(fg)' ≠ f'g' — product rule ના ચારેય પદ જોઈએ
chain rule માં ×du/dx (અંદરના function નું derivative) ભૂલશો નહીં
quotient rule numerator ક્રમ: f'g − fg' (ઊંધું નહીં)

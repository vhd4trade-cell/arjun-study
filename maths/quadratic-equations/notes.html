00Quadratic equation શું છે

outcome Quadratic equation ના roots ને directly શોધ્યા વગર પણ, roots વિશેની condition (sum, product, nature, location, common root) જવાબ આપી શકાય — એ આ chapter નું core skill છે.

વ્યાખ્યા

Quadratic equation એટલે ax² + bx + c = 0 (જ્યાં a≠0). Degree 2 ની polynomial equation — એટલે મહત્તમ 2 roots (real અથવા complex) હોય છે. અહીં a,b,c ને coefficients કહેવાય — Latin co- (=સાથે) + efficere (=બનાવવું, અસર કરવું) પરથી — એટલે "x ની સાથે ભેગા મળીને term ની કિંમત બનાવતી સંખ્યા" (દા.ત. bx માં b, x ની સાથે "સાથે-કામ" કરે છે).

"Quadratic" શબ્દ નો પાયો "Quadratic" Latin શબ્દ quadratus (=squared, ચોરસ) પરથી આવે છે, અને quadr- (=ચાર) સાથે જોડાયેલો છે — ચોરસ ને ચાર બાજુ હોય છે, અને x² ("x નો square") ભૂમિતિ રીતે ચોરસ ના area જેવું છે (બાજુ=x હોય તો area=x²). એટલે "quadratic equation" = "x² ધરાવતું equation" = "squaring સાથે સંકળાયેલું equation". આ જ મૂળ શબ્દ "quadrilateral" (ચાર બાજુ વાળો આકાર), "quadrant" (વર્તુળ નો ચોથો ભાગ) માં પણ દેખાય છે — બધે "ચાર/square" નો concept common છે.
બાજુ x મોટી થાય એટલે area (x²) બાજુ ના square (વર્ગ) જેટલી ઝડપથી વધે — આ જ "quadratic growth" નો પાયો
"root" શબ્દ નો પાયો — "solution" કેમ નહીં? Root ની વ્યાખ્યા: r એ equation નો root છે ⟺ x ની જગ્યાએ r મૂકતાં equation સાચું પડે (એટલે ax²+bx+c માં x=r મૂકતાં કિંમત 0 થાય). આ કોઈપણ equation ના "solution" ની general વ્યાખ્યા જ છે — તો પછી ખાસ "root" કેમ?

કારણ — factor theorem: (x − r) એ એવું expression છે જે x ના બદલાવા સાથે બદલાય છે, અને ફક્ત x=r પર જ 0 થાય છે (બીજા કોઈ x પર નહીં — r એક fixed constant છે, x=r ના મૂક્યે (x−r)≠0). આ જ કારણથી "r" ને બદલે "(x−r)" લખાય છે — ફક્ત "r" તો કંઈ 0 નથી થતું, પણ "(x−r)" x ના function તરીકે બરાબર x=r પર 0 થાય છે.

Zero-product property (ખરું કારણ multiply કરવાથી equation પાછું મળે છે): બે સંખ્યાઓ નો ગુણાકાર 0 થાય ⟺ ઓછામાં ઓછી એક સંખ્યા 0 હોય. એટલે (x−r₁)(x−r₂) = 0 ⟺ x−r₁=0 અથવા x−r₂=0 ⟺ x=r₁ અથવા x=r₂. આ કોઈ metaphor નથી — આ જ ખરું ગણિત છે જે બતાવે છે કે factored form ના roots બરાબર r₁,r₂ જ છે, બીજું કંઈ નહીં.
(x−2) પોતે x=2 પર 0 થાય, (x−5) પોતે x=5 પર 0 થાય — બંને ને multiply કરેલો parabola બંને જ points પર x-axis ને કાપે છે, બીજે ક્યાંય નહીં
Product 0 થાય ⟺ ઓછામાં ઓછું એક factor 0 હોય — આ mechanism જ roots ને factors સાથે જોડે છે
worked example — actual numbers, r₁,r₂ ને બદલે
ધારો roots 2 અને 5 છે. Factor form: (x−2)(x−5)
Check x=2: (2−2)(2−5) = (0)(−3) = 0 ✓ — પહેલું factor 0 થયું, product 0
Check x=5: (5−2)(5−5) = (3)(0) = 0 ✓ — બીજું factor 0 થયું, product 0
Check x=1 (કોઈ root નહીં): (1−2)(1−5) = (−1)(−4) = 4 ≠ 0 — બંને factors non-zero, product પણ non-zero
Expand: (x−2)(x−5) = x² −5x −2x +10 = x² −7x +10 — એટલે sum=2+5=7 (=−b/a=7/1 ✓), product=2×5=10 (=c/a=10/1 ✓)
Roots = જ્યાં curve x-axis ને છેદે છે. a>0 → cup ઉપર તરફ ખૂલે, a<0 → નીચે તરફ
why it matters Quadratic equations physics ના projectile motion, roots-based inequality problems, coordinate geometry (circle-line intersection), અને JEE ના લગભગ દરેક chapter (complex numbers, sequences, calculus ના maxima-minima) માં પાછળથી embedded તરીકે આવે છે. "Roots શોધવા" કરતાં "roots વિશે reasoning કરવું" — એ જ આ chapter નું JEE-level core છે.
real-world example ક્રિકેટ કે ફૂટબોલમાં ઊંચે ફેંકેલા બોલ ની height-vs-time curve બરાબર આ જ parabola છે (h=−½gt²+u·t+h₀ સ્વરૂપ, જે ax²+bx+c જ છે). Roots = બોલ ક્યારે જમીન અડકે (h=0) — બે roots માંથી એક negative time (ભૂતકાળ, discard) અને એક positive time (actual landing) હોય છે.
Physical time માત્ર t≥0 માટે meaningful — t=−1 root ગણિત રીતે સાચો છે પણ ભૂતકાળ હોવાથી discard, t=4 એ actual landing
10th થી shift 10th માં આપણે માત્ર actual roots શોધતા (factoring/formula). 11th-JEE માં પ્રશ્નો મોટેભાગે roots ને directly શોધ્યા વગર — sum/product/discriminant ના relations વાપરીને — પૂછાય છે. Roots શોધવા એ છેલ્લો resort છે, પહેલો નહીં.

01Roots શોધવા

શા માટે ભણવું: આગળના બધા parts આ પાયા પર ઊભા છે — discriminant D એ આખા chapter ની "master quantity" છે.

formula — quadratic formula
x = [−b ± √(b²−4ac)] / 2a
ax²+bx+c=0 ના બંને roots — factoring ન થાય ત્યારે પણ કામ કરે
બંને roots vertex (−b/2a) ની આસપાસ સપ્રમાણ છે — ±√D/2a જેટલા દૂર
real-world example Satellite dish કે car headlight નું parabolic mirror આ જ curve નું 3D version છે — light/signal ને એક focus point પર ભેગા કરવા. Engineers ne mirror ના edges ક્યાં cut કરવા (એટલે "roots" જેવું boundary) એ પણ આ જ પ્રકારના equation થી નક્કી થાય છે.
formula — discriminant
D = b² − 4ac
roots ની nature (real/complex, equal/distinct, rational/irrational) — D જ decide કરે છે
"Discriminant" શબ્દ નો પાયો Latin discriminare = "અલગ પાડવું, વચ્ચે ભેદ પારખવો" (discrimination શબ્દ પણ આ જ મૂળ માંથી — "ભેદ પારખવો"). D ને "discriminant" કહેવાય કારણ કે એ એકલો number રહીને પણ roots ના ત્રણ સંભવિત "પ્રકાર" (real-distinct, real-equal, complex) ને પારખી/અલગ પાડી આપે છે — roots શોધ્યા વગર જ.
worked example
Q. 2x² − 5x + 2 = 0 ના roots શોધો.
Factoring: 2x² −4x −x +2 = 2x(x−2) −1(x−2) = (2x−1)(x−2) = 0
Roots: x = 1/2, 2
Check via D: D = 25−16 = 9 = 3² (perfect square) → rational roots ✓ consistent
common mistake Quadratic formula માં −b નું sign ભૂલવું, અથવા 2a ને બદલે a થી ભાગવું. લખતી વખતે formula આખું એકસાથે યાદ રાખો, ટુકડે ટુકડે નહીં.
self-check x² − 6x + 9 = 0 ના roots શોધો, અને D ની કિંમત ચકાસો — D=0 નો શું અર્થ થાય?

02Nature of roots

શા માટે ભણવું: JEE માં "roots real છે?" "roots equal છે?" પ્રકારના પ્રશ્નો roots શોધ્યા વગર, ફક્ત D પરથી જ પુછાય છે.

D ની કિંમતRoots ની nature
D > 0બે distinct real roots
D = 0બે equal (repeated) real roots = −b/2a
D < 0બે conjugate complex roots (p±iq સ્વરૂપ)
D > 0, perfect square
(a,b,c rational)		બે rational roots
D > 0, non-perfect-square
(a,b,c rational)		બે conjugate irrational (surd) roots
D એ literally "curve x-axis ને કેટલી વાર અડકે છે" ગણે છે — 2 વાર, 1 વાર (touch), કે 0 વાર
real-world example રસ્તા પર બોલ ફેંક્યો હોય (D>0: બે વાર જમીન ને અડકે — ફેંક્યો ત્યારે અને પડ્યો ત્યારે, પણ physically માત્ર landing વાળો root જ meaningful). Cricket માં બોલ બરાબર ફિલ્ડર ના હાથ ની height પર જ પહોંચે (D=0: એક જ point પર "just touch"). બોલ ક્યારેય જમીન ને ના અડકે એવી ઊંચાઈ પર જ રહે (D<0: અશક્ય physically, પણ ગણિત રીતે "કોઈ real landing time નથી" — complex roots).
high exam probability a,b,c rational હોય અને એક root p+√q (q non-perfect-square) હોય, તો બીજો root આપોઆપ p−√q જ હોવો જોઈએ — surd roots હંમેશા conjugate pair માં આવે છે. આ property ઘણી વાર "બીજો root શોધો" પ્રકારના પ્રશ્નમાં સીધી વપરાય છે.
common mistake "D≥0 એટલે roots real" બોલતી વખતે a,b,c real હોવા જરૂરી છે એ ભૂલી જવાય છે — a,b,c complex હોય તો આ rule લાગુ નથી પડતું (JEE Advance level પર આ point ક્યારેક ટ્રેપ તરીકે વપરાય છે).
formula — real-coefficient equation, one root given as non-real
a,b,c ∈ ℝ અને એક root p+iq (q≠0) આપેલ હોય ⟹ બીજો root p−iq (conjugate) જ હોય
આ પરથી S=α+β=2p, P=αβ=p²+q² સીધા મળી જાય — equation ફરી બનાવવા કે α−β, α−constant જેવી expressions શોધવા વાપરો
self-check x²−(3+2i)x+(1+3i)=0 — શું આ equation ના roots conjugate pair માં હશે? (Hint: coefficients real છે?)

03Sum, product અને roots બનાવવા

શા માટે ભણવું: આ chapter નું સૌથી વધુ વપરાતું tool — "roots શોધ્યા વગર roots વિશે બોલવું".

formula — sum & product of roots
α + β = −b/a , αβ = c/a
ax²+bx+c=0 ના roots α,β માટે — direct coefficients પરથી
formula — roots પરથી equation બનાવવી
x² − (α+β)x + αβ = 0
roots ની sum અને product ખબર હોય તો equation reconstruct કરવા
Sum,Product ⟺ Rectangle ના sides — ક્લાસિક "sum-product આપ્યું, sides શોધો" problem નું ગણિત આ જ છે
real-world example "એક ખેતરની ફરતે 40m ની વાડ છે (perimeter fixed), અને area 96 m² છે — sides શોધો" પ્રકારના practical problems બરાબર આ formula વાપરે છે: sum=perimeter/2, product=area, પછી x²−(sum)x+product=0 solve કરો.
worked example
Q. 3x²−5x+2=0 ના roots α,β હોય, તો α+β અને αβ શોધો, અને 2α,2β ને roots ધરાવતું equation બનાવો.
α+β = 5/3, αβ = 2/3
નવા roots ની sum = 2α+2β = 2(5/3) = 10/3, product = 4αβ = 8/3
નવું equation: x² − (10/3)x + 8/3 = 0 ⟹ 3x² −10x +8 = 0
common mistake α+β = −b/a માં "−" sign ભૂલી જવો — ખાસ કરીને b positive હોય ત્યારે "sum = b/a" લખાઈ જાય છે, જે ખોટું છે.
self-check x²+7x+12=0 ના roots α,β હોય, તો 1/α + 1/β શોધો (roots શોધ્યા વગર).

04Symmetric functions of roots

શા માટે ભણવું: JEE માં α²+β², α³+β³, α⁴+β⁴ પ્રકારના expressions ડાયરેક્ટ પુછાય છે — બધા α+β અને αβ પરથી જ નીકળે છે.

formula — symmetric function building blocks
α²+β² = (α+β)² − 2αβ
α³+β³ = (α+β)³ − 3αβ(α+β)
α⁴+β⁴ = (α²+β²)² − 2(αβ)²
α−β = ±√D / a (D = b²−4ac)
બધા જ higher symmetric sums, sum(S) અને product(P) ના combination તરીકે લખી શકાય
Symmetric quantities roots ના "combined" behavior બતાવે, asymmetric quantities roots ના "relative position" (distance/order) બતાવે
real-world example બે rockets/particles ના position roots α,β તરીકે model કરીએ તો α+β,αβ (symmetric) એમનું center-of-mass જેવું combined behavior આપે, જ્યારે α−β (asymmetric) એ બે વચ્ચેનું actual separation/gap આપે — physics ના two-body problems માં આ જ split વારંવાર વપરાય છે.
must understand કોઈપણ symmetric function of α,β (એટલે કે α અને β ને અંદરોઅંદર બદલવાથી value ના બદલાય — દા.ત. α²β+αβ², α³+β³) હંમેશા S=α+β અને P=αβ ના પદોમાં લખી શકાય. Asymmetric function (દા.ત. α−β, α²−β²) directly ના લખાય — ત્યાં ±√D/a જેવું root-sign વાળું પદ આવે છે.
worked example
Q. x²−px+q=0 ના roots α,β હોય, તો α³+β³ ને p,q માં લખો.
S=α+β=p, P=αβ=q
α³+β³ = S³−3PS = p³−3pq
common mistake α³+β³ = (α+β)(α²−αβ+β²) ફોર્મ્યુલા સાચી છે, પણ ત્યાં α²−αβ+β² ને ફરીથી (α²+β²)−αβ = (S²−2P)−P = S²−3P લખવાનું ભૂલી જવાય છે — છેલ્લે P,S માં convert કરવાનું જ ચૂકી જવાય.
self-check x²−4x+1=0 ના roots α,β હોય, તો α⁴+β⁴ શોધો.

05Common roots

શા માટે ભણવું: બે અલગ quadratic equations ને link કરતો, JEE-favorite pattern.

5a. બંને roots common

formula
a₁/a₂ = b₁/b₂ = c₁/c₂
a₁x²+b₁x+c₁=0 અને a₂x²+b₂x+c₂=0 ના બંને roots common હોય ત્યારે જ — બંને equations proportional (essentially same) છે

5b. માત્ર એક root common

ધારો કે α common root છે. બંને equations માંથી α² ને eliminate કરીને α ને a,b,c ના પદોમાં cross-multiplication થી શોધાય છે:

formula — one common root ની condition
(c₁a₂ − c₂a₁)² = (a₁b₂ − a₂b₁)(b₁c₂ − b₂c₁)
common root α = (c₁a₂−c₂a₁)/(a₁b₂−a₂b₁) = (b₁c₂−b₂c₁)/(c₁a₂−c₂a₁)
worked example
Q. x²−6x+5=0 અને x²−3x+a=0 નું એક common root હોય, તો a ના શક્ય values શોધો.
પ્રથમ equation ના roots: 1, 5
x=1 common → 1−3+a=0 → a=2
x=5 common → 25−15+a=0 → a=−10
Answer: a = 2 અથવા −10
common mistake જ્યારે એક equation ના roots સહેલાઈથી factoring થી મળે (ઉપરના example જેમ), ત્યારે સીધો cross-multiplication formula વાપરવો — actually direct substitution (દરેક root ને બીજા equation માં મૂકવો) સહેલું અને ઝડપી છે. Formula ત્યારે જ વાપરો જ્યારે roots સીધા ના મળે.
self-check x²+ax+b=0 અને x²+bx+a=0 (a≠b) નું એક common root હોય, તો બતાવો કે એ common root = 1, અને a+b+1=0.

06Location of roots

શા માટે ભણવું: "roots બંને k થી મોટા છે" કે "roots (k1,k2) વચ્ચે છે" પ્રકારના પ્રશ્નો parabola ના graph પરથી સીધા solve થાય છે — algebra કરતાં ઝડપી.

must understand — core idea ax²+bx+c=0 નું graph (y=ax²+bx+c) એક parabola છે — Greek para (=બાજુમાં) + bolē (=ફેંકવું, throw — "ballistic" શબ્દ પણ આ જ મૂળ) પરથી — શબ્દનો ઇતિહાસ સીધો "throw/projectile" સાથે જોડાયેલો છે, અને એ જ curve ફેંકેલા બોલ નો રસ્તો પણ છે (Part 00 નું real-world example યાદ કરો). a>0 હોય તો parabola ઉપર તરફ ખૂલે છે (U shape), a<0 હોય તો નીચે તરફ (∩ shape). કોઈપણ point k પર parabola ની height, એટલે f(k) = ak²+bk+c, ના sign પરથી k, roots ની ડાબી બાજુ છે, વચ્ચે છે, કે જમણી બાજુ છે — એ ખબર પડે છે.
a>0: k roots ની બહાર → f(k) same sign as a (positive) · k roots ની વચ્ચે → f(k) opposite sign (negative)
ConditionRequirements (a>0 ધારીને)
બંને roots > kD≥0, a·f(k)>0, −b/2a > k
બંને roots < kD≥0, a·f(k)>0, −b/2a < k
k, roots ની વચ્ચેa·f(k) < 0
roots ∈ (k₁,k₂)D≥0, a·f(k₁)>0, a·f(k₂)>0, k₁ < −b/2a < k₂
high exam probability "a·f(k)" લખવાનું કારણ: a ના sign પ્રમાણે parabola ની દિશા બદલાય છે, એટલે માત્ર f(k) નું sign પૂરતું નથી — a વડે multiply કરીને sign ને a=positive ના case જેવું "normalize" કરવામાં આવે છે. આ ટ્રીક ભૂલવાથી a<0 ના cases માં જવાબ ઊંધો આવે છે.
self-check x²−(k+1)x+k=0 ના બંને roots 2 થી મોટા હોય એવા k ના values ની range શોધો.

6a. Vertex ની value, અને graph પરથી a,b,c ના signs

"Vertex" શબ્દ નો પાયો Latin vertere = "ફેરવવું, વળવું" (convert, revert, universe જેવા શબ્દો પણ આ જ મૂળ માંથી). Vertex = curve જ્યાં "વળે" છે — નીચે જતી દિશા ત્યાં જ ઉપર જવાની દિશામાં ફરે છે (અથવા ઊંધું). એ જ turning point છે.
formula — vertex point
Vertex = ( −b/2a , c − b²/4a )
Parabola નું સૌથી નીચું (a>0) અથવા સૌથી ઊંચું (a<0) point — x-coordinate −b/2a, અને ત્યાંની height c−b²/4a
a<0 parabola નો vertex = curve નું સૌથી ઊંચું point (maximum value)
real-world example ઊંચે ફેંકેલા બોલ ની max height, કે કોઈ business ના profit=revenue−cost ને x (quantity) ના quadratic તરીકે લખો તો profit સૌથી વધારે ક્યારે થાય — બંને પ્રશ્નોનો જવાબ આ જ vertex formula આપે છે. Vertex ની x-coordinate = "કેટલા units બનાવવા" કે "કેટલો સમય" (optimal input), y-coordinate = "મહત્તમ height/profit" (optimal output).
worked example
Q. y=−(x−1)(x−3) ના સૌથી ઊંચા point અને y=x(x−4) ના સૌથી નીચા point વચ્ચેનું distance શોધો.
y=−(x−1)(x−3)=−x²+4x−3, vertex x=2, height=−4+8−3=1 → point (2,1)
y=x(x−4)=x²−4x, vertex x=2, height=4−8=−4 → point (2,−4)
બંને points નું x same (2) → distance = |1−(−4)| = 5
must understand — graph પરથી a,b,c reading Parabola નું picture આપ્યું હોય (roots ક્યાં છે, ઉપર/નીચે ખૂલે છે, y-axis ને ક્યાં કાપે છે) ત્યારે: a નું sign = parabola ઉપર(+)/નીચે(−) ખૂલે છે એ પરથી; c = f(0) = graph y-axis ને ક્યાં કાપે છે એ પરથી (ઉપર્ + , નીચે −); b નું sign vertex ની x-position (−b/2a) ના sign પરથી નીકળે — a અને vertex ની બાજુ (ડાબે/જમણે) બંને ભેગા વાપરવા પડે.
common mistake Vertex b=0 પર y-axis પર જ હોય એવો special case (સममित parabola) — ત્યારે roots પણ origin ની આસપાસ symmetric (±k સ્વરૂપ) હોય છે, અને "sum of roots=0" સીધું vertex ના position પરથી જ ખબર પડી જાય, calculation કરવાની જરૂર નથી.

07Quadratic inequalities

શા માટે ભણવું: ax²+bx+c >,<,≥,≤ 0 form ના પ્રશ્નો — roots ના આધારે number-line પર sign મૂકીને solve થાય છે.

must understand — wavy curve method 1. Roots α ≤ β શોધો (D≥0 ધારીને). 2. Number line પર α, β mark કરો. 3. a>0 હોય તો roots ની બહાર (x<α અથવા x>β) expression positive, વચ્ચે (α<x<β) negative. a<0 હોય તો ઊંધું.
worked example
Q. x²−5x+6 < 0 solve કરો.
Roots: (x−2)(x−3)=0 → x=2,3. a=1>0.
Roots ની વચ્ચે expression negative → 2 < x < 3
common mistake D<0 હોય (roots complex) ત્યારે inequality solve કરવા roots ની જરૂર જ નથી — a>0 હોય તો expression બધા real x માટે positive (ax²+bx+c>0 ∀x), a<0 હોય તો બધા x માટે negative. આ shortcut ભૂલી જવાથી વિદ્યાર્થીઓ ખોટી રીતે "no solution" કે ખોટો range લખે છે.
self-check x²+x+1 > 0 ના બધા real x માટે સાચું છે કે નહીં? D અને a બંને ચકાસીને જવાબ આપો.

7a. Parameter-based inequality — "for all x" / "for at least one x"

must understand — બે અલગ પ્રશ્ન-પ્રકાર "ax²+bx+c > 0 solve કરો" (x માટે) અલગ છે "ax²+bx+c > 0 બધા x માટે સાચું રહે એવા parameter (દા.ત. a) ના values શોધો" કરતાં. બીજા પ્રકારમાં x એ variable નથી — parameter (a,p,k...) એ unknown છે, અને condition D<0 (કે D≤0) + a નું sign વાપરવાનું છે, x ની કોઈ range નહીં.
Condition પરRequirement
ax²+bx+c > 0 ∀x∈Ra > 0 અને D < 0
ax²+bx+c < 0 ∀x∈Ra < 0 અને D < 0
ax²+bx+c < 0 for at least one real xa < 0 અથવા D > 0 (a>0 હોય તો roots ની વચ્ચે negative મળે જ)
D<0 = curve ક્યારેય x-axis ને અડતો નથી, એટલે એક જ sign સર્વત્ર જળવાય
real-world example Engineering design માં "structure પર stress હંમેશા ચોક્કસ safe limit કરતાં ઓછો રહેવો જોઈએ, ગમે તે load (x) માટે" — આવી condition ઘણી વાર ax²+bx+c<0 ∀x ના રૂપમાં આવે છે. Design parameter (a,b,c) ને એ રીતે choose કરવા પડે કે D<0 રહે — નહીં તો કોઈક load પર structure fail થઈ શકે.
worked example
Q. x²+2ax+10−3a > 0 બધા real x માટે સાચું રહે એવા a ની range શોધો.
a(coefficient of x²)=1>0 પહેલેથી, એટલે D<0 જ જોઈએ.
D = 4a²−4(10−3a) = 4(a²+3a−10) < 0 → a²+3a−10<0 → (a+5)(a−2)<0 → −5<a<2

08JEE extensions beyond board syllabus

શા માટે ભણવું: આ ભાગ ના topics ગુજરાત બોર્ડ ના core syllabus થી આગળ છે, પણ JEE Main/Advance ના PYQ sets માં વારંવાર દેખાય છે — Practice and Answer Keys ના Phoenix PYQ sheets માં આમાંથી ઘણા patterns સીધા વપરાયેલા મળશે.

8a. Higher-degree equations, quadratic માં convert કરવી

Biquadratic (ax⁴+bx²+c=0) type: y=x² substitute કરી quadratic-in-y બનાવો.

formula — substitution trick
ax⁴+bx²+c=0 → ay²+by+c=0, y=x²
y ના roots શોધ્યા પછી x=±√y લેવાનું — દરેક positive y બે real x આપે
Substitution flow: quartic → quadratic-in-y (સહેલું) → પાછું x માં convert
real-world example Symmetric potential-energy wells (physics) કે lens-design ના equations ઘણી વાર માત્ર even powers (x²,x⁴) માં જ હોય છે — કારણ કે system ડાબે-જમણે symmetric છે (x→−x પર કંઈ ના બદલાય). આવા symmetric systems solve કરવા આ જ y=x² trick literally વપરાય છે.

Reciprocal-type equations (ax⁴+bx³+cx²+bx+a=0, coefficients symmetric): x²થી ભાગીને t = x + 1/x substitute કરો.

8b. Range of rational quadratic expressions

must understand — parameter trick y = (a₁x²+b₁x+c₁)/(a₂x²+b₂x+c₂) નું range શોધવા: y ને parameter ધારીને cross-multiply કરો, x ના quadratic તરીકે ફરી લખો, અને D ≥ 0 (real x મળે એ માટે) ની condition પરથી y ની range નીકળે છે.
worked example — આ પ્રકારનો પ્રશ્ન Practice sheets માં આવેલો છે
Q. x real હોય, તો (3x²+9x+17)/(3x²+9x+7) નું maximum value શોધો.
y(3x²+9x+7) = 3x²+9x+17 → (3y−3)x² + (9y−9)x + (7y−17) = 0
x real માટે D≥0: (9y−9)² − 4(3y−3)(7y−17) ≥ 0
સરળ કરતાં: 81(y−1)² − 12(y−1)(7y−17) ≥ 0 → 3(y−1)[27(y−1)−4(7y−17)] ≥ 0
3(y−1)(−y+41) ≥ 0 → (y−1)(y−41) ≤ 0 → 1 ≤ y ≤ 41
Maximum value = 41

8c. "More than 2 roots ⟹ identity" trick

formula
ax²+bx+c=0 ના 3 થી વધારે (ડિસ્ટિન્ક્ટ) roots હોય ⟺ a=b=c=0
Degree-2 equation ના મહત્તમ 2 જ roots હોઈ શકે — જો 3 મળે તો equation ખરેખર identity (દરેક x માટે સાચું) જ હોઈ શકે
3 distinct roots મળે એ curved parabola માટે impossible — એટલે curve ખરેખર x-axis પર જ "સપાટ" પડેલી હોવી જોઈએ (identity)
real-world example કોઈ measured data (દા.ત. 3 અલગ-અલગ temperature readings પર voltage બરાબર predicted quadratic formula જેટલું જ મળે) — જો ખરેખર ત્રણ (કે વધારે) points પર બે અલગ quadratic formulas સરખું જ પરિણામ આપે, તો scientifically એ બે formulas ખરેખર એક જ formula છે (a,b,c coefficients બરાબર સરખા) — data-fitting/curve-matching માં આ logic વારંવાર વપરાય છે.
high exam probability Functional-equation પ્રકારના પ્રશ્નોમાં (દા.ત. "f(x)=ax²+bx+c બધા x માટે f(x)=f(1−x) સાચું છે, અને એ ત્રણ ડિસ્ટિન્ક્ટ x માટે equal થાય છે એવું આપ્યું હોય") — આ trick એ સીધું a,b,c વચ્ચેનો relation આપી દે છે.
self-check x⁴−13x²+36=0 ના બધા roots શોધો (Part 8a ની substitution trick વાપરીને).

8d. Power-sum recurrence — αⁿ+βⁿ (કે αⁿ−βⁿ) ઝડપથી શોધવા

formula — Newton's recurrence (degree 2 version)
Pₙ = S·Pₙ₋₁ − P·Pₙ₋₂ (S=α+β, P=αβ, Pₙ=αⁿ+βⁿ)
દરેક higher power sum, પાછલા બે power sums પરથી સીધો નીકળે — α³+β³, α⁴+β⁴ repeat કરીને શોધવાની જરૂર નહીં

એ જ recurrence aₙ=αⁿ−βⁿ (asymmetric difference) માટે પણ ચાલે છે: aₙ = S·aₙ₋₁ − P·aₙ₋₂.

worked example
Q. α,β roots of x²−6x−2=0. aₙ=αⁿ−βⁿ હોય, તો (a₁₀−2a₈)/(3a₉) શોધો.
S=6, P=−2. Recurrence: aₙ = 6aₙ₋₁+2aₙ₋₂ ⟹ a₁₀ = 6a₉+2a₈ ⟹ a₁₀−2a₈ = 6a₉
(a₁₀−2a₈)/(3a₉) = 6a₉/3a₉ = 2

8e. Transformed roots — products અને ratios

α,β ના પરથી બનતા નવા roots ના sum-product ને હંમેશા S,P ના પદોમાં ફેરવવા:

formula — product-type new roots
αβ² + α²β = αβ(α+β) = PS , αβ²·α²β = P³
નવા equation ના roots αβ², α²β હોય તો — sum=PS, product=P³ વાપરીને x²−(PS)x+P³=0
formula — ratio-type new roots (α/β, β/α)
α/β + β/α = (α²+β²)/P = (S²−2P)/P , (α/β)(β/α)=1
Product હંમેશા 1 — sum માટે S,P જ વાપરવા. જો S,P ને બદલે α+β=−p, α³+β³=q આપ્યું હોય, તો પહેલા P = (S³−q)/3S (α³+β³=S³−3PS પરથી) કાઢી લેવું

8f. Root-is-square-of-other

must understand — technique x²+px+q=0 નો એક root બીજા નો square હોય (β=α²) ત્યારે: S=α+β=α+α², P=αβ=α³. આ બંને equations માંથી α ને eliminate કરીને (α ને S,P બંનેમાં expression તરીકે treat કરીને) p,q વચ્ચેનો relation નીકળે છે — સામાન્ય રીતે p³+q²−q(3p+1)=0 પ્રકારનું result આવે (sign conventions પ્રમાણે ચાર જુદા form શક્ય, exact sign paper પ્રમાણે ચકાસવું).

8g. Functional substitution — (x−a)(x−b)=c પ્રકાર

must understand જો α,β એ (x−a)(x−b)=c ના roots હોય (એટલે (x−a)(x−b)−c=0 નું), તો (x−α)(x−β)+c=0 ના roots સીધા a, b જ હોય છે — કારણ કે બંને equations એ જ parabola ને ઊંચે/નીચે shift કરેલું સ્વરૂપ છે, ફક્ત roles ઊંધા થાય છે. Direct expansion કરવાની જરૂર નથી, pattern ઓળખી લેવો.

8h. Identity in x — multiple unknowns સાથે

must understand — Part 8c થી આગળ Part 8c માં "3+ roots ⟹ a=b=c=0" જોયું — એ single quadratic માટે હતું. જ્યારે expression માં બે અલગ unknowns (દા.ત. a અને b બંને) હોય અને એ x ના બધા values માટે 0 રહેવું જોઈએ, ત્યારે x ની દરેક power (x², x¹, x⁰) નો coefficient અલગ-અલગ 0 મૂકવો પડે — એટલે એક equation ને બદલે 2-3 simultaneous equations મળે છે, જે a,b ના possible values (ઘણી વાર માત્ર 0 જ) આપે છે.
common mistake "Identity in x" જોઈને સીધું discriminant-based ("3 roots" trick) લગાવવા જવું — જ્યારે expression માં એક કરતાં વધારે unknown constant હોય, ત્યારે coefficient-matching (દરેક power ને અલગ 0 મૂકવો) જ સાચી રીત છે, "3 roots" trick નહીં.

8i. Modulus-mixed quadratic equations most frequent JEE pattern

must understand \|x−a\| ધરાવતું equation solve કરવા — number line ને a ના આધારે cases માં તોડો (x<a અને x≥a), દરેક case માં modulus ખૂલે એટલે equation plain quadratic બને, અને છેલ્લે મળેલો root એ case ની range માં આવે છે કે નહીં — ચકાસવું જરૂરી (ના આવે તો reject).
worked example
Q. x²+\|2x−3\|−4=0 ના roots ના squares નો સરવાળો શોધો.
Case x≥3/2: x²+2x−3−4=0 → x²+2x−7=0 → x=−1±2√2; માત્ર x=−1+2√2 (≈1.83) આ case માં valid
Case x<3/2: x²−2x+3−4=0 → x²−2x−1=0 → x=1±√2; માત્ર x=1−√2 (≈−0.41) આ case માં valid
બંને roots ના squares ઉમેરીને final answer મળે
common mistake Case-split કર્યા પછી મળેલા roots ને એ જ case ની range સામે ચકાસ્યા વગર સ્વીકારી લેવા — ઘણી વાર એક case નો root ખરેખર બીજા case ની range માં પડે છે, જે invalid (extraneous) છે.

8j. Floor-function (fractional-part) equations

must understand [x] = greatest integer ≤ x, {x} = x−[x] (fractional part, 0≤{x}<1). આવા equations માં [x] ને એક integer parameter n ધારી લો (x=n+f, 0≤f<1), equation ને n,f માં expand કરો, અને પછી n ના integer values ચકાસો જેના માટે f ની range સાચી બેસે.
worked example
Q. [eˣ]²+[eˣ+1]−3=0 ના solutions નો interval શોધો.
t=[eˣ] ધારો (integer). t²+(t+1)−3=0 → t²+t−2=0 → t=1 અથવા t=−2
eˣ>0 હોવાથી t=[eˣ]≥0, એટલે t=−2 reject. t=1 ⟹ 1≤eˣ<2 ⟹ x∈[0,ln2)

8k. Exponential/logarithmic substitution to quadratic

formula — substitution pattern
a·(base)^(2f(x)) + b·(base)^(f(x)) + c = 0 → t=(base)^(f(x)), at²+bt+c=0
eˣ, aˣ, e^(sinx) — ગમે તે exponential term repeat થાય ત્યારે t=એ term ધારીને quadratic બનાવો; પછી t>0 (કે sinx જેવા bounded cases માટે specific range) ચકાસીને x પાછું કાઢો
worked example
Q. (√3+√2)ˣ+(√3−√2)ˣ=10 ના solutions ની સંખ્યા શોધો.
(√3+√2)(√3−√2)=1, એટલે (√3−√2)ˣ = 1/(√3+√2)ˣ. t=(√3+√2)ˣ ધારો (t>0)
t+1/t=10 → t²−10t+1=0 → t=5±2√6, બંને positive — એટલે 2 solutions
common mistake t માટે મળેલા roots માંથી negative અથવા invalid-range roots (દા.ત. sinx=t હોય તો \|t\|>1 reject, eˣ=t હોય તો t≤0 reject) કાઢી નાખવાનું ભૂલી જવું — છેલ્લે "કેટલા x મળે" ગણતી વખતે આ સૌથી common ભૂલ છે.

8l. Radical equations reducible to quadratic form

must understand √(quadratic) ના સરવાળા/તફાવત વાળા equations માં, ઘણી વાર બંને બાજુના quadratics નો common ભાગ કાઢીને એક નવો variable (દા.ત. y=x²−ax) ધારી શકાય — જે equation ને સીધું સરળ બનાવે, પૂરું square કરવાની જરૂર ન પડે.
worked example — sketch
Q. √(x²−4x+3) + √(x²−9) = √(4x²−14x+6) ના real roots ની સંખ્યા શોધો.
દરેક term ને factor કરો: √((x−1)(x−3)) + √((x−3)(x+3)) = √((x−3)(4x−2))... પેટર્ન જુઓ — (x−3) common છે, y=√(x−3) જેવો substitution કરીને સરળ થાય છે
(domain condition: ત્રણેય radicals real રહેવા x ની range ચકાસવી જરૂરી — ઘણી વાર domain પોતે જ answer ને 1 root સુધી સીમિત કરી દે છે)

8m. Repeated compound-expression substitution

must understand જ્યારે equation માં એક જ complicated expression (દા.ત. 3x²+4x+3) વારંવાર દેખાય, ત્યારે એને u ધારી લો — આખું equation u ના (અને related u−1 જેવા) પદોમાં એક સાદું quadratic (કે quadratic-in-ratio) બની જાય છે.
rare but real — brief mentions only Infinite continued fractions (દા.ત. x=4+1/(5+1/(4+1/(5+...)))): આખા fraction ને ફરી x (કે બે-તબક્કાનું y) તરીકે ધારીને, self-referencing equation quadratic બને છે. Iterative root-mapping (α root ⟹ f(α) પણ root, દા.ત. α²−2): બંને roots ના set ને α,f(α) તરીકે treat કરીને sum/product ની conditions થી a,b શોધાય — advanced, ઓછું frequent.

8n. Genuinely complex-coefficient quadratics

must understand — different rules apply જ્યારે equation ના coefficients (a,b,c) પોતે complex હોય (દા.ત. x²+(2i−1)=0), ત્યારે: S=−b/a, P=c/a હજુ પણ સાચા છે (Vieta's ક્યારેય coefficients ના real/complex પર આધારિત નથી), પણ D≥0 ⟹ real roots, conjugate-pair roots, "real અને imaginary part અલગ પાડવા" — આ બધા rules ફક્ત real coefficients માટે જ સાચા છે, complex coefficients પર લાગુ ન પડે.
common mistake Complex coefficients જોઈને પણ "roots conjugate pair માં આવશે" ધારી લેવું — ના આવે. Complex-coefficient equation ના બંને roots સ્વતંત્ર complex numbers છે, એકબીજાના conjugate હોવા જરૂરી નથી.

8o. Repeated power-reduction using the defining equation

must understand — Newton's recurrence થી અલગ α equation નું root છે એટલે α² ને હંમેશા લોઅર powers (α¹, constant) ના પદોમાં લખી શકાય (equation પરથી જ). આ relation repeat વાપરીને α ની કોઈપણ ઊંચી power (α¹²,α⁹⁶ વગેરે) ધીમે ધીમે નીચે લાવી શકાય — આ Newton ના power-sum recurrence (Pₙ=αⁿ+βⁿ માટે) થી અલગ છે, આ ટેકનિક એક જ root ની single power ને simplify કરવા વાપરાય છે.
adjacent topic — degree 3/4 Vieta's α+β=−b/a, αβ=c/a ની idea ax³+bx²+cx+d=0 (ત્રણ roots) અને higher degree માટે પણ extend થાય છે (Σα=−b/a, Σαβ=c/a, αβγ=−d/a વગેરે) — એ Theory of Equations નો ભાગ છે, આ chapter નો core નથી, પણ PYQ sets માં ક્યારેક crossover question તરીકે આવે છે (દા.ત. "roots of a cubic, find (r₁+2)(r₂+2)(r₃+2)" — અહીં (r+2) ના factors ને એક નવા polynomial ના roots તરીકે treat કરીને, અથવા direct substitution કરીને ઉકેલાય).

JEE extension — modulus સમીકરણ: |A| + |B| = |A ± B|

y = |x² − 4| + |x² − 9| ના ગણેલા બિંદુઓ (5 થી ઉપરનો ભાગ clip): સમાનતા ફક્ત 4 ≤ x² ≤ 9 માં.
formula — must memorize
|A| + |B| = |A + B| ⟺ AB ≥ 0; |A| + |B| = |A − B| ⟺ AB ≤ 0
Triangle inequality |A| + |B| ≥ |A ± B| માં સમાનતા ત્યારે જ જ્યારે બંને "એક દિશામાં" હોય. તેથી બે modulus નો સરવાળો જોઈએ ત્યારે પહેલાં તપાસો: A + B કે A − B જમણી બાજુ સરળ બને છે? |x| વાળા quadratic (x² − a|x| + b = m) માં t = |x| ≥ 0 મૂકો: દરેક ધન t ⟹ બે x, t = 0 ⟹ એક x. Real-world: GPS/નકશામાં "A થી B થઈને C" નું અંતર સીધા A-C અંતર જેટલું ત્યારે જ જ્યારે B સીધી રેખા પર હોય — એ જ સમાનતા શરત.
worked example
Given — |x² − 4| + |x² − 9| = 5
Need — ઉકેલ ગણ
Method — A = x² − 4, B = x² − 9, A − B = 5 ⟹ AB ≤ 0
Calculation — (x² − 4)(x² − 9) ≤ 0 ⟹ 4 ≤ x² ≤ 9 ⟹ x ∈ [−3, −2] ∪ [2, 3]
Check — x = 2.5: 2.25 + 2.75 = 5 ✓; x = 0: 4 + 9 = 13 ✗
common mistakeEndpoints છોડી દેવા — A અથવા B = 0 પર પણ સમાનતા પૂરી થાય ⟹ બંધ અંતરાલ.

JEE extension — અનંત nested radical અને log-domain વાળા સમીકરણ

y = √(6 + y) અને y = y ના ગણેલા વક્રો; cobweb પગલાં ખરેખર ગણેલા — 3 તરફ જાય છે.
formula — must memorize
√(a + √(a + √(a + …))) = y ⟹ y = √(a + y) ⟹ y² − y − a = 0 (ધન મૂળ)
અનંત શ્રેણી પોતાની અંદર ફરી દેખાય છે, તેથી y પોતાનાથી વ્યાખ્યાયિત થાય. Radical હંમેશા ≥ 0, એટલે ફક્ત ધન મૂળ લો. Log સમીકરણ (log f = log g) ઉકેલી પછી domain (f > 0, g > 0) થી roots ગાળો — log(kx) = 2log(x + 1) માં k < 0 હોય તો પણ x ઋણ હોય ત્યારે kx > 0 બને. Real-world: continued fraction/નેસ્ટેડ ફોર્મ્યુલા (જેમ કે golden ratio φ = √(1 + √(1 + …))) આ જ રીતે ઉકેલાય.
worked example
Given — √(6 + √(6 + √(6 + …)))
Need — કિંમત
Method — y = √(6 + y)
Calculation — y² − y − 6 = 0 ⟹ (y − 3)(y + 2) = 0 ⟹ y = 3
Check — પગલાં: 2.449, 2.906, 2.984, 2.997 → 3 ✓
common mistakeઋણ મૂળ (−2) પણ સ્વીકારવું, અથવા log સમીકરણમાં domain તપાસ્યા વગર બધા roots લખી દેવા.

8p. Newton's identities — 3+ roots ના power-sums (cubic/quartic વગેરે)

must understand — Part 8d નું higher-degree extension Part 8d નું Pₙ=S·Pₙ₋₁−P·Pₙ₋₂ recurrence માત્ર 2 roots (quadratic) માટે છે. 3+ roots (cubic, quartic...) માટે elementary symmetric functions e₁=Σr, e₂=Σrᵢrⱼ, e₃=Σrᵢrⱼrₖ... (polynomial ના coefficients પરથી સીધા, sign alternate કરીને) વાપરી power-sums pₙ=Σrⁿ કાઢવાનું Newton's identities કહેવાય:
formula — Newton's identities (પ્રથમ 3)
p₁=e₁   p₂=e₁p₁−2e₂   p₃=e₁p₂−e₂p₁+3e₃
xⁿ−e₁xⁿ⁻¹+e₂xⁿ⁻²−e₃xⁿ⁻³+... ના standard sign pattern સાથે equation ના printed coefficients ને match કરીને e₁,e₂,e₃ ઓળખો (sign flip ધ્યાનથી)
worked example — Practice sheets માં આવેલો છે
Q. x⁴−3x³−2x²+3x+1=0 ના roots ના cubes નો sum શોધો.
e₁=3, e₂=−2, e₃=−3 (coefficients ને −e₁,+e₂,−e₃,+e₄ pattern સાથે match કરીને)
p₁=3; p₂=3(3)−2(−2)=13; p₃=3(13)−(−2)(3)+3(−3)=39+6−9=36
common mistake e₂,e₃ ના sign ને coefficient ના sign સાથે directly (flip વગર) લેવા — standard form xⁿ−e₁xⁿ⁻¹+e₂xⁿ⁻²−e₃xⁿ⁻³+... માં alternate signs છે, એ ભૂલવું નહીં.

8q. Palindromic polynomial — y+1/y substitution

must understand Exponential/polynomial equation ના coefficients symmetric હોય (દા.ત. y⁴+4y³−58y²+4y+1: 1,4,−58,4,1 — આગળ-પાછળ સરખા) ત્યારે y²થી divide કરી u=y+1/y મૂકતા degree ઘટીને quadratic-in-u બને છે. Real y માટે |u|≥2 જરૂરી (AM-GM: y+1/y ના extreme values ±2 પર) — આ constraint valid u ને filter કરવા હંમેશા વાપરવો.
formula
y²+1/y² = u²−2   (u=y+1/y, y≠0)
worked example — Practice sheets માં આવેલો છે
Q. e⁴ˣ+4e³ˣ−58e²ˣ+4eˣ+1=0 ના real solutions ની સંખ્યા.
y=eˣ: y²+4y−58+4/y+1/y²=0 → (u²−2)+4u−58=0 → u²+4u−60=0 → u=6, u=−10
u=6 (|u|≥2 ✓): y+1/y=6 → y=3±2√2 (બંને positive) → 2 valid x. u=−10: y negative → reject (eˣ>0)
Answer: 2 real solutions
remember — સંપૂર્ણ chapter
  1. D=b²−4ac — roots ની nature (real/equal/complex, rational/irrational) સંપૂર્ણપણે decide કરે છે
  2. α+β=−b/a, αβ=c/a — roots શોધ્યા વગર reasoning નો પાયો
  3. Symmetric functions (α²+β², α³+β³...) → S,P ના પદોમાં લખાય; asymmetric (α−β) માં ±√D/a આવે
  4. Common root: બંને common ⟹ ratios equal; એક common ⟹ cross-multiplication formula
  5. Location of roots: a·f(k) નું sign parabola પરથી k ક્યાં આવેલો છે એ બતાવે
  6. Inequality: roots ની બહાર/વચ્ચે a ના sign પ્રમાણે expression નું sign — wavy curve

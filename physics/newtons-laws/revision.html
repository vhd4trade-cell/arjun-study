Newton's Laws of Motion — revision sheet

11th science · Gujarat board + JEE · one-page quick scan before exam · PABT Phase Test 2 (04-10-2026)

10-second must-knows
ΣF=0 ⟺ a=0 F = ma = dp/dt J = FΔt = Δp F(A on B) = −F(B on A) f_s ≤ μ_sN, f_k = μ_kN F = −kx (spring) a(Atwood) = (m₂−m₁)g/(m₁+m₂) tanθ = v²/(rg) — banking & pendulum

00Force — foundation ↗

force ની વ્યાખ્યા
influence જે, એકલું લાગે તો, velocity બદલે
3 laws ની story
1st: force ન હોય તો શું · 2nd: કેટલું બદલાય · 3rd: ક્યાંથી આવે

01પહેલો નિયમ — Inertia ↗

condition
ΣF = 0 ⟺ a = 0
rest અથવા uniform velocity — બંને એક જ category
pseudo-force
F_pseudo = −m a_frame
ફક્ત non-inertial frame ની અંદર બેસીને solve કરો ત્યારે
inertial frame
પોતે accelerate ન થતો frame — 1st law સીધો સાચો
not this
Ground frame થી pseudo-force ઉમેરવો — ખોટું

02બીજો નિયમ — F=ma, Momentum, Impulse ↗

momentum
p = mv
mool law
F = dp/dt
constant mass → F=ma
impulse-momentum
J = FΔt = Δp = m(v−u)
not this
દિશા (sign) ભૂલી જવી — v ઊલટી દિશામાં ઋણ
JEE: variable-mass thrust
F = v_rel × dm/dt
રોકેટ ઉપર જવા: F=m(a+g); rocket/ફુગ્ગા-પ્રકારના પ્રશ્નો

03ત્રીજો નિયમ — Action-Reaction ↗

statement
F(A on B) = −F(B on A)
pair ના 3 rules
1) અલગ 2 object · 2) same force-type · 3) same instant
misconception
action-reaction cancel થાય — ના, અલગ object પર, cancel ક્યારેય નહીં

04Free Body Diagram ↗

5 steps
isolate → mg → contact forces (N,T,f) → applied force → arrows+labels
not this
N = mg હંમેશા ધારી લેવું — equation થી કાઢો

05Forces ના પ્રકાર ↗

gravity
W = mg
normal
સપાટીને લંબ, ક્યારેય parallel નહીં
tension
string ફક્ત pull કરે, push નહીં; ideal string માં T સરખું
friction
f_s ≤ μ_sN, f_k = μ_kN
μ_s > μ_k હંમેશા
spring (Hooke's law)
F = −kx
not this
f_s ને હંમેશા μ_sN બરાબર માનવું — max જ છે, self-adjusting
JEE: વક્ર સપાટી પર limiting friction
dy/dx = μ (તે બિંદુએ)
સીધા incline ના tanθ=μ ને generalize — ગોળાકાર ખાડા/ટેકરી

06Equilibrium ↗

component method
ΣFₓ = 0, ΣFᵧ = 0
Lami's theorem
F₁/sinα = F₂/sinβ = F₃/sinγ
α,β,γ = સામેના ખૂણા
solved: 30°/60° string
T₁=0.5W, T₂=0.866W (sinθ ratio)

07Connected Bodies ↗

string constraint
T સરખું, |a| બંને object માટે સરખું
Atwood machine — a
a = (m₂−m₁)g/(m₁+m₂)
Atwood machine — T
T = 2m₁m₂g/(m₁+m₂)
not this
Tension માટે અલગ mass નું equation વાપરવાનું ભૂલવું
JEE: cascading pulley constraint
છેડો1+છેડો2 = 2×axle નો a
દરેક movable ગરગડી માટે અલગ constraint, પછી substitute
દોરી પર ચડતો માણસ
T = m(g + a)
ઉતરે ⟹ m(g − a)
spring balance
વાંચન = તેમાંથી પસાર થતો તણાવ T, ગતિમાં mg નહીં

08Circular Motion Dynamics ↗

ideal banking
tanθ = v²/(rg)
N cosθ=mg, N sinθ=mv²/r
conical pendulum
tanθ = v²/(rg)
T cosθ=mg, T sinθ=mv²/r; r=Lsinθ
centripetal force
F_c = mv²/r = mω²r
નવો force-type નથી — existing force નું center-તરફનું net
conical pendulum period
T_period = 2π√(h/g)
h = L cosθ (O થી circle plane સુધીની ઊંચાઈ)
not this
Conical pendulum માં r=L ધારવું — સાચું: r=L sinθ
not this
ground frame માં centrifugal force દોરવો

!Common mistakes — quick strip

l ny, F=ma માં mass constant ના હોય તો F=dp/dt વાપરો
action-reaction ક્યારેય એક જ object ના FBD માં ભેગા ના આવે
string push ના કરી શકે — tension ઋણ ના થાય, ઢીલી પડે તો T=0
Atwood machine માં Tension બંને mass ના equation થી cross-check કરો
banking/conical pendulum માં component ને ઊંધા (sin↔cos) ના મૂકો

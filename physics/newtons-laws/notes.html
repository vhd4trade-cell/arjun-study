00Force અને Newton's Laws શું છે

outcome "Force" ખરેખર શું છે, "law" કેમ કહેવાય (guess નહીં), અને ત્રણેય laws એકબીજા સાથે કેવી રીતે જોડાયેલા છે — એ ચોખ્ખું થશે.

Force ની ખરી વ્યાખ્યા

Force Latin fortis (strong) પરથી આવે છે. પણ physics માં force ને "ધક્કો કે ખેંચાણ" કહેવું અધૂરું છે — ચોક્કસ વ્યાખ્યા: force એ કોઈપણ influence છે જે, એકલું લાગુ પડે તો, object ની velocity બદલે (speed, direction, અથવા બંને). Velocity ન બદલાય ત્યાં સુધી force નું existence સાબિત ન થાય — આ જ વ્યાખ્યા ત્રણેય laws ને જન્મ આપે છે.

why it matters કોઈપણ motion — ચાલવું, ગાડી ચલાવવી, satellite નું ભ્રમણ, પુલ નું ટકી રહેવું — બધું force અને acceleration ના સંબંધ પર આધારિત છે. Mechanics નો આખો પાયો આ ત્રણ laws છે; આગળ work-energy, rotational motion, gravitation — બધું આના પર જ બંધાય છે. PABT Phase Test 2 (04-10-2026) માં direct topic તરીકે છે.
"Law" કેમ કહેવાય — guess નહીં Newton એ 1687 માં Principia માં આ ત્રણ statements ને "law" કહ્યા કારણ કે એ કોઈ ચોક્કસ situation માટે નહીં, પણ બ્રહ્માંડના દરેક object પર, દરેક વખતે, verify થયેલા universal પેટર્ન છે — a "theory" જેમ ચકાસાતું નથી, પણ પ્રયોગોથી વારંવાર confirm થયેલું, exception વગરનું નિયમ છે (Newtonian scale પર — ખૂબ ઊંચી speed કે અતિ નાના particle પર relativity/quantum mechanics લાગુ પડે, જે 11th ના scope બહાર છે).
must understand — ત્રણેય laws એક જ story ના ત્રણ ભાગ 1st law કહે છે force ન હોય તો શું થાય (કંઈ ન બદલાય — status quo). 2nd law કહે છે force હોય તો કેટલું બદલાય (quantitative measure — F=ma). 3rd law કહે છે force ક્યાંથી આવે છે (એકલો force ક્યારેય ન હોય, હંમેશા pair માં). ત્રણેય સાથે મળીને "શરીર કેમ movement કરે છે અથવા નથી કરતું" નો સંપૂર્ણ જવાબ આપે છે.
1st law (qualitative) → 2nd law (quantitative) → 3rd law (origin) — ત્રણેય એક unified framework
real-world example
Table પર પડેલી ચોપડી — કોઈ visible push/pull ન દેખાય તોય gravity (નીચે) અને table નું normal force (ઉપર) બંને હાજર છે, પણ equal-opposite હોવાથી net force શૂન્ય — ચોપડી સ્થિર રહે છે. આ 1st law નું ઉદાહરણ છે: net force = 0 ⟹ કંઈ ન બદલાય.
→ Next action: Part 1 થી શરૂ — પહેલો law સમજવો, કારણ કે "force" ની આખી વ્યાખ્યા એના પર જ ઊભી છે.

01પહેલો નિયમ — Inertia અને Reference frames

outcome Inertia શું છે, કયા frame માં આ law સાચો પડે (inertial vs non-inertial), અને pseudo-force ક્યારે વાપરવું — સ્પષ્ટ થશે.
why it matters Bus સહસા brake મારે ત્યારે આપણે આગળ કેમ ધકેલાઈએ — આ રોજિંદો અનુભવ પહેલા law પરથી જ સમજાય છે. Rotating frame, lift ની અંદરના problems (JEE માં common) — બધા આ law ના non-inertial frame extension પરથી આવે છે.
1a — Statement અને inertia 1b — Inertial vs non-inertial frame 1c — Pseudo-force

1a. કથન અને Inertia નો ખરો અર્થ

Statement: દરેક object પોતાની rest ની અવસ્થા અથવા uniform velocity ની અવસ્થામાં જ રહે છે, જ્યાં સુધી કોઈ બાહ્ય (external) net force એને એ અવસ્થા બદલવા મજબૂર ન કરે.

Inertia Latin iners (idle, without skill/power) પરથી આવે છે — object પોતાની જાતે પોતાની motion ની અવસ્થા બદલી શકતું નથી, એ "idle" (નિષ્ક્રિય) ગુણ છે. Inertia કોઈ force નથી — એ object નો ગુણધર્મ (property) છે, જે એની mass સાથે સીધો જોડાયેલો છે: mass જેટલી વધારે, velocity બદલવા સામે object એટલો વધારે "પ્રતિકાર" કરે (વધારે force જોઈએ).

must understand — "rest" અને "uniform velocity" એક જ category Textbook માં rest ને અલગ અને uniform motion ને અલગ ગણવાની ભૂલ ન કરવી. Rest એટલે v=0 ની uniform velocity — physics ની દૃષ્ટિએ બંને "કંઈ બદલાતું નથી" ની જ એક અવસ્થા (zero acceleration). Law કહે છે: acceleration ત્યારે જ આવે જ્યારે net external force લાગે — rest હોય કે 100 km/h સીધી લીટીમાં, ફરક નથી.
Passenger નું શરીર બસ ની જૂની velocity જાળવી રાખવા મથે છે (inertia) — બસ ધીમી પડે, શરીર નહીં, તેથી સાપેક્ષ રીતે આગળ ધકેલાય
formula — first law's quantitative face
ΣF = 0 ⟺ a = 0
Net external force શૂન્ય ⟺ acceleration શૂન્ય (rest અથવા uniform velocity)

1b. Inertial vs Non-inertial reference frame

1st law દરેક frame માં સાચો નથી પડતો — ફક્ત ચોક્કસ પ્રકારના frame માં. Inertial frame = એવો reference frame જે પોતે accelerate ન થતો હોય (rest માં અથવા constant velocity થી ગતિ કરતો હોય). આવા frame માં 1st law સીધો સાચો પડે છે. Non-inertial frame = accelerating frame (દા.ત. brake મારતી bus, વળાંક લેતી ગાડી, ઉપર-નીચે થતી lift) — આમાં 1st law સીધો લાગુ ન પડે, કારણ કે frame પોતે જ accelerate થાય છે.

exam probability — high "Inertial frame એટલે શું" અને "non-inertial frame નું ઉદાહરણ આપો" — બંને direct-definition પ્રશ્નો વારંવાર પુછાય છે.

1c. Pseudo-force — non-inertial frame માં Newton's laws વાપરવાની ટ્રિક

Non-inertial frame માં બેઠેલા observer ને object પર કોઈ real force ન હોય તોય "કંઈક ધક્કો મારે છે" એવું લાગે (દા.ત. accelerating bus માં ઊભેલા passenger ને પાછળ ધકેલાવા જેવું લાગવું). આ ખરેખર કોઈ real force નથી — frame પોતે accelerate થાય છે એની અસર છે. છતાં non-inertial frame ની અંદર Newton's 2nd law સીધો વાપરવો હોય તો, એક કાલ્પનિક (pseudo) force ઉમેરવો પડે.

formula — must memorize
Fpseudo = −m aframe
Frame ના acceleration ની બરાબર magnitude, પણ વિરુદ્ધ દિશામાં — object ના mass m સાથે ગુણેલું
worked example
Given — Lift ઉપર તરફ a=2 m/s² થી accelerate થાય છે, અંદર m=5 kg નો block ફ્લોર પર ઊભો છે (g=10 m/s²)
Need — Floor નું normal force N block પર
Method — Lift (ground frame) inertial frame ગણીને block પર real forces: mg નીચે, N ઉપર. Block પણ lift સાથે જ a=2 m/s² ઉપર જાય છે
Calculation — 2nd law: N − mg = ma ⟹ N = m(g+a) = 5(10+2) = 60 N
Check — Lift ના frame (non-inertial) માંથી verify: N − mg − Fpseudo = 0 (lift frame માં block સ્થિર), Fpseudo=ma=10N નીચે તરફ (lift ઉપર જાય, pseudo-force વિરુદ્ધ દિશામાં) ⟹ N = mg + ma = 50+10 = 60 N ✓ બંને method same જવાબ
common mistake Pseudo-force ને ground (inertial) frame માંથી solve કરતી વખતે પણ ઉમેરી દેવો — ખોટું. Pseudo-force ફક્ત non-inertial frame ની અંદર બેસીને solve કરો ત્યારે જ ઉમેરાય, ground frame થી ક્યારેય નહીં.
self-check 1. Car જમણી તરફ વળાંક લે ત્યારે અંદર બેઠેલા વ્યક્તિને ડાબી તરફ ધકેલાવા જેવું કેમ લાગે?
2. Lift નીચે તરફ a=2 m/s² થી accelerate થાય તો ઉપરના example માં N કેટલું થશે?

02બીજો નિયમ — F = ma, Momentum, Impulse

outcome F=ma ક્યાંથી આવે છે (momentum ના mechanism પરથી), impulse-momentum theorem, અને numerical problems solve કરવાની ability.
why it matters આ chapter નું સૌથી વધારે numerically વપરાતું formula. Connected bodies, circular motion, pulleys — બધા problems આખરે F=ma (અથવા એના momentum-form) પર જ ઊભા છે.
2a — Momentum 2b — F=ma ક્યાંથી આવ્યું 2c — Impulse

2a. Momentum — "quantity of motion"

Newton એ પોતે 2nd law ને F=ma તરીકે નહીં, momentum ના ફેરફાર તરીકે લખ્યો હતો. Momentum (p) = mass × velocity — object ની "motion કેટલી છે" એનું measure, જેમાં mass (કેટલું ભારે) અને velocity (કેટલું ઝડપી) બંને ભાગ ભજવે છે.

formula — must memorize
p = mv
Vector quantity — velocity ની દિશામાં જ
"momentum" કેમ કહેવાય Latin momentum = "movement, moving power" (movere = to move પરથી). ધીમી ટ્રક અને ઝડપી સાઇકલ બંનેને રોકવા મુશ્કેલ હોઈ શકે — ટ્રક mass થી, સાઇકલ speed થી. Momentum બંને effect ને એક number માં ભેગું કરે છે, જે એટલે જ "motion ની power" કહેવાય છે.

2b. F = ma ક્યાંથી આવે છે

Newton નું original statement: net force = momentum ના બદલાવાનો rate.

formula — mool statement
F = dp/dt
Force = momentum time સાથે કેટલી ઝડપથી બદલાય છે

જ્યારે mass constant હોય (મોટાભાગના 11th ના problems માં એવું જ હોય છે), તો:

derivation
F = dp/dt = d(mv)/dt
m constant હોવાથી બહાર કાઢી શકાય: F = m (dv/dt)
dv/dt એ જ acceleration a ની વ્યાખ્યા છે
∴ F = ma
must understand F=ma એ special case છે, mool law નહીં. Mool law momentum પરથી છે કારણ કે mass બદલાય એવા systems (rocket, જ્યાં ઇંધણ બળીને mass ઘટે) માં F=ma ખોટું પડે, પણ F=dp/dt હંમેશા સાચું રહે છે. 11th ના syllabus મોટાભાગે constant-mass systems પૂરતો છે, એટલે F=ma જ મુખ્યત્વે વપરાશે.
a = F/m = 10/2 = 5 m/s² — acceleration force ની જ દિશામાં, mass ના proportion માં ઊલટું

2c. Impulse — force × time

F = dp/dt ને rearrange કરી બંને બાજુ time સાથે integrate કરતા: impulse મળે છે — ટૂંકા સમય માટે લાગતું મોટું force, momentum માં એટલો જ ફેરફાર લાવે છે.

formula — must memorize
J = F·Δt = Δp = m(v−u)
Impulse = momentum માં ફેરફાર (impulse-momentum theorem)
Bat બોલ ને મારે ત્યારે force ટૂંકા સમય માટે spike થાય છે — curve ની નીચેનો area = impulse = momentum માં ફેરફાર
real-world example — impulse ઘટાડવો/વધારવો
Cricket માં હાથ પાછળ ખેંચીને catch લેવો — Δp (બોલ ના momentum માં ફેરફાર) ફિક્સ છે, પણ હાથ પાછળ ખેંચતા Δt વધે છે, તેથી F = Δp/Δt ઘટે છે — હાથ ને ઓછું વાગે
Car ના airbags/crumple zones — accident માં Δt વધારીને peak force ઘટાડે છે, જ્યારે karate ma ઈંટ તોડવી હોય ત્યારે ઊલટું — Δt શક્ય એટલું ઓછું રાખીને F મહત્તમ કરાય છે
worked example
Given — m=0.15 kg નો બોલ u=20 m/s ની ઝડપે bat તરફ આવે છે, bat થી અથડાઈને v=−25 m/s (ઊલટી દિશામાં) પાછો જાય છે, અથડામણ Δt=0.01 s ચાલે છે
Need — bat એ બોલ પર લગાડેલ average force
Method — Δp = m(v−u), દિશા sign સાથે ધ્યાનમાં લેવી (u ને + માનીએ તો v ઋણ)
Calculation — Δp = 0.15×(−25−20) = 0.15×(−45) = −6.75 kg·m/s; F = Δp/Δt = −6.75/0.01 = −675 N (એટલે 675 N, u ની વિરુદ્ધ દિશામાં)
Check — દિશા બોલ ના પાછા ફરવાની દિશામાં જ છે — sensible ✓
common mistake Momentum માં ફેરફાર કાઢતી વખતે દિશા (sign) ભૂલી જવી — બોલ પાછો વળે ત્યારે v ને ઋણ ન લખવાથી જવાબ અડધો જ (ખોટો) આવે છે.
self-check m=1000 kg ની car u=20 m/s થી v=0 સુધી 4 સેકંડમાં રોકાય તો average braking force કેટલું?

JEE extension — variable-mass (thrust) સમીકરણ F=ma ત્યાં જ સીધું લાગુ પડે છે જ્યાં m અચળ હોય. રોકેટ, હવા ભરેલો ફુગ્ગો (જેમાંથી ગેસ escape થાય છે), કે વરસાદમાં ભરાતી ટ્રોલી જેવા તંત્રમાં દળ પોતે t સાથે બદલાય છે — ત્યાં momentum ને ફરી p=mv થી શરૂ કરી derive કરવું પડે:
F_thrust = v_rel × (dm/dt)
જ્યાં v_rel = બહાર નીકળતા દ્રવ્યનો તંત્રને સાપેક્ષ વેગ, dm/dt = દળ બદલાવાનો દર. રોકેટ ઉપર તરફ પ્રવેગ a મેળવવા, ગુરુત્વાકર્ષણ સામે પણ લડવું પડે છે, એટલે:
F_thrust = m(a+g)   (રોકેટ ઉપર જતું હોય ત્યારે)
શા માટે કામ કરે છે: escape થતો ગેસ પોતાનું momentum લઈ જાય છે; Newton ના 3rd law મુજબ, ગેસ ને આગળ ધકેલવા તંત્રે જે બળ લગાડ્યું, એટલું જ બળ ગેસ તંત્ર પર પાછું (વિરુદ્ધ દિશામાં) લગાડે છે — આ જ thrust.
worked example
Given — ફુગ્ગાનું દળ 10g, હવા 4.5 cm/s ના દરે નીકળે છે, 5s માં ખાલી થાય
Method — dm/dt = 10g/5s = 2 g/s; F=v_rel×dm/dt
Calculation — F = 4.5 cm/s × 2 g/s = 9 dyne (cgs એકમમાં સીધું)
આ board syllabus થી આગળ (JEE-level extension) છે — momentum-સંરક્ષણના મુખ્ય પ્રકરણમાં વધુ ઊંડાણથી આવરી લેવાશે.

03ત્રીજો નિયમ — Action-Reaction Pairs

outcome Action-reaction pair ને સાચી રીતે ઓળખતા (કયા બે object, કયા બે force) આવડશે, અને common misconceptions દૂર થશે.
why it matters ત્રીજો law સૌથી વધારે ગેરસમજ ઊભી કરતો law છે — ખાસ કરીને "તો પછી બે equal-opposite force cancel કેમ નથી થતા" જેવા doubt. આ clear ન થાય તો connected-bodies અને equilibrium problems માં ભૂલ થશે.
3a — Statement 3b — Pair ઓળખવાની રીત 3c — Common misconception

3a. કથન

Statement: દરેક action ને એક equal-magnitude, opposite-direction reaction હોય છે. A, B પર જેટલો force લગાડે, B, A પર બરાબર એટલો જ force, વિરુદ્ધ દિશામાં, એ જ instant લગાડે.

formula — must memorize
FA on B = − FB on A
બંને force ની magnitude સરખી, દિશા વિરુદ્ધ, બંને એક જ સમયે અસ્તિત્વમાં

3b. Pair કેવી રીતે ઓળખવો

Action-reaction pair ના 3 નિયમ યાદ રાખો:

Ruleઅર્થ
1બે force અલગ-અલગ બે object પર લાગે છે — ક્યારેય એક જ object પર બંને નહીં
2બંને force same type ના હોય છે (એક gravity, બીજો gravity; એક normal, બીજો normal — mix ન થાય)
3બંને force એક જ instant અસ્તિત્વમાં હોય — એક પહેલા, બીજો પછી નહીં
વ્યક્તિ દીવાલ પર force લગાડે (action) → દીવાલ વ્યક્તિ પર બરાબર એટલું જ force પાછું આપે (reaction) — વ્યક્તિ પાછળ ધકેલાય છે

3c. સૌથી મોટો misconception — "તો cancel કેમ નથી થતા?"

common misconception "જો બે force equal-opposite હોય, તો net force શૂન્ય થવો જોઈએ, અને object ક્યારેય move જ ન થવું જોઈએ" — આ ખોટું છે, કારણ કે action-reaction ના બે force ક્યારેય cancel નથી થતા, કારણ કે એ અલગ-અલગ object પર લાગે છે. Cancel ફક્ત ત્યારે થાય જ્યારે બે force એક જ object પર લાગેલા હોય (એ equilibrium ની વાત છે, Part 6 માં) — action-reaction pair ક્યારેય એક જ object ના free-body diagram માં સાથે નથી આવતો.
must understand Person દીવાલ ને ધક્કો મારે → દીવાલ person ને પાછું ધક્કો મારે (reaction). Person move થાય છે કારણ કે person ના પોતાના free-body diagram માં ફક્ત એક જ force છે (દીવાલ તરફથી મળતું reaction force) — action force (person → wall) person ના પોતાના diagram માં આવતું જ નથી, એ તો દીવાલ પર લાગે છે.
real-world example
Rocket propulsion — Rocket પાછળની તરફ gas ને જોરથી ધકેલે છે (action), gas rocket ને એટલા જ force થી આગળ ધકેલે છે (reaction) — space માં કોઈ હવા/જમીન ના હોવા છતાં rocket આગળ વધે છે, કારણ કે ધક્કો gas સાથે જ pair થયેલો છે, હવા સાથે નહીં
ચાલવું — પગ જમીન ને પાછળ ધકેલે છે (action), જમીન પગ ને આગળ ધકેલે છે (reaction) — એ જ reaction force આપણને આગળ ચલાવે છે
self-check 1. Earth, Moon ને ગુરુત્વાકર્ષણ force થી ખેંચે છે. Moon, Earth ને કેટલા force થી ખેંચે?
2. ટેબલ પર પડેલી ચોપડી ના weight (mg) નું reaction pair કયું force છે — normal force N, કે કંઈક બીજું?
→ Next: ત્રણેય laws સમજાયા — હવે એમને actual problems માં વાપરવા systematic tool જોઈએ: free body diagram — Part 4.

04Free Body Diagram (FBD) — કેવી રીતે દોરવો

outcome કોઈપણ object નું સાચું free body diagram systematically દોરી શકીશ — આ આખા chapter નું સૌથી વ્યવહારુ (practical) tool છે.
why it matters FBD ખોટું હોય તો 2nd law ની equation ખોટી બનશે, ભલે math ગમે એટલું સાચું હોય. લગભગ દરેક numerical mistake ખરેખર FBD ની ભૂલ હોય છે, algebra ની નહીં.
4a — FBD શું છે 4b — દોરવાના steps 4c — Worked example

4a. FBD શું છે

Free body diagram = એક object ને isolate કરીને, એના પર લાગતા real force (fields અને contact — gravity, normal, tension, friction, spring, applied) ને arrow વડે દોરેલું diagram. "Free" એટલે object ને એના surroundings થી અલગ (free) કરીને, ફક્ત એ એક object પર ધ્યાન કેન્દ્રિત કરવું.

must understand FBD માં ફક્ત એ object પર સીધા લાગતા force આવે — object ના પોતાના weight (એ force system ની બહાર object જે force બીજા પર લગાડે, દા.ત. action-reaction નો બીજો ભાગ), કે "ગતિ" (velocity, acceleration) ને force તરીકે ક્યારેય ન દોરવા. Object ના પોતાના FBD માં "ma" કે "centrifugal force" (non-inertial frame સિવાય) દોરવું ભૂલ છે.

4b. દોરવાના 5 steps

Stepશું કરવું
1જે object નું FBD દોરવું છે એને એક બિંદુ/આકાર તરીકે isolate કરો (surroundings ભૂંસી નાખો — geometry ફક્ત reference માટે)
2Weight (mg) હંમેશા — સીધું નીચે, center થી
3જ્યાં-જ્યાં object બીજી સપાટી/string/spring ને touch કરે છે ત્યાં contact force ઉમેરો (normal, tension, friction, spring force)
4કોઈ applied/external force હોય (push, pull) તો ઉમેરો
5દરેક force ને arrow થી, સાચી દિશામાં, અલગ label સાથે દોરો — magnitude ખબર ન હોય તોય symbol (N, T, f) લખો
Block ને isolate કરીને 3 force: mg (નીચે, weight), N (ઉપર, table નું normal), T (બાજુ, દોરડાનું tension) — ટેબલ, દોરડું ના draw કરવા, ફક્ત force
common mistake FBD માં N ને hંમેશા mg બરાબર માની લેવું — ખોટું. N ફક્ત ત્યારે mg બરાબર થાય જ્યારે vertical direction માં બીજું કોઈ force ન હોય અને object vertically accelerate ન થતું હોય. Incline, extra vertical force, કે vertical acceleration હોય તો N અલગ જ આવે — હંમેશા equation થી કાઢો, ધારી ન લો.
self-check Ceiling થી લટકતો, સ્થિર block નું FBD દોરો — કેટલા force છે, કયા?
→ Next: FBD દોરવા માટે એ જાણવું જોઈએ કે કયા-કયા પ્રકારના force exist કરે છે — Part 5.

05Forces ના પ્રકાર

outcome Gravity, normal, tension, friction (static+kinetic), spring — આ 5 force ને ક્યારે, કેટલા magnitude અને કઈ દિશામાં લગાડવા એ આવડશે.
why it matters 11th level ના લગભગ દરેક mechanics problem આ 5 force ના combination પર જ બનેલો છે — આ ઓળખ્યા વગર કોઈપણ FBD અધૂરું રહેશે.
5a — Gravity (mg) 5b — Normal (N) 5c — Tension (T) 5d — Friction — static/kinetic 5e — Spring force

5a. Gravitational force (Weight)

Earth દરેક object ને પોતાના કેન્દ્ર તરફ (લગભગ સીધું નીચે) ખેંચે છે. Magnitude = mg, હંમેશા vertically downward, object ના center of mass થી.

formula — must memorize
W = mg
g ≈ 9.8 m/s² (ઘણીવાર numerical માં g=10 m/s² વપરાય)

5b. Normal force (N)

જ્યારે બે સપાટી touch કરે, ત્યારે દરેક સપાટી બીજી ને surface ને લંબ (perpendicular) દિશામાં ધકેલે છે — surface ને compress થતી અટકાવવા. Normal force ક્યારેય surface ની સમાંતર (parallel) નથી હોતો.

"normal" કેમ કહેવાય Geometry માં "normal" એટલે surface ને perpendicular રેખા (mathematics નો જૂનો શબ્દ, Latin normalis = "made according to a carpenter's square," એટલે કે ચોક્કસ 90°). Normal force નું નામ સીધું geometric perpendicularity પરથી આવ્યું છે — "સામાન્ય" force નહીં.

5c. Tension (T)

String/rope/wire ખેંચાયેલી (taut) હોય ત્યારે, એની અંદરથી પસાર થતું pulling force — string ના બંને છેડે, string ની લંબાઈ ની દિશામાં, string ને પોતાની તરફ ખેંચતું force. Ideal (massless, inextensible) string માં tension આખી string માં સરખું જ રહે છે.

must understand String ફક્ત ખેંચી શકે (pull), ક્યારેય ધકેલી (push) નથી શકતી — string ઢીલી પડે તો T=0 થઈ જાય, ઋણ ન થાય. Rod આનાથી અલગ છે — rod push અને pull બંને કરી શકે.

5d. Friction — Static અને Kinetic

બે સપાટી વચ્ચે relative motion (અથવા motion ની કોશિશ) ને વિરોધ કરતું, સપાટી ને સમાંતર (parallel) force. બે પ્રકાર: Static friction (સપાટી હજુ move નથી થઈ — friction ખરેખર applied force જેટલું જ self-adjust થાય છે) અને Kinetic friction (સપાટી move થઈ ચૂકી છે — friction હવે fixed, ઓછું).

formula — must memorize
fs,max = μsN   |   fk = μkN
μs > μk હંમેશા (static coefficient, kinetic કરતા વધારે) — object ને "ધકેલવાનું શરૂ" કરવા વધારે force જોઈએ, પણ એકવાર move થાય પછી ઓછું force પૂરતું
applied) f_s,max = 20N kinetic (f_k = 15N, constant) μ_s=0.4 m=5kg, N=50N μ_k=0.3
m=5kg block, N=50N: fs,max=μsN=0.4×50=20N (applied 20N સુધી static friction=applied force); એ પછી block move થાય, fk=μkN=0.3×50=15N constant
worked example
Given — m=5 kg block, μs=0.4, μk=0.3, g=10 m/s², applied force F=25 N horizontal
Need — Block move થશે કે નહીં, અને acceleration
Method — પહેલા fs,max સાથે F compare કરો
Calculation — N=mg=50N; fs,max=0.4×50=20N. F=25N > 20N ⟹ block move કરે છે. હવે kinetic friction લાગુ: fk=0.3×50=15N. Net force = 25−15=10N; a=10/5=2 m/s²
Check — F>f_s,max ⟹ motion — consistent ✓
common mistake Static friction ને હંમેશા μsN (maximum value) બરાબર માની લેવું. Static friction એ maximum સુધીની કોઈપણ value હોઈ શકે — applied force જેટલું જ, self-adjusting. μsN ફક્ત ત્યારે વપરાય જ્યારે block "just about to move" હોય (limiting equilibrium).

5e. Spring force — Hooke's law

Spring ને ખેંચો કે દબાવો, એ પોતાની natural length તરફ પાછા ફરવા force લગાડે છે — displacement ના પ્રમાણમાં, વિરુદ્ધ દિશામાં.

formula — must memorize
F = −kx
k = spring constant (N/m), x = natural length થી displacement, ઋણ ચિહ્ન = force હંમેશા displacement ની વિરુદ્ધ (restoring)
real-world example
Weighing machine ની spring, car ના suspension springs, pen ની click spring — બધા Hooke's law પર કામ કરે છે; JEE માં SHM (Simple Harmonic Motion) chapter પણ આ જ formula પર બંધાયેલું છે
self-check k=200 N/m ની spring 5 cm ખેંચાય તો restoring force કેટલું?
JEE extension — વક્ર (curved) સપાટી પર limiting friction સીધા incline માટે tanθ=μ (limiting condition) એ ખૂણો આખા ઢોળાવ પર એક જ (અચળ) હોય છે. પણ ગોળાકાર/વક્ર સપાટી (દા.ત. ગોળાર્ધ ખાડો, y=f(x) વક્ર) પર દરેક બિંદુએ સ્પર્શકનો ઢોળાવ અલગ-અલગ હોય છે — ત્યાં "સ્થાનિક ખૂણો" જ dy/dx (સ્પર્શકનો slope) બરાબર થાય છે:
સરકવાની શરૂઆત જ્યાં: dy/dx = μ (તે બિંદુએ)
શા માટે: વક્ર સપાટીના કોઈપણ બિંદુએ, ત્યાંનો સ્પર્શક (tangent) એ સ્થાનિક રીતે એક નાનકડા સીધા incline જેવો જ વર્તે છે — એટલે સીધા incline નું tanθ=μ ત્યાં પણ લાગુ પડે, ફક્ત θ ને derivative dy/dx થી કાઢવું પડે.
worked example
Given — બ્લોક y=x²/4 વક્ર સપાટી પર, μ=0.5
Method — dy/dx=μ પર limiting x શોધો, પછી y=x²/4 થી ઊંચાઈ
Calculation — dy/dx=x/2=0.5 ⟹ x=1; y=1²/4=0.25m — આ મહત્તમ ઊંચાઈ જ્યાં સુધી બ્લોક સરકતો નથી
Board syllabus થી આગળ (JEE-level extension) — ગોળાર્ધ ખાડા/ટેકરી પરના "જંતુ ચઢે/બ્લોક મુકાય" પ્રકારના પ્રશ્નોમાં આ જ technique વપરાય છે.

06Equilibrium of Forces

outcome ત્રણ (કે વધારે) concurrent force ના equilibrium problems Lami's theorem અથવા component method થી solve કરી શકીશ.
why it matters લટકતા sign board, hanging weight બે દોરડાથી, static structures — બધા equilibrium problems આ chapter ના numerical માં common છે.
6a — Equilibrium condition 6b — Component method 6c — Lami's theorem

6a. Equilibrium ની condition

Object equilibrium (સ્થિર, અથવા constant velocity) માં હોય ⟺ 1st law પ્રમાણે net force શૂન્ય. Multiple force હોય તો, દરેક independent direction માં (સામાન્ય રીતે horizontal અને vertical) અલગ-અલગ સરવાળો શૂન્ય થવો જોઈએ.

formula — must memorize
ΣFx = 0   અને   ΣFy = 0
Component method — કોઈપણ સંખ્યાના force માટે વાપરી શકાય

6b. ઉદાહરણ — બે દોરડાથી લટકતું weight

Ceiling થી બે string વડે weight W લટકે છે — string OA, horizontal થી 30° ના angle એ, string OB, horizontal થી 60° ના angle એ. Tensions T₁ (OA માં), T₂ (OB માં) કાઢવા.

O બિંદુ પર ત્રણ concurrent force: T₁ (30° ડાબે-ઉપર), T₂ (60° જમણે-ઉપર), W (સીધું નીચે)
worked example
Given — θ₁=30° (ડાબી string), θ₂=60° (જમણી string), W=weight
Need — T₁, T₂ (W ના પ્રમાણમાં)
Method — O બિંદુ પર component method: horizontal balance, vertical balance
Calculation (horizontal) — T₁cos30° = T₂cos60° ⟹ T₁(0.866) = T₂(0.5) ⟹ T₁ = 0.577 T₂
Calculation (vertical) — T₁sin30° + T₂sin60° = W ⟹ (0.577T₂)(0.5) + T₂(0.866) = W ⟹ T₂(0.2887+0.866) = W ⟹ T₂ = 0.866 W
T₁ = 0.577 × 0.866 W = 0.5 W
Check — T₁ : T₂ : W = 0.5 : 0.866 : 1 = sin30° : sin60° : sin90° — આ જ Lami's theorem નું result છે (નીચે જુઓ) ✓

6c. Lami's theorem — ત્રણ concurrent force માટે shortcut

ત્રણ concurrent force equilibrium માં હોય, તો દરેક force, બાકીના બે force વચ્ચેના angle ના sine ના પ્રમાણમાં હોય છે:

formula — must memorize
F₁/sin α = F₂/sin β = F₃/sin γ
α = F₂,F₃ વચ્ચેનો ખૂણો (F₁ ની સામેનો), એ જ પ્રમાણે β, γ — બધા ખૂણા ભેગા મળીને 360°
common mistake Lami's theorem માં angle ને force ની વચ્ચેનો angle (દા.ત. બે string વચ્ચેનો ખૂણો) લેવાની ભૂલ કરવી — સાચી રીત: force ની સામેનો ખૂણો (બાકીના બે force વચ્ચેનો, ૩જા force ની arrow ને ઊલટાવીને measure કરેલો) લેવો.
self-check ઉપરના example માં Lami's theorem વાપરીને T₁ ને W ના પ્રમાણમાં verify કરો (angle opposite to T₁ = 90°+60°=150°... ખૂણાઓ ચકાસો).

07Connected Bodies — Pulley Systems

outcome String/pulley થી જોડાયેલા બે object ના systems (Atwood machine સહિત) ને solve કરવાની systematic method આવડશે.
why it matters Connected-body problems (Atwood machine, incline+pulley) JEE અને board બંનેમાં high-frequency numerical છે — string ના constraint (બંને object ની acceleration સરખી) ને યોગ્ય રીતે વાપરવું આ topic ની ચાવી છે.
7a — String constraint 7b — Atwood machine

7a. String constraint — પાયાનો વિચાર

Ideal (massless, inextensible) string બે object ને જોડે ત્યારે: (1) string માં tension આખે-આખી સરખું, (2) string ની લંબાઈ ફિક્સ હોવાથી, બંને object ની speed અને acceleration ની magnitude સરખી હોય છે (string ના બંને છેડે જોડાયેલા object એક સાથે જ ખસે).

must understand Connected bodies problem solve કરવાની ચાવી: દરેક object નું અલગ FBD દોરો, દરેક માટે અલગ 2nd law equation લખો, પછી string constraint (a સરખું, T સરખું) વાપરીને equations ને ભેગી ઉકેલો — બંને object ને ભેગા "એક system" તરીકે વિચારવાની ભૂલ direction sign ને ગૂંચવી નાખે છે.

7b. Atwood Machine — બે લટકતા mass, એક pulley

Frictionless, massless pulley પરથી પસાર થતી string ના બંને છેડે m₁, m₂ (m₂>m₁) લટકે છે.

m₂ (ભારે) નીચે, m₁ (હલકું) ઉપર — બંને ની acceleration magnitude સરખી (string constraint), tension T બંને બાજુ સરખું
worked example — derivation
Given — m₁=3 kg, m₂=5 kg, g=10 m/s², frictionless massless pulley
m₂ ની equation (નીચે તરફ move, નીચે positive) — m₂g − T = m₂a
m₁ ની equation (ઉપર તરફ move, ઉપર positive) — T − m₁g = m₁a
બંને equation ઉમેરો — m₂g − m₁g = (m₁+m₂)a ⟹ a = (m₂−m₁)g/(m₁+m₂)
Calculation — a = (5−3)(10)/(3+5) = 20/8 = 2.5 m/s²
Tension — m₁ ના equation થી: T = m₁(g+a) = 3(10+2.5) = 37.5 N; m₂ ના equation થી verify: T = m₂(g−a) = 5(10−2.5) = 37.5 N ✓ બંને same
formula — Atwood machine, must memorize
a = (m₂−m₁)g / (m₁+m₂)
T = 2m₁m₂g / (m₁+m₂) — બંને mass ના equation ને ભેગા ઉકેલતા સીધું આ formula મળે
common mistake બંને mass ને એક જ equation માં "એક system" ગણીને m₂g−m₁g=(m₁+m₂)a સીધું લખી દેવું, પણ Tension કાઢવાનું ભૂલી જવું — Tension માટે અચૂક કોઈ એક mass નું અલગ equation પાછું વાપરવું પડે.
self-check m₁=2 kg, m₂=6 kg હોય તો a અને T કેટલા થશે? (g=10 m/s²)
JEE extension — cascading (ગરગડી-પર-ગરગડી) constraint method ક્યારેક એક movable ગરગડી બીજી ગરગડીના axle પરથી લટકે છે (ગરગડી-ની-અંદર-ગરગડી). આવા multi-level તંત્રમાં, દરેક ગરગડી માટે અલગ-અલગ constraint સમીકરણ લખવું પડે — બધા mass ને એક સાથે ભેગા ના કરવા:
દરેક movable ગરગડી માટે: (છેડા-1 નો a) + (છેડા-2 નો a) = 2 × (ગરગડીના axle નો a)
પદ્ધતિ: સૌથી ઉપરની (ceiling-fixed) ગરગડીથી શરૂ કરો — તેના બે છેડા (એક mass, બીજો નીચેની ગરગડીની axle) નો સંબંધ લખો. પછી નીચેની ગરગડી માટે ફરી આ જ rule (તેના પોતાના બે છેડા માટે) લખો. છેલ્લે બધા સમીકરણોને substitute કરી એક જ સંબંધમાં ભેગા કરો.
worked example — sketch
Setup — ટોચની ગરગડી પર m₁ (એક બાજુ) અને બીજી ગરગડીની axle (બીજી બાજુ); એ બીજી ગરગડી પર m₂ અને ત્રીજી ગરગડીની axle; ત્રીજી ગરગડી પર m₃,m₄
Step 1 — ટોચની ગરગડી: a(2જી ગરગડીની axle) = −a₁
Step 2 — 2જી ગરગડી: a₂ + a(3જી ગરગડીની axle) = 2×(−a₁)
Step 3 — 3જી ગરગડી: a(3જી ગરગડીની axle) = (a₃+a₄)/2
Combine — a₂+(a₃+a₄)/2=−2a₁ ⟹ 4a₁+2a₂+a₃+a₄=0
Board syllabus થી આગળ (JEE-level extension) — સામાન્ય Atwood machine (Part 7 નો મુખ્ય ભાગ) એ આનો જ સાદો (single-pulley) ખાસ કિસ્સો છે.

JEE pattern — દોરી પર ચડતો માણસ અને spring balance નું વાંચન

T = m(g + a) ની રેખા m = 60 kg માટે ગણેલી: a = 0 પર 600 N, a = 2 m/s² પર 720 N > 700 N.
formula — must memorize
માણસ દોરી પર a થી ઉપર ચડે: T − mg = ma ⟹ T = m(g + a)
માણસ દોરીને નીચે ખેંચે છે, પ્રતિક્રિયારૂપે દોરી તેને ઉપર T થી ખેંચે છે (3rd law). નીચે a થી ઉતરે ⟹ T = m(g − a). Spring balance હંમેશા તેમાંથી પસાર થતો તણાવ વાંચે — system ગતિમાં હોય તો લટકતા દળનું mg નહીં. Real-world: gym rope climbing — ઝટકાથી ચડતાં દોરી પર ભાર વધે છે, એટલે rope rating વજન કરતાં વધુ રખાય.
worked example
Given — 60 kg માણસ, દોરી 700 N સુધી સહન કરે (g = 10)
Need — મહત્તમ ઉપર તરફનો પ્રવેગ
Method — T = m(g + a) ≤ 700
Calculation — 60(10 + a) ≤ 700 ⟹ a ≤ 1.67 m/s²
Check — a = 2 ⟹ 720 N > 700 ⟹ દોરી તૂટે ✓
common mistakeSpring balance ને "લટકતા દળનું વજન" વાંચતું માનવું — ગતિમાં (Atwood જેવા તંત્રમાં) વાંચન T = m(g ∓ a) હોય છે.

08Circular Motion Dynamics

outcome Banking of roads અને conical pendulum ના problems માં centripetal force ને correctly identify કરીને solve કરી શકીશ.
why it matters Circular path પર ફરતા object ને પણ Newton's 2nd law જ લાગુ પડે છે — ફક્ત acceleration ની દિશા center તરફ (centripetal) હોય છે. Road turn, satellite, pendulum — બધામાં આ જ logic વપરાય છે. (Collision અને full rotational dynamics આ chapter ના scope બહાર છે — અલગ topic.)
8a — Centripetal force ની foundation 8b — Banking of roads 8c — Conical pendulum

8a. Centripetal force — "force" કોઈ નવો પ્રકાર નથી

Circular path પર constant speed થી ફરતું object પણ accelerate થાય છે — કારણ કે velocity ની દિશા સતત બદલાય છે (speed ભલે ના બદલાય). આ acceleration હંમેશા center તરફ હોય છે — તેને centripetal (Latin: "center શોધતું") acceleration કહે છે. 2nd law પ્રમાણે, આ acceleration લાવવા માટે જરૂરી net force ને centripetal force કહેવાય — પણ એ કોઈ નવા પ્રકારનું force નથી, existing force (tension, normal, gravity, friction) જ, center તરફ ગોઠવાઈને આ ભૂમિકા ભજવે છે.

formula — must memorize
Fc = mv²/r = mω²r
હંમેશા center તરફ; આ કોઈ "extra" force ઉમેરવાનો નથી — ફક્ત existing force નું net, center તરફ કેટલું છે એ measure છે
common mistake FBD માં "centrifugal force" ને બહારની તરફ દોરી દેવું (ground/inertial frame માંથી solve કરતી વખતે). Centrifugal force ફક્ત rotating (non-inertial) frame ની અંદર બેસીને solve કરો ત્યારે જ pseudo-force તરીકે આવે — ground frame થી ક્યારેય નહીં (જુઓ Part 1c).

8b. Banking of roads

વળાંકવાળા રસ્તા ને બહારની ધાર ઊંચી (angle θ) બનાવવામાં આવે છે જેથી friction વગર પણ car centripetal force મેળવી શકે — normal force N નો horizontal component જ centripetal force પૂરું પાડે.

N ને θ ના ખૂણે split: N cosθ weight balance કરે (vertical), N sinθ centripetal force પૂરું પાડે (horizontal, center તરફ)
derivation
Vertical equilibrium: N cosθ = mg
Horizontal (centripetal): N sinθ = mv²/r
બીજાને પહેલાથી ભાગતા: tanθ = v²/(rg)
formula — must memorize (ideal banking, no friction)
tan θ = v² / (rg)
આ v ને "ideal speed" કહેવાય — આ speed પર friction ની જરૂર જ નથી પડતી
worked example
Given — r=100 m, θ=30°, g=10 m/s²
Need — ideal speed v
Calculation — v² = rg tanθ = 100×10×tan30° = 1000×0.577 = 577; v = √577 ≈ 24 m/s (≈ 86.4 km/h)
real-world example
Highway ના વળાંક, race track (Formula 1 ના banked curve), railway track ના વળાંક પર outer rail ને થોડું ઊંચું રાખવું — બધા આ જ principle વાપરે છે

8c. Conical pendulum

એક દોરડાના છેડે mass બાંધીને, બીજો છેડો ફિક્સ કરીને, mass ને horizontal circle માં ફેરવવામાં આવે — દોરડું ફરતા-ફરતા એક cone નો આકાર બનાવે છે.

String vertical થી θ ના ખૂણે ઝૂકે છે; T cosθ weight balance કરે, T sinθ centripetal force પૂરું પાડે — banking જેવું જ ganit, T ની જગ્યાએ N
must understand — banking જેવું જ pattern Conical pendulum અને banked road ganit-rite (mathematically) સરખા છે — ફક્ત banking માં N (surface normal) role ભજવે છે, conical pendulum માં T (string tension) — બંનેમાં "force ને બે component માં split કરો, એક weight balance કરે, બીજો centripetal force પૂરો પાડે" — એ જ logic.
worked example
Given — string length L=1 m, θ=37° (sin37°=0.6, cos37°=0.8), g=10 m/s²
Need — speed v, અને period of revolution
Calculation — r = L sinθ = 1×0.6 = 0.6 m; h = L cosθ = 1×0.8 = 0.8 m (O થી circle ના plane સુધીની ઊંચાઈ)
tanθ = v²/(rg) ⟹ v² = rg tanθ = 0.6×10×(0.6/0.8) = 6×0.75 = 4.5; v ≈ 2.12 m/s
Period — Tperiod = 2π√(h/g) = 2π√(0.8/10) = 2π×0.283 ≈ 1.78 s
common mistake r ને string ની લંબાઈ L બરાબર માની લેવી. Circle ની actual radius r = L sinθ છે (string ના vertical component L cosθ નહીં) — θ ધ્યાનમાં લીધા વગર r=L વાપરવાથી જવાબ ખોટો આવશે.
self-check 1. Banked road પર car ideal speed કરતાં ધીમી જાય તો friction કઈ દિશામાં કામ કરશે (અંદર કે બહાર)?
2. Conical pendulum માં θ વધારવાથી (વધારે ઝડપે ફેરવવાથી) speed v વધે કે ઘટે?
chapter સમાપ્ત — યાદ રાખવાના મુખ્ય points
  1. 1st law: net force=0 ⟺ a=0 (rest અથવા uniform velocity) — inertial frame માં જ સીધું સાચું
  2. 2nd law: F=ma (constant mass), મૂળભૂત રીતે F=dp/dt; impulse J=FΔt=Δp
  3. 3rd law: action-reaction હંમેશા બે અલગ object પર, same type, same instant — ક્યારેય cancel નથી થતા
  4. FBD: ફક્ત object પર સીધા લાગતા real force — weight, normal, tension, friction, spring, applied
  5. Friction: fs≤μsN (self-adjusting), fk=μkN (fixed); μs>μk
  6. Connected bodies: અલગ FBD, string constraint (a સરખું, T સરખું) વાપરો
  7. Circular motion: banking/conical pendulum બંનેમાં tanθ=v²/(rg) — force ને split કરવાની logic સરખી

02વાયુના નિયમો↗

Boyle (T સ્થિર)
PV = const
Charles (P સ્થિર)
V/T = const
Gay-Lussac (V સ્થિર)
P/T = const
Avogadro (P, T સ્થિર)
V/n = const
ભૂલ
T હંમેશા કેલ્વિનમાં. બંને બાજુ એક જ P/V એકમ.
self-check
P બમણું, T સ્થિર → V = અડધું.

03આદર્શ વાયુ સમીકરણ↗

આદર્શ વાયુ
PV = nRT
n = m/M · R = 0.0821 (atm, L) / 8.314 (SI)
ઘનતા ↔ મોલર દળ
d = PM/RT
M = dRT/P · તપાસ: 1.25 g/L, 273 K, 1 atm → 28.0 g/mol
self-check
0.5 mol, 5 L, 300 K → P = 2.463 atm
ભૂલ
atm સાથે 0.0821, Pa સાથે 8.314 — મિશ્રણથી હજાર ગણું ખોટું

04ડાલ્ટનનો આંશિક દબાણનો નિયમ↗

કુલ દબાણ
P = Σ pi
આંશિક દબાણ
pi = xi · P
x = મોલ-અંશ (દળ નહીં)

05ગ્રેહામનો નિયમ↗

06ગતિજ સિદ્ધાંત અને ઝડપ↗

ઝડપ (SI, M kg/mol)
ump = √(2RT/M)
સરેરાશ ઝડપ
uavg = √(8RT/πM)
rms ઝડપ
urms = √(3RT/M)
ક્રમ
1.414 : 1.596 : 1.732
ump : uavg : urms
તપાસ
O₂, 300 K → urms = 483.6 m/s · ump = 394.8 m/s
self-check
urms 4 ગણી → T 16 ગણું (u ∝ √T)
ભૂલ
M ને g/mol માં લઈને R = 8.314 — kg/mol કરો

07વાસ્તવિક વાયુઓ↗

Compressibility
Z = PV / nRT
Z = 1 આદર્શ · Z < 1 આકર્ષણ · Z > 1 કદ-અસર
van der Waals
(P + an²/V²)(V − nb) = nRT
a: આકર્ષણ (દબાણ ઉમેરો) · b: કદ (કદમાંથી બાદ)
JEE only — ક્રાંતિક
Tc = 8a/27Rb · Pc = a/27b² · Vc = 3b
JEE only — Boyle તાપમાન
TB = a/Rb
તપાસ CO₂
a = 3.6, b = 0.0427 → Tc ≈ 304 K, Pc ≈ 73 atm
ભૂલ
a, b ના એકમ ભૂલવા — a: L²·atm/mol², b: L/mol
